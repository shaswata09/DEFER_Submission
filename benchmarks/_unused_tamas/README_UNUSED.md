# Not reported

This directory held the TAMAS "simulated" and "real-logs" evaluations. Both are
self-authored, LLM-free smoke tests of the P1-P5 middleware against scripted
payloads: the "attacker" and the "defender" are the same code base, so the
numbers say nothing about a real adversary and are **not reported** in the
revision. The code is kept only so that the archived v1 results under
`results_legacy_v1/` can be traced; nothing in the analysis pipeline reads it.
