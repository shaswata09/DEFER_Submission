│                                                                              │

│  link amino acids together to form proteins. Ribosomes can be found          │

│  reticulum. So, while the nucleus is essential for providing the blueprint,  │
│  the ribosome is the machine that does the building.                         │
│                                                                              │

│  is the construction site where the building (protein) is actually made.     │

│  ---                                                                         │
│                                                                              │
│  **2. Question: Where is DNA stored in a eukaryotic cell?**                  │
│  **Student Response:** Cytoplasm                                             │
│  **Correct Answer:** Nucleus                                                 │
│                                                                              │
│  **Explanation:**                                                            │
│  In eukaryotic cells (like those in plants, animals, and fungi), DNA is      │
│  safely stored inside the **nucleus**, which is surrounded by a protective   │
│  membrane. The nucleus acts like a control center, keeping the genetic       │
│  material organized and protected while regulating which genes are used and  │
│  when.                                                                       │
│                                                                              │
│  The **cytoplasm** is the jelly-like fluid that fills the cell and contains  │
│  organelles like mitochondria and ribosomes, but it does *not* contain the   │
│  cell’s main DNA. While mitochondria do have a small amount of their own     │
│  DNA, the vast majority is in the nucleus.                                   │
│                                                                              │
│  **Helpful Analogy:**                                                        │
│  Imagine the nucleus as a safe where the most important documents (DNA) are  │
│  kept. The cytoplasm is like the rest of the office — busy and important,    │
│  but the master files aren’t just sitting out on the desk.                   │
│                                                                              │

│  **3. Question: What is the cytoskeleton made of?**                          │
│  **Student Response:** Microtubules and microfilaments                       │
│  **Correct Answer:** Microtubules, actin filaments (microfilaments), and     │
│  intermediate filaments                                                      │
│                                                                              │
│  **Explanation:**                                                            │
│  You were on the right track! The cytoskeleton is like the cell’s internal   │
│  scaffolding, and it’s made of **three** main types of protein fibers        │
│  working together:                                                           │
│                                                                              │
│  - **Microtubules**: Thick, hollow tubes that help maintain cell shape, act  │
│  as tracks for moving organelles, and are key during cell division.          │
│  - **Actin filaments (microfilaments)**: Thin fibers that help with cell     │
│  movement and changes in shape, like when a cell crawls or pinches in two.   │
│  - **Intermediate filaments**: Middle-sized fibers that provide mechanical   │
│  strength and help anchor organelles in place.                               │
│                                                                              │
│  While you correctly identified microtubules and microfilaments,             │
│  **intermediate filaments** are also a crucial part of the system — they’re  │
│  the “steel cables” that add durability and help the cell resist             │
│  stretching.                                                                 │
│                                                                              │
│  **Helpful Analogy:**                                                        │
│  Think of the cytoskeleton like a tent: microtubules are the poles that      │
│  give it shape, actin filaments are the ropes that allow it to shift or      │
│  move, and intermediate filaments are the guy lines that keep it sturdy in   │
│  the wind.                                                                   │

### **Detailed Explanations for Incorrect Answers**

**1. Question: Which organelle is responsible for protein synthesis?**  
**Student Response:** Nucleus  
**Correct Answer:** Ribosome  

**Explanation:**  
It’s a common mix-up, but here’s the key: while the **nucleus** holds the DNA that contains the *instructions* for making proteins, it doesn’t actually build them. Think of the nucleus like a library where the recipe book (DNA) is stored. The actual cooking (protein synthesis) happens in the kitchen — and in the cell, that kitchen is the **ribosome**.

**Helpful Analogy:**  
The nucleus is like the office that sends out blueprints, and the ribosome is the construction site where the building (protein) is actually made.

**2. Question: Where is DNA stored in a eukaryotic cell?**  
**Student Response:** Cytoplasm  
**Correct Answer:** Nucleus  

**Explanation:**  
In eukaryotic cells (like those in plants, animals, and fungi), DNA is safely stored inside the **nucleus**, which is surrounded by a protective membrane. The nucleus acts like a control center, keeping the genetic material organized and protected while regulating which genes are used and when.

The **cytoplasm** is the jelly-like fluid that fills the cell and contains organelles like mitochondria and ribosomes, but it does *not* contain the cell’s main DNA. While mitochondria do have a small amount of their own DNA, the vast majority is in the nucleus.

**Helpful Analogy:**

**Helpful Analogy:**
