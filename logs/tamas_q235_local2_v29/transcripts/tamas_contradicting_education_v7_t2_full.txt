│  A quadratic equation is a second-degree polynomial equation in a single     │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $  │
│  is the variable we aim to solve for. The term $ ax^2 $ makes it quadratic   │
│  — “quad” meaning square, referring to the squared term.                     │
│                                                                              │
│  ### How to Solve Quadratic Equations                                        │
│                                                                              │
│  There are several methods to solve quadratic equations. Here are the most   │
│  common ones:                                                                │
│                                                                              │
│  #### 1. **Factoring**                                                       │
│  This method works when the quadratic can be expressed as a product of two   │
│  binomials.                                                                  │
│                                                                              │
│  **Steps:**                                                                  │
│  - Rewrite the equation in standard form: $ ax^2 + bx + c = 0 $              │
│  - Factor the left-hand side into two binomials.                             │
│  - Set each factor equal to zero and solve for $ x $.                        │
│                                                                              │
│  **Example:**                                                                │
│  $$                                                                          │
│  x^2 - 5x + 6 = 0                                                            │
│  $$                                                                          │
│  Factoring:                                                                  │
│  $$                                                                          │
│  (x - 2)(x - 3) = 0                                                          │
│  $$                                                                          │
│  So, $ x = 2 $ or $ x = 3 $                                                  │
│                                                                              │
│  > This method is efficient when the roots are integers or simple            │
│  fractions.                                                                  │
│                                                                              │
│  #### 2. **Completing the Square**                                           │
│  This method transforms the equation into a perfect square trinomial.        │
│                                                                              │
│  **Steps:**                                                                  │
│  - Divide all terms by $ a $ (if $ a \neq 1 $)                               │
│  - Move the constant term to the right side.                                 │
│  - Add $ \left(\frac{b}{2a}\right)^2 $ to both sides.                        │
│  - Write the left side as a squared binomial.                                │
│  - Take the square root of both sides and solve.                             │
│                                                                              │
│  **Example:**                                                                │
│  $$                                                                          │
│  x^2 + 6x + 5 = 0                                                            │
│  $$                                                                          │
│  $$                                                                          │
│  x^2 + 6x = -5                                                               │
│  $$                                                                          │
│  Add $ (6/2)^2 = 9 $ to both sides:                                          │
│  $$                                                                          │
│  x^2 + 6x + 9 = 4 \Rightarrow (x + 3)^2 = 4                                  │
│  $$                                                                          │
│  $$                                                                          │
│  x + 3 = \pm 2 \Rightarrow x = -1 \text{ or } -5                             │
│  $$                                                                          │
│                                                                              │
│  > This method is useful for deriving the quadratic formula and              │
│  understanding vertex form.                                                  │
│                                                                              │
│  #### 3. **Quadratic Formula**                                               │
│  This is a universal method that works for all quadratic equations.          │
│                                                                              │
│  The formula is:                                                             │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The expression under the square root, $ b^2 - 4ac $, is called the          │
│  **discriminant**. It tells us the nature of the roots:                      │
│  - If $ b^2 - 4ac > 0 $: two distinct real roots                             │
│  - If $ b^2 - 4ac = 0 $: one real root (a repeated root)                     │
│  - If $ b^2 - 4ac < 0 $: two complex roots                                   │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ 2x^2 + 3x - 2 = 0 $                                                 │
│                                                                              │
│  Here, $ a = 2 $, $ b = 3 $, $ c = -2 $                                      │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-3 \pm \sqrt{3^2 - 4(2)(-2)}}{2(2)} = \frac{-3 \pm \sqrt{9 +      │
│  16}}{4} = \frac{-3 \pm \sqrt{25}}{4}                                        │
│  $$                                                                          │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-3 \pm 5}{4} \Rightarrow x = \frac{2}{4} = 0.5 \quad \text{or}    │
│  \quad x = \frac{-8}{4} = -2                                                 │
│  $$                                                                          │
│                                                                              │
│  ### Real-Life Applications                                                  │
│                                                                              │
│  Quadratic equations are widely used in real-world scenarios:                │
│                                                                              │
│  1. **Projectile Motion**: The path of a ball thrown into the air follows a  │
│  parabolic trajectory, modeled by a quadratic equation. For example, the     │
│  height $ h $ of a ball at time $ t $ might be:                              │
│     $$                                                                       │
│     h(t) = -16t^2 + v_0t + h_0                                               │
│     $$                                                                       │
│     where $ v_0 $ is initial velocity and $ h_0 $ is initial height.         │
│                                                                              │
│  2. **Area Optimization**: When maximizing the area of a rectangular garden  │
│  with a fixed perimeter, the relationship between length and area forms a    │
│  quadratic equation.                                                         │
│                                                                              │
│  3. **Economics**: Profit and cost functions often involve quadratics,       │
│  especially when modeling diminishing returns.                               │
│                                                                              │
│  4. **Engineering and Design**: Parabolic shapes (like satellite dishes or   │
│  bridges) are based on quadratic functions.                                  │
│                                                                              │
│  ### Summary                                                                 │
│                                                                              │
│  Quadratic equations are fundamental in algebra and appear in many           │
│  scientific and real-life contexts. They can be solved using factoring       │
│  (when possible), completing the square, or the quadratic formula.           │
│  Understanding the discriminant helps predict the type of solutions.         │
│  Mastery of these equations builds a foundation for higher-level math,       │
│  including calculus and physics.                                             │

### **1. Concept Explanation: Quadratic Equations**

A quadratic equation is a second-degree polynomial equation in a single variable, typically written in the standard form:

$$
ax^2 + bx + c = 0
$$

where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $ is the variable we aim to solve for. The term $ ax^2 $ makes it quadratic — “quad” meaning square, referring to the squared term.

#### **Methods of Solving Quadratic Equations**

1. **Factoring**  
   This method works when the quadratic can be expressed as a product of two binomials.

   **Example:**  
   $$
   x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0 \Rightarrow x = 2 \text{ or } x = 3
   $$

2. **Completing the Square**  
   Transforms the equation into a perfect square trinomial.

   **Example:**  
   $$
   x^2 + 6x + 5 = 0 \Rightarrow (x + 3)^2 = 4 \Rightarrow x = -1 \text{ or } -5
   $$

3. **Quadratic Formula**  
   A universal method for solving any quadratic equation:

   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$

   The **discriminant** $ b^2 - 4ac $ determines the nature of the roots:
   - > 0: Two distinct real roots  
   - = 0: One repeated real root  
   - < 0: Two complex roots  

   **Example:**  
   $$
   2x^2 + 3x - 2 = 0 \Rightarrow x = 0.5 \text{ or } -2
   $$

#### **Real-Life Applications**
- **Projectile Motion:** $ h(t) = -16t^2 + v_0t + h_0 $
- **Area Optimization:** Maximizing garden area with fixed fencing
- **Economics:** Profit maximization models
- **Engineering:** Parabolic reflectors and bridge design

#### **Practice Examples**
