│  Newton's First Law states that an object at rest stays at rest, and an      │
│  object in motion continues in motion with the same speed and in the same    │
│  direction unless acted upon by an unbalanced force. This tendency to        │
│  resist changes in motion is called inertia, and it depends only on          │
│  mass—the more mass, an object has, the greater its inertia. A common        │
│  example is a book lying on a table; it won’t suddenly start moving unless   │
│  someone pushes it. Similarly, a hockey puck sliding on ice will keep going  │
│  until friction or a player stops it. The misconception here is that         │
│  “motion creates force,” but in reality, force is not produced by motion     │
│  itself—force causes changes in motion. If no net force acts on a moving     │
│  object, it will simply keep moving at constant velocity, as seen in space   │
│  where spacecraft glide without propulsion.                                  │
│                                                                              │
│  Newton's Second Law explains how the velocity of an object changes when it  │
│  is subjected to an external force. It is mathematically expressed as F_net  │
│  = ma, meaning the net force on an object equals its mass times its          │
│  acceleration. Acceleration is the rate of change of velocity, so if you     │
│  push a shopping cart with twice the force, it accelerates twice as much     │
│  (assuming mass stays constant). If the mass doubles, the same force         │
│  produces half the acceleration. A real-world example is a car accelerating  │
│  from a stoplight: the engine provides force through the tires, and the      │
│  car’s acceleration depends on both the force applied and the total mass of  │
│  passengers and cargo. A frequent misunderstanding is thinking that F=ma     │

│  isn’t true—once force stops, acceleration stops, though motion may          │
│  continue.                                                                   │

│  Newton's Third Law asserts that for every action, there is an equal and     │
│  opposite reaction. This means forces always come in pairs: if Object A      │
│  exerts a force on Object B, then Object B simultaneously exerts an equal    │
│  and opposite force on Object A. These forces act on different objects,      │

│  (action), the gas pushes the rocket upward with equal force (reaction).     │

│  cancel—this would only happen if they acted on the same object, which they  │

│  Newton's Third Law asserts that for every action, there is an equal and     │

### **Concept Explanations for Common Errors**

**2. Newton’s Third Law: Equal and Opposite Forces on Different Objects**  
When you push a wall, it pushes back equally. These forces don’t cancel because they act on *different* things: your hand and the wall. If you push a cart, the cart pushes back on you, but since you’re braced on the ground, you move it forward.

**3. Energy Is Transformed, Not Lost**

**Example**: Brakes on a bike get hot—kinetic energy becomes thermal energy.
