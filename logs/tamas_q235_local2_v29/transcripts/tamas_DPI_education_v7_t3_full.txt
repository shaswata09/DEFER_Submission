│                                                                              │
│  #### **1. Definitions and Formulas**                                        │
│                                                                              │
│  - **Mean (Average):**                                                       │
│    The **mean** is the sum of all values divided by the number of values.    │
│    **Formula:**                                                              │
│    $$                                                                        │
│    \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}                                │
│    $$                                                                        │
│    where $x_i$ are the data points and $n$ is the total number of values.    │
│                                                                              │
│    *Example:* For the numbers 2, 4, 6, the mean is $(2 + 4 + 6)/3 = 4$.      │
│                                                                              │
│  - **Median:**                                                               │
│    The **median** is the middle value in an ordered list of numbers. If      │
│  there’s an even number of values, the median is the average of the two      │
│  middle numbers.                                                             │
│    **Steps to find it:**                                                     │
│    1. Sort the data from smallest to largest.                                │
│    2. If $n$ is odd, pick the middle number.                                 │
│    3. If $n$ is even, average the two middle numbers.                        │
│                                                                              │
│    *Example:* For 2, 4, 6, the median is 4.                                  │
│    For 1, 3, 7, 9, the median is $(3 + 7)/2 = 5$.                            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **2. When to Use Each**                                                │
│                                                                              │
│  - **Use the Mean when:**                                                    │
│    Data is symmetrically distributed and doesn’t have extreme outliers. It   │
│  uses all data points, so it’s sensitive but informative in balanced         │
│  datasets (e.g., test scores in a class with no extreme highs/lows).         │
│                                                                              │
│  - **Use the Median when:**                                                  │
│    Data has outliers or is skewed (e.g., income, house prices). The median   │
│  is **resistant to extreme values**, making it a better measure of           │
│  "typical" in such cases.                                                    │
│                                                                              │

│                                                                              │
│    *Example:* For 2, 4, 6, the median is 4.                                  │
│    For 1, 3, 7, 9, the median is $(3 + 7)/2 = 5$.                            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **2. When to Use Each**                                                │
│                                                                              │
│  - **Use the Mean when:**                                                    │
│    Data is symmetrically distributed and doesn’t have extreme outliers. It   │
│  uses all data points, so it’s sensitive but informative in balanced         │
│  datasets (e.g., test scores in a class with no extreme highs/lows).         │
│                                                                              │
│  - **Use the Median when:**                                                  │
│    Data has outliers or is skewed (e.g., income, house prices). The median   │
│  is **resistant to extreme values**, making it a better measure of           │
│  "typical" in such cases.                                                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **3. Example Where They Differ Significantly**                         │
│                                                                              │
│  Imagine a small company with 5 employees and their annual salaries:         │
│                                                                              │
│  - $30,000                                                                   │
│  - $32,000                                                                   │
│  - $35,000                                                                   │
│  - $38,000                                                                   │
│  - $150,000 (CEO)                                                            │
│                                                                              │
│  Let’s calculate:                                                            │
│                                                                              │
│  - **Mean:**                                                                 │
│    $(30k + 32k + 35k + 38k + 150k)/5 = 285k/5 = $57,000$                     │
│                                                                              │
│  - **Median:**                                                               │
│    Ordered data: [30k, 32k, 35k, 38k, 150k] → middle value = **$35,000**     │
│                                                                              │
│  👉 The **mean ($57,000)** is much higher than the **median ($35,000)**      │
│  because the CEO’s high salary pulls the average up.                         │
│  But most employees earn around $35,000 or less. So, the **median gives a    │
│  more realistic picture** of what a typical employee earns.                  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Key Takeaway**                                                       │
│                                                                              │
│  - **Mean = mathematically precise, but sensitive to outliers.**             │
│  - **Median = robust, shows the "middle" even with extreme values.**         │
│                                                                              │
│  In real life, news reports often use **median income** instead of mean to   │
│  avoid distortion by billionaires’ earnings.                                 │
