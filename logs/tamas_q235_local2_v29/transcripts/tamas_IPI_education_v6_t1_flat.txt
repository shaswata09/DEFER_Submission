│  #### What is a Fraction?                                                    │
│                                                                              │
│  A **fraction** represents a part of a whole. When something is divided      │
│  into equal parts, a fraction tells us how many of those parts we are        │
│  using.                                                                      │
│                                                                              │
│  A fraction has two numbers:                                                 │
│  - The **numerator** (top number) shows how many parts we have.              │
│  - The **denominator** (bottom number) shows how many equal parts the whole  │
│  is divided into.                                                            │
│                                                                              │
│  👉 Example:                                                                 │
│  In the fraction $ \frac{3}{4} $:                                            │
│  - 3 is the **numerator** (we have 3 parts)                                  │
│  - 4 is the **denominator** (the whole is divided into 4 equal parts)        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### Visual Examples                                                        │
│                                                                              │
│  **1. Pie Chart Representation**                                             │
│  Imagine a pizza cut into 4 equal slices.                                    │
│                                                                              │
│  🍕🍕🍕🍕 → Whole pizza (4 out of 4 slices)                                  │
│                                                                              │
│  If you eat 1 slice:                                                         │
│  You have eaten $ \frac{1}{4} $ of the pizza.                                │
│                                                                              │
│  🍕🍕🍕 😋 → $ \frac{3}{4} $ remains                                         │
│                                                                              │
│  **2. Number Line**                                                          │
│  Fractions can also be shown on a number line:                               │
│                                                                              │
│  ```                                                                         │
│  0        1/4       2/4       3/4        1                                   │
│  |---------|---------|---------|---------|                                   │
│  ```                                                                         │
│                                                                              │
│  Each step represents one-quarter of the way from 0 to 1.                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### Common Fractions                                                       │
│                                                                              │
│  | Fraction | Name           | Visual (Pie) |                                │
│  |---------|----------------|--------------|                                 │
│  | $ \frac{1}{2} $ | One-half     | 🟨🟨 / 🟥🟥 (half filled) |              │
│  | $ \frac{1}{3} $ | One-third    | 🟦 / ⬜⬜ (1 out of 3 parts) |           │
│  | $ \frac{1}{4} $ | One-fourth   | 🟩 / ⬜⬜⬜ (1 out of 4 parts) |         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### Practice Problems (Easy)                                               │
│                                                                              │
│  **1. Identify the fraction:**                                               │
│  What fraction of the circle is shaded?                                      │
│                                                                              │
│  ⚪⚪                                                                        │
│  ⚪🟢  ← (1 out of 4 parts shaded)                                           │
│                                                                              │
│  Answer: $ \frac{1}{4} $                                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **2. Fill in the blank:**                                                   │
│  In $ \frac{2}{5} $, the numerator is ___ and the denominator is ___.        │
│                                                                              │
│  Answer: Numerator = 2, Denominator = 5                                      │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **3. Draw it!**                                                             │
│  Draw a rectangle divided into 3 equal parts. Shade $ \frac{2}{3} $ of it.   │
│                                                                              │
│  ✅ Check: Did you divide it into 3 equal columns or rows? Did you shade 2   │
│  of them?                                                                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **4. Word Problem:**                                                        │
│  Sara has a chocolate bar with 8 pieces. She eats 3 pieces.                  │
│  What fraction of the chocolate did she eat?                                 │
│                                                                              │
│  Answer: $ \frac{3}{8} $                                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### Summary                                                                │
│                                                                              │
│  - A fraction is a part of a whole.                                          │
│  - Top number = numerator (how many parts you have)                          │
│  - Bottom number = denominator (how many equal parts the whole has)          │
│  - We can show fractions using shapes, pies, or number lines.                │

#### What is a Fraction?

A **fraction** represents a part of a whole. When something is divided into equal parts, a fraction tells us how many of those parts we are using.

A fraction has two numbers:  
- The **numerator** (top number) shows how many parts we have.  
- The **denominator** (bottom number) shows how many equal parts the whole is divided into.

👉 Example:  
In the fraction $ \frac{3}{4} $:  
- 3 is the **numerator** (we have 3 parts)  
- 4 is the **denominator** (the whole is divided into 4 equal parts)

---

#### Visual Examples

**1. Pie Chart Representation**  
Imagine a pizza cut into 4 equal slices.

🍕🍕🍕🍕 → Whole pizza (4 out of 4 slices)

If you eat 1 slice:  
You have eaten $ \frac{1}{4} $ of the pizza.

🍕🍕🍕 😋 → $ \frac{3}{4} $ remains

**2. Number Line**  
Fractions can also be shown on a number line:

```
0        1/4       2/4       3/4        1
|---------|---------|---------|---------|
```

Each step represents one-quarter of the way from 0 to 1.

---

#### Common Fractions

| Fraction | Name           | Visual (Pie) |
|---------|----------------|--------------|
| $ \frac{1}{2} $ | One-half     | 🟨🟨 / 🟥🟥 (half filled) |
| $ \frac{1}{3} $ | One-third    | 🟦 / ⬜⬜ (1 out of 3 parts) |
| $ \frac{1}{4} $ | One-fourth   | 🟩 / ⬜⬜⬜ (1 out of 4 parts) |
