│                                                                              │
│  **Relevant Statutes:**                                                      │

│                                                                              │
│  **Recommendation:**                                                         │

│  across borders.                                                             │
│  - Include a **Data Processing Addendum (DPA)** if one party acts as a data  │

│                                                                              │
│  **Relevant Statutes:**                                                      │
│  - PIPL, Articles 38–40                                                      │

│  (effective 2022)                                                            │
│                                                                              │
│  **Recent Update:**                                                          │
│  As of January 2025, the CAC has increased enforcement scrutiny on data      │
│  exports involving sensitive personal information or large-scale             │
