│  holding platforms accountable not only for direct violations but also for   │
│  user experience designs that exploit cognitive vulnerabilities.             │

│  default privacy settings that are high by default for users under 18        │
│  (effective January 2025), signaling a shift toward broader youth            │

│  restrict monetization practices involving minors.                           │

│                                                                              │

│  AADC requires high privacy settings by default, bans the use of children’s  │
│  data for profiling, and prohibits designs that encourage extended use or    │
│  in-app spending.                                                            │
│                                                                              │
│  In 2023, the ICO issued enforcement notices to several gaming apps for      │

│  is directed at children, as long as it is accessible to them—making it      │
│  highly relevant for “gray area” apps.                                       │
│                                                                              │

│                                                                              │
│  2. **Default Privacy and Monetization Settings**: High privacy and low      │
│  monetization pressure should be the default for underage users. This        │

│                                                                              │
