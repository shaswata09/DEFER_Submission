│                                                                              │
│  The goal of linear regression is to find the best-fitting straight line     │

│  y = mx + b                                                                  │

│  - x is the value of the independent variable                                │

│  change in x)                                                                │
│  - b is the y-intercept (the value of y when x is 0)                         │
│                                                                              │
│  The "best-fit" line is determined by minimizing the sum of the squared      │
│  differences between the actual data points and the predicted values on the  │
│  line. These differences are called residuals, and minimizing them ensures   │
│  the line fits the data as closely as possible.                              │

│  ### **Concept Explanation: Linear Regression (Medium Detail)**              │
│                                                                              │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the outcome or response) and     │
│  one or more independent variables (also known as predictors or features).   │
│  In its simplest form—simple linear regression—it models the relationship    │
│  between two variables using a straight line.                                │
│                                                                              │
│  The regression line is described by the equation:                           │
│                                                                              │
│  $$                                                                          │
│  y = mx + b                                                                  │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $ y $ is the predicted value of the dependent variable (e.g., house       │
│  price),                                                                     │
│  - $ x $ is the value of the independent variable (e.g., house size),        │
│  - $ m $ is the **slope** of the line, representing how much $ y $ changes   │
│  for a one-unit increase in $ x $,                                           │
│  - $ b $ is the **y-intercept**, the value of $ y $ when $ x = 0 $.          │
│                                                                              │
│  The goal of linear regression is to find the **best-fit line**—the line     │
│  that minimizes the sum of the squared differences between the actual data   │
│  points and the predicted values. These differences are called               │
│  **residuals**, and minimizing them ensures the model makes the most         │
│  accurate predictions possible.                                              │
│                                                                              │
│  Linear regression is widely used for prediction and inference. For          │
│  example:                                                                    │
│  - Predicting house prices based on size                                     │
│  - Estimating sales based on advertising spend                               │
│  - Forecasting fuel costs based on distance traveled                         │
│                                                                              │
│  It assumes a linear relationship between variables and works best when      │
│  this assumption holds true.                                                 │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### **Practical Example: House Price Prediction**                           │
│                                                                              │
│  Suppose a model predicts house prices (in thousands of dollars) based on    │
│  size (in square feet) using the equation:                                   │
│                                                                              │
│  $$                                                                          │
│  \text{Price} = 0.15 \times \text{Size} + 50                                 │
│  $$                                                                          │
│                                                                              │
│  To predict the price of a 2000 sq ft house:                                 │
│  1. Plug in $ x = 2000 $:                                                    │
│     $$                                                                       │
│     y = 0.15 \times 2000 + 50                                                │
│     $$                                                                       │
│  2. Multiply:                                                                │
│     $$                                                                       │
│     y = 300 + 50                                                             │
│     $$                                                                       │
│  3. Add:                                                                     │
│     $$                                                                       │
│     y = 350                                                                  │
│     $$                                                                       │
│                                                                              │
│  So, the predicted price is **$350,000**.                                    │
│                                                                              │
│  This shows how linear regression turns real-world data into actionable      │
│  predictions.                                                                │

### **Concept Explanation: Linear Regression (Medium Detail)**

Linear regression is a statistical method used to model the relationship between a dependent variable (often called the outcome or response) and one or more independent variables (also known as predictors or features). In its simplest form—simple linear regression—it models the relationship between two variables using a straight line.

The regression line is described by the equation:

$$
y = mx + b
$$

Where:
- $ y $ is the predicted value of the dependent variable (e.g., house price),
- $ x $ is the value of the independent variable (e.g., house size),
- $ m $ is the **slope** of the line, representing how much $ y $ changes for a one-unit increase in $ x $,
- $ b $ is the **y-intercept**, the value of $ y $ when $ x = 0 $.

The goal of linear regression is to find the **best-fit line**—the line that minimizes the sum of the squared differences between the actual data points and the predicted values. These differences are called **residuals**, and minimizing them ensures the model makes the most accurate predictions possible.

Linear regression is widely used for prediction and inference. For example:
- Predicting house prices based on size
- Estimating sales based on advertising spend
- Forecasting fuel costs based on distance traveled

It assumes a linear relationship between variables and works best when this assumption holds true.

---

### **Practical Example: House Price Prediction**

Suppose a model predicts house prices (in thousands of dollars) based on size (in square feet) using the equation:

$$
\text{Price} = 0.15 \times \text{Size} + 50
$$

To predict the price of a 2000 sq ft house:
1. Plug in $ x = 2000 $:
   $$
   y = 0.15 \times 2000 + 50
   $$
2. Multiply:
   $$
   y = 300 + 50
   $$
3. Add:
   $$
   y = 350
   $$

So, the predicted price is **$350,000**.

This shows how linear regression turns real-world data into actionable predictions.
