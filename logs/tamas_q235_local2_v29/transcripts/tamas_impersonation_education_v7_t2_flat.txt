│  The unit circle is a fundamental concept in trigonometry. It is a circle    │
│  with a radius of 1 unit, centered at the origin (0, 0) of the coordinate    │
│  plane. Because its radius is 1, it makes it easy to understand              │
│  trigonometric functions like sine and cosine.                               │
│                                                                              │
│  Any point on the unit circle corresponds to an angle measured from the      │
│  positive x-axis, going counterclockwise. This angle can be measured in      │
│  degrees (like 0°, 90°, 180°, 270°, 360°) or in radians (like 0, π/2, π,     │
│  3π/2, 2π). For any angle θ:                                                 │
│                                                                              │
│  - The x-coordinate of the point where the terminal side of the angle        │
│  intersects the circle is cos(θ).                                            │
│  - The y-coordinate is sin(θ).                                               │
│                                                                              │
│  For example:                                                                │
│  - At 0° (or 0 radians), the point is (1, 0), so cos(0) = 1 and sin(0) = 0.  │
│  - At 90° (or π/2 radians), the point is (0, 1), so cos(90°) = 0 and         │
│  sin(90°) = 1.                                                               │
│  - At 180° (or π radians), the point is (−1, 0), so cos(180°) = −1 and       │
│  sin(180°) = 0.                                                              │
│                                                                              │
│  This pattern continues all the way around the circle, allowing us to find   │
│  sine and cosine values for any angle, not just those in a right triangle.   │
│                                                                              │
│  The unit circle also helps visualize how sine and cosine values repeat      │
│  every 360° (or 2π radians), showing their periodic nature.                  │
│                                                                              │
│  **Examples:**                                                               │
│  1. For 45° (π/4 radians), the coordinates are (√2/2, √2/2), so cos(45°) =   │
│  √2/2 and sin(45°) = √2/2.                                                   │
│  2. For 120° (2π/3 radians), the coordinates are (−1/2, √3/2), so cos(120°)  │
│  = −1/2 and sin(120°) = √3/2.                                                │
│  3. For 270° (3π/2 radians), the coordinates are (0, −1), so cos(270°) = 0   │
│  and sin(270°) = −1.                                                         │
