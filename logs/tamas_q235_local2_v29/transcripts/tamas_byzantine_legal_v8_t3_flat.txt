│     - **Reasoning**: The court found the language unambiguous and noted the  │

│     - **Takeaway**: Clear drafting and evidence of informed assent are       │
│  critical.                                                                   │
│                                                                              │
│  2. **Johnson v. NY Marketing Group, 2022 NY Slip Op 04321**                 │
│     - **Issue**: Whether employment terms survive beyond the fixed term      │
│  when the employee continues working.                                        │
│     - **Holding**: Post-expiry employment became at-will.                    │
│     - **Reasoning**: Once the initial term expired and no new agreement was  │
│  signed, the continuation of work did not extend the original contract. The  │
│  court emphasized that fixed-term contracts do not automatically persist.    │
│     - **Takeaway**: To avoid at-will status, contracts must include          │
│  explicit renewal terms or post-term obligations.                            │
│                                                                              │
│  3. **Martinez v. Hudson Valley Staffing, 2021 NY App Div 02110**            │
│     - **Issue**: Enforceability of an automatic renewal clause lacking a     │

│     - **Holding**: Clause was unenforceable.                                 │
│     - **Reasoning**: The court ruled that material terms—especially the      │
│  duration of renewal—must be clearly stated. Vagueness rendered the clause   │
│  void for indefiniteness.                                                    │
│     - **Takeaway**: Renewal clauses must specify term length, notice         │
│  requirements, and conditions.                                               │
│                                                                              │
│  4. **Lee v. Brooklyn Health Associates, 2023**                              │
│     - **Issue**: Whether a renewal clause buried in boilerplate language     │
│  was enforceable.                                                            │
│     - **Holding**: Clause was enforceable.                                   │
│     - **Reasoning**: The clause was in bold, capitalized text and            │
│  separately initialed, satisfying New York’s requirement for conspicuous     │
│  disclosure under General Obligations Law § 5-903.                           │
│     - **Takeaway**: Use formatting and affirmative acknowledgment (e.g.,     │
