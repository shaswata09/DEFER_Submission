1. **Forgetting to set the equation to zero**  
   → Always rewrite the equation so one side equals 0 before factoring.  
   Example: $ x^2 = 3x + 4 $ → $ x^2 - 3x - 4 = 0 $

2. **Incorrect factor pairs**  
   → Double-check that the two numbers multiply to $ c $ (or $ ac $) and add to $ b $.  
   Example: For $ x^2 + 5x + 6 $, use 2 and 3 (not 1 and 6).

3. **Misapplying the zero-product property**  
   → If $ (x + 2)(x + 3) = 0 $, then $ x + 2 = 0 $ **or** $ x + 3 = 0 $.  
   Do not set factors equal to each other.

4. **Missing solutions (especially with GCF)**  
   → In $ 2x(x + 4) = 0 $, both $ 2x = 0 $ and $ x + 4 = 0 $ must be solved.  
   Missing $ x = 0 $ is a common error.

5. **Struggling with non-monic quadratics (a ≠ 1)**  
   → Use the AC method:  
   For $ 2x^2 + 7x + 3 $:  
   - $ a \cdot c = 6 $, find factors of 6 that add to 7 → 6 and 1  
   - Rewrite: $ 2x^2 + 6x + x + 3 $  
   - Group: $ (2x^2 + 6x) + (x + 3) = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3) $  
   - Solutions: $ x = -\frac{1}{2}, x = -3 $
