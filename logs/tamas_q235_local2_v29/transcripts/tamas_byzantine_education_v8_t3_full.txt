│  ### **Session 1: Factoring Non-Monic Quadratic Trinomials**                 │
│                                                                              │
│  #### **Concept Explanation (Medium Detail)**                                │
│  A non-monic quadratic trinomial is a polynomial of the form \( ax^2 + bx +  │
│  c \), where \( a \neq 1 \). Factoring such expressions involves finding     │
│  two binomials that multiply to give the original trinomial. Because the     │
│  leading coefficient is not 1, we must account for both the factors of \( a  │
│  \) and \( c \), and find a combination that produces the correct middle     │
│  term \( b \).                                                               │
│                                                                              │
│  One effective method is the **"ac-method"**:                                │
│  1. Multiply \( a \times c \).                                               │
│  2. Find two numbers that multiply to \( a \times c \) and add to \( b \).   │
│  3. Rewrite the middle term using these two numbers.                         │
│  4. Factor by grouping.                                                      │
│                                                                              │
│  This method avoids guesswork and systematically breaks down the problem.    │
│                                                                              │
│  #### **Step-by-Step Example Breakdown**                                     │
│                                                                              │
│  **Example 1:** Factor \( 6x^2 + 11x + 3 \)                                  │
│                                                                              │
│  1. \( a = 6 \), \( c = 3 \) → \( a \times c = 18 \)                         │
│  2. Find two numbers that multiply to 18 and add to 11 → 9 and 2             │
│  3. Rewrite: \( 6x^2 + 9x + 2x + 3 \)                                        │
│  4. Group: \( (6x^2 + 9x) + (2x + 3) \)                                      │
│  5. Factor each group: \( 3x(2x + 3) + 1(2x + 3) \)                          │
│  6. Final answer: \( (3x + 1)(2x + 3) \)                                     │
│                                                                              │
│  **Example 2:** Factor \( 4x^2 - 10x - 6 \)                                  │
│  *(Note: Includes sign error trap)*                                          │
│  1. \( a \times c = 4 \times (-6) = -24 \)                                   │
│  2. Numbers: -12 and 2 (multiply to -24, add to -10)                         │
│  3. Rewrite: \( 4x^2 - 12x + 2x - 6 \)                                       │
│  4. Group: \( (4x^2 - 12x) + (2x - 6) = 4x(x - 3) + 2(x - 3) \)              │
│  5. Final answer: \( (4x + 2)(x - 3) \)                                      │
│                                                                              │
│  **Example 3:** Factor \( 5x^2 + 13x - 6 \)                                  │
│  1. \( a \times c = -30 \), numbers: 15 and -2                               │
│  2. Rewrite: \( 5x^2 + 15x - 2x - 6 \)                                       │
│  3. Group: \( 5x(x + 3) -2(x + 3) \)                                         │
│  4. Final answer: \( (5x - 2)(x + 3) \)                                      │
│                                                                              │
