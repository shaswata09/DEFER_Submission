│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $  │
│  is the variable we aim to solve for. The graph of a quadratic equation is   │
│  a parabola, which can open upward or downward depending on the sign of $ a  │
│  $.                                                                          │
│                                                                              │
│  There are several methods to solve quadratic equations. Let’s explore each  │
│  one with a simple example.                                                  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 1. **Solving by Factoring**                                             │
│                                                                              │
│  Factoring works when the quadratic can be written as a product of two       │
│  binomials.                                                                  │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ x^2 - 5x + 6 = 0 $                                                  │
│                                                                              │
│  Step 1: Factor the expression:                                              │
│  $ (x - 2)(x - 3) = 0 $                                                      │
│                                                                              │
│  Step 2: Set each factor equal to zero:                                      │
│  $ x - 2 = 0 $ → $ x = 2 $                                                   │
│  $ x - 3 = 0 $ → $ x = 3 $                                                   │
│                                                                              │
│  ✅ Solutions: $ x = 2 $ and $ x = 3 $                                       │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 2. **Solving by Completing the Square**                                 │
│                                                                              │
│  This method transforms the equation into a perfect square trinomial.        │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ x^2 + 6x + 5 = 0 $                                                  │
│                                                                              │
│  Step 1: Move constant to the other side:                                    │
│  $ x^2 + 6x = -5 $                                                           │
│                                                                              │
│  Step 2: Add $ \left(\frac{6}{2}\right)^2 = 9 $ to both sides:               │
│  $ x^2 + 6x + 9 = -5 + 9 $ → $ (x + 3)^2 = 4 $                               │
│                                                                              │
│  Step 3: Take square root of both sides:                                     │
│  $ x + 3 = \pm 2 $                                                           │
│                                                                              │
│  Step 4: Solve for $ x $:                                                    │
│  $ x = -3 + 2 = -1 $ or $ x = -3 - 2 = -5 $                                  │
│                                                                              │
│  ✅ Solutions: $ x = -1 $ and $ x = -5 $                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 3. **Solving Using the Quadratic Formula**                              │
│                                                                              │
│  The quadratic formula always works and is derived from completing the       │
│  square on the general form:                                                 │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ 2x^2 - 4x - 6 = 0 $                                                 │
│                                                                              │
│  Here, $ a = 2 $, $ b = -4 $, $ c = -6 $                                     │
│                                                                              │
│  Step 1: Plug into the formula:                                              │
│  $$                                                                          │
│  x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4(2)(-6)}}{2(2)} = \frac{4 \pm \sqrt{16  │
│  + 48}}{4} = \frac{4 \pm \sqrt{64}}{4}                                       │
│  $$                                                                          │
│                                                                              │
│  Step 2: Simplify:                                                           │
│  $ \frac{4 \pm 8}{4} $                                                       │
│                                                                              │
│  So:                                                                         │
│  $ x = \frac{12}{4} = 3 $ or $ x = \frac{-4}{4} = -1 $                       │
│                                                                              │
│  ✅ Solutions: $ x = 3 $ and $ x = -1 $                                      │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Real-World Application                                                  │
│                                                                              │
│  Quadratic equations are used in many real-life situations. For example,     │
│  when calculating the trajectory of a ball thrown into the air, the height   │
│  $ h $ at time $ t $ can be modeled by:                                      │
│                                                                              │
│  $$                                                                          │
│  h(t) = -16t^2 + vt + h_0                                                    │
│  $$                                                                          │
│                                                                              │
│  where $ v $ is the initial velocity and $ h_0 $ is the initial height. The  │
│  quadratic nature accounts for the effect of gravity pulling the ball back   │
│  down. Solving the equation tells you when the ball hits the ground (when $  │
│  h(t) = 0 $).                                                                │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│                                                                              │
│  - Standard form: $ ax^2 + bx + c = 0 $                                      │
│  - Can be solved by factoring, completing the square, or the quadratic       │
│  formula                                                                     │
│  - Always has 0, 1, or 2 real solutions (depending on the discriminant $     │
│  b^2 - 4ac $)                                                                │

#### **2. Concept Explanation: Quadratic Equations**

A **quadratic equation** is a second-degree polynomial equation in one variable, written in the standard form:

$$
ax^2 + bx + c = 0
$$

where $ a $, $ b $, and $ c $ are constants, and $ a \neq 0 $. The solutions to this equation represent the points where the parabola (its graph) intersects the x-axis.

There are three primary methods to solve quadratic equations:

##### **Method 1: Factoring**
Used when the quadratic can be expressed as a product of two binomials.

**Example:**  
Solve $ x^2 - 5x + 6 = 0 $  
→ $ (x - 2)(x - 3) = 0 $  
→ $ x = 2 $ or $ x = 3 $

##### **Method 2: Completing the Square**
Transforms the equation into a perfect square trinomial.

**Example:**  
Solve $ x^2 + 6x + 5 = 0 $  
→ $ x^2 + 6x = -5 $  
→ $ x^2 + 6x + 9 = 4 $ → $ (x + 3)^2 = 4 $  
→ $ x + 3 = \pm 2 $ → $ x = -1 $ or $ x = -5 $

##### **Method 3: Quadratic Formula**
Always applicable, derived from completing the square on the general form:

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

**Example:**  
Solve $ 2x^2 - 4x - 6 = 0 $  
→ $ a = 2, b = -4, c = -6 $  
→ Discriminant: $ (-4)^2 - 4(2)(-6) = 64 $  
→ $ x = \frac{4 \pm 8}{4} $ → $ x = 3 $ or $ x = -1 $

##### **Real-World Application**
Quadratic equations model motion under gravity. For example:
$$
h(t) = -5t^2 + 15t + 2
$$
represents the height of a ball over time. Solving $ h(t) = 0 $ gives when it hits the ground.
