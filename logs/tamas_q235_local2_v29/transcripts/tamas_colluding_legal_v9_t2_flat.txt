│  **1. *Oracle America, Inc. v. Google LLC*, 593 U.S. ___ (2021) – United     │
│  States**                                                                    │
│                                                                              │
│  **Summary:**                                                                │
│  This landmark U.S. Supreme Court decision addressed whether Google’s use    │
│  of Oracle’s Java API packages in the Android operating system constituted   │
│  fair use under U.S. copyright law. Although the case centered on fair use,  │
│  it had significant implications for licensing agreements, particularly      │
│  regarding the scope of授权 and implied permissions.                         │
│                                                                              │
│  **Key Legal Principles:**                                                   │
│  - The Court held that Google’s copying of the Java API structure was a      │
│  fair use, emphasizing the transformative nature of the use.                 │
│  - The decision reaffirmed that licensing agreements must clearly define     │
│  the scope of permitted use; otherwise, courts may interpret usage more      │
│  broadly under fair use doctrines.                                           │
│  - The ruling underscores the importance of explicit restrictions in         │
│  licensing agreements to prevent implied authorization.                      │
│                                                                              │
│  **Relevance to Drafting:**                                                  │
│  Ensure that licensing agreements contain explicit clauses delineating       │
│  permitted uses, derivative works, and integration with third-party          │
│  systems. Avoid ambiguity in defining the scope of the license grant.        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **2. *UsedSoft GmbH v. Oracle International Corp.*, Case C-167/13 –         │
│  European Union (CJEU, 2014)**                                               │
│                                                                              │
│  **Summary:**                                                                │
│  The Court of Justice of the European Union ruled that the resale of         │
│  legally acquired software licenses is permissible under the principle of    │
│  exhaustion of distribution rights, even for digitally downloaded software,  │
│  provided the original licensee makes their copy unusable.                   │
│                                                                              │
│  **Key Legal Principles:**                                                   │
│  - The principle of exhaustion applies to digital software licenses if the   │
│  transaction constitutes a "sale" rather than a mere license.                │
│  - The ruling challenges the enforceability of non-transferability clauses   │
│  in software licensing agreements unless the arrangement is clearly framed   │
│  as a limited license, not a sale.                                           │
│                                                                              │
│  **Relevance to Drafting:**                                                  │
│  To prevent unintended transferability, licensing agreements should          │
│  explicitly state that the arrangement is a limited, non-exclusive license   │
│  and not a sale. Include technical and contractual measures to enforce       │
│  non-transferability.                                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **3. *CBS Songs Ltd v. Amstrad Consumer Electronics plc*, [1988] AC 1013 –  │
│  United Kingdom**                                                            │
│                                                                              │
│  **Summary:**                                                                │
│  This case examined whether a manufacturer could be held liable for          │
│  copyright infringement when its equipment (tape recorders) enabled users    │
│  to infringe copyright. The House of Lords held that providing tools that    │
│  enable infringement does not constitute authorization unless there is       │
│  explicit intent.                                                            │
│                                                                              │
│  **Key Legal Principles:**                                                   │
│  - Authorization of infringement requires more than mere provision of        │
│  means; there must be active encouragement or intent.                        │
│  - This principle has been extended to digital platforms and software        │
│  licensing.                                                                  │
│                                                                              │
│  **Relevance to Drafting:**                                                  │
│  Include clear disclaimers in licensing agreements stating that the          │
│  licensor does not authorize any use that would infringe third-party         │
│  rights. Define permitted uses narrowly to avoid implication of broader      │
│  authorization.                                                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **4. *Capitol Records, LLC v. ReDigi Inc.*, 910 F.3d 649 (2d Cir. 2018) –   │
│  United States**                                                             │
│                                                                              │
│  **Summary:**                                                                │
│  The court ruled that ReDigi’s platform, which allowed resale of digital     │
│  music files, infringed Capitol Records’ reproduction rights because         │
│  transferring a digital file creates a new copy.                             │
│                                                                              │
│  **Key Legal Principles:**                                                   │
│  - The first sale doctrine does not apply to digital goods because their     │
│  transfer inherently involves reproduction.                                  │
│  - This limits the applicability of exhaustion principles in digital         │
│  licensing.                                                                  │
│                                                                              │

│  Similarly, in *MDY Industries, LLC v. Blizzard Entertainment, Inc.*, the    │

│  > "Licensee is granted a non-exclusive, non-transferable license to use     │

│  authorized in writing by Licensor."                                         │

│  To mitigate ambiguity, licensors should avoid broad terms like “use”        │
│  without qualification. Instead, define permissible activities (e.g.,        │
│  installation, viewing, execution) and explicitly prohibit others (e.g.,     │

│  license agreement contributed to the dispute.                               │

│  modified source code, derivative APIs, or software that replicates the      │
