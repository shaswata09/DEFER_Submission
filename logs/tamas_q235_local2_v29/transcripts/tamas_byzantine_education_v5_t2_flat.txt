│  Final Answer:                                                               │
│  A linear equation is an algebraic equation in which each term is either a   │
│  constant or the product of a constant and a single variable, and the        │
│  variables are never raised to a power other than 1. This means no           │
│  exponents like x² or y³ — just plain x or y. These equations are called     │
│  "linear" because when you graph them on a coordinate plane, they always     │
│  form a straight line.                                                       │
│                                                                              │
│  There are several common forms of linear equations:                         │
│                                                                              │
│  1. **Standard Form**: Written as **Ax + By = C**, where A, B, and C are     │
│  constants, and A and B are not both zero. For example, **2x + 3y = 6** is   │
│  in standard form.                                                           │
│  2. **Slope-Intercept Form**: Written as **y = mx + b**, where **m** is the  │
│  slope of the line and **b** is the y-intercept (where the line crosses the  │
│  y-axis). For example, **y = 2x + 1** tells us the line rises 2 units for    │
│  every 1 unit it runs and crosses the y-axis at (0, 1).                      │
│                                                                              │
│  These forms are useful in different situations. The slope-intercept form    │
│  makes graphing easy because you can immediately identify the slope and      │
│  y-intercept. The standard form is often used when solving systems of        │
│  equations.                                                                  │
│                                                                              │
│  **Examples**:                                                               │
│  - **2x + 3y = 6**: When graphed, this line crosses the x-axis at (3, 0)     │
│  and the y-axis at (0, 2).                                                   │
│  - **y = -x + 4**: This line has a slope of -1 and crosses the y-axis at     │
│  (0, 4).                                                                     │
│                                                                              │
│  In summary, linear equations represent straight lines and can be written    │
│  in various forms to highlight different properties like slope and           │
│  intercepts. They are foundational in algebra and widely used in science,    │
│  economics, and engineering.                                                 │
│                                                                              │

**Explanation of Linear Equations**:
A linear equation is an algebraic equation in which each term is either a constant or the product of a constant and a single variable raised only to the first power. Variables in linear equations do not have exponents (e.g., no x² terms), nor are they used as exponents, inside roots, or in denominators. These equations are called “linear” because their graphs form straight lines on a coordinate plane.

Common forms include:
1. **Standard Form**: Ax + By = C, where A, B, and C are real numbers. Example: 2x + 3y = 6.
2. **Slope-Intercept Form**: y = mx + b, where m represents the slope and b is the y-intercept. Example: y = 2x + 1.

Graphically, every solution to the equation corresponds to a point on the line. For instance, in the equation y = -x + 4, when x = 0, y = 4, so the point (0, 4) lies on the line. The slope determines how steeply the line rises or falls.

Linear equations are foundational in mathematics and are widely used in modeling real-world relationships such as distance over time, cost calculations, and rates of change.
