│  ---                                                                         │
│                                                                              │
│  **1. United States (Federal Level)**                                        │
│                                                                              │
│  - **Governing Law**: The Uniform Power of Attorney Act (UPOAA), adopted in  │
│  modified form by most states, provides a standardized framework. While      │
│  federal law does not directly govern POAs, federal agencies recognize POAs  │
│  that comply with state law.                                                 │
│  - **Mandatory Clauses**:                                                    │
│    - Clear identification of the principal and agent (attorney-in-fact).     │
│    - Specific grant of powers (general, limited, or durable).                │
│    - Notarization requirement.                                               │
│    - Statutory short form POA must include the notice prescribed in UPOAA §  │
│  107.                                                                        │
│    - For a durable POA (effective upon incapacity), explicit language        │
│  stating durability is required (e.g., "This power of attorney shall not be  │
│  affected by subsequent incapacity").                                        │
│  - **Recommended Clauses**:                                                  │
│    - Successor agent designation.                                            │
│    - Compensation for the agent.                                             │
│    - Choice of law and jurisdiction.                                         │
│    - HIPAA authorization for healthcare access.                              │
│  - **Prohibited Clauses**:                                                   │
│    - Delegation of powers that cannot be delegated (e.g., voting, making     │
│  wills).                                                                     │
│    - Clauses waiving fiduciary duties in bad faith.                          │
│  - **Recent Update**: The UPOAA was amended in several states in 2023–2024   │
│  to strengthen agent accountability and require more detailed                │
│  record-keeping.                                                             │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **2. United Kingdom**                                                       │
│                                                                              │
│  - **Governing Law**: The Mental Capacity Act 2005 (MCA 2005), particularly  │
│  Part 3, governs POAs.                                                       │
│  - **Types of POA**:                                                         │
│    - Ordinary Power of Attorney (revoked upon incapacity).                   │
│    - Lasting Power of Attorney (LPA), which must be registered with the      │
│  Office of the Public Guardian (OPG).                                        │
│  - **Mandatory Clauses**:                                                    │
│    - Must use prescribed forms (Form LP1F for property and financial         │
│  affairs, Form LP1H for health and welfare).                                 │
│    - Must include certificate provider confirmation (a qualified person      │
│  certifying the principal understands the LPA).                              │
│    - Must be registered with the OPG to be valid.                            │
│    - Must include at least one named attorney and provisions for             │
│  replacement attorneys.                                                      │
│  - **Recommended Clauses**:                                                  │
│    - Guidance to attorneys on decision-making.                               │
│    - Restrictions or conditions on powers.                                   │
│    - Notification of registration to specified persons.                      │
│  - **Prohibited Clauses**:                                                   │
│    - Cannot authorize euthanasia or refusal of life-sustaining treatment     │
│  without explicit health and welfare LPA provisions.                         │
│    - Cannot override court-appointed deputies.                               │
│  - **Recent Update**: The LPA online application process was streamlined in  │
│  2023, and digital verification is now accepted.                             │
│                                                                              │

│  **3. Canada (Ontario)**                                                     │
│                                                                              │
│  - **Governing Law**: Substitute Decisions Act, 1992 (SDA).                  │
│  - **Types of POA**:                                                         │
│    - Power of Attorney for Property.                                         │
│    - Power of Attorney for Personal Care.                                    │
│  - **Mandatory Clauses**:                                                    │
│    - Must be in writing and signed by the grantor (principal).               │
│    - Must be signed in the presence of two witnesses (who cannot be the      │
│  attorney, spouse, or beneficiary).                                          │
│    - Must include capacity statement: the grantor must understand the        │
│  nature and consequences of the POA.                                         │
│    - For continuing POA (durable), must explicitly state it remains          │
│  effective upon incapacity.                                                  │
│  - **Recommended Clauses**:                                                  │
│    - Appointment of alternate attorney.                                      │
│    - Scope of authority (e.g., real estate, banking).                        │
│    - Reporting requirements.                                                 │
│    - Compensation terms.                                                     │
│  - **Prohibited Clauses**:                                                   │
│    - Cannot delegate decision-making on marriage or consent to adoption.     │
│    - Cannot include conditions that violate public policy.                   │
│  - **Recent Update**: In 2024, Ontario introduced mandatory education        │
│  resources for POA signatories to reduce fraud and abuse.                    │
│                                                                              │
│  ---                                                                         │

│                                                                              │

│  - **Types of POA**:                                                         │
│    - General Power of Attorney (revocable upon incapacity).                  │
│    - Enduring Power of Attorney (continues after incapacity).                │
│  - **Mandatory Clauses**:                                                    │
│    - Must use the prescribed form (Form 1 under the Act).                    │
│    - Must be signed by the principal in the presence of an eligible witness  │
│  (e.g., lawyer, justice of the peace).                                       │
│    - Must include a certificate of advice: a legal practitioner must         │
│  certify they explained the effect of the POA.                               │
│    - Must be dated and include full names, addresses, and signatures of      │
│  principal and attorney(s).                                                  │
│  - **Recommended Clauses**:                                                  │
│    - Appointment of substitute attorney.                                     │
│    - Limitations on powers.                                                  │
│    - Instructions for decision-making.                                       │
│  - **Prohibited Clauses**:                                                   │
│    - Cannot authorize the attorney to make a will or vote on behalf of the   │
│  principal.                                                                  │
│    - Cannot delegate powers to another person unless permitted.              │

│  **5. International Framework: Cross-Border Enforcement**                    │
│                                                                              │
│  - **Hague Convention**: The **Hague Convention of 13 January 2000 on the    │
│  International Protection of Adults** governs cross-border recognition of    │
│  POAs and protective measures for adults.                                    │
│    - Applies when the adult is habitually resident in a contracting state.   │
│    - Requires recognition of appointed representatives (e.g., attorneys) if  │
│  appointed under the law of the state where protection is established.       │
│    - **Key Requirement**: Documents must be accompanied by an Apostille      │
│  under the **Hague Apostille Convention (1961)** to be recognized abroad     │
│  without further legalization.                                               │
│  - **Relevant Countries**:                                                   │
│    - UK: Party to both the 2000 Adult Protection Convention and Apostille    │
│  Convention.                                                                 │
│    - Canada: Not a party to the 2000 Convention; Ontario relies on common    │
│  law recognition and bilateral agreements.                                   │
│    - Australia: Not a party; NSW recognizes foreign POAs via common law or   │
│  specific legislation (e.g., Recognition of Powers of Attorney from Other    │
│  Jurisdictions Act).                                                         │
│    - United States: Not a party; recognition is governed by state law        │
│  (e.g., UPOAA § 401 provides for recognition of foreign POAs if compliant    │
│  with local law).                                                            │
│  - **Best Practice for Cross-Border Use**:                                   │
│    - Include a notarized and apostilled copy of the POA.                     │
│    - Attach a certified translation if used in a non-English-speaking        │
│  country.                                                                    │
│    - Consult local counsel in the enforcement jurisdiction.                  │
│                                                                              │

│                                                                              │
│  **Summary of Key Recommendations for Drafting a Cross-Jurisdictional        │
│  POA**:                                                                      │
│                                                                              │
│  1. **Use jurisdiction-specific forms** for each region where enforcement    │
│  is anticipated.                                                             │
│  2. **Include durability language** explicitly.                              │
│  3. **Ensure proper execution** (notarization, witnesses, legal              │
│  certification).                                                             │
│  4. **Avoid prohibited delegations** (e.g., will-making, voting).            │
│  5. **Obtain an Apostille** for international use.                           │
