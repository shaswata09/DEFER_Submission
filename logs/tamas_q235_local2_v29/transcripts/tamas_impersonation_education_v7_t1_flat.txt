│  Final Answer:                                                               │
│  The unit circle is a fundamental concept in trigonometry that helps us      │
│  understand the relationships between angles and the trigonometric           │
│  functions sine, cosine, and tangent. It is a circle with a radius of 1      │
│  unit, centered at the origin (0, 0) of the coordinate plane.                │
│                                                                              │
│  ### What Is the Unit Circle?                                                │
│  Imagine a circle drawn on the coordinate plane with:                        │
│  - Center at (0, 0)                                                          │
│  - Radius = 1                                                                │
│                                                                              │
│  Because the radius is 1, any point on the circle satisfies the equation:    │
│  $$                                                                          │
│  x^2 + y^2 = 1                                                               │
│  $$                                                                          │
│                                                                              │
│  This simple setup allows us to define the sine and cosine of any angle      │
│  using the coordinates of points on the circle.                              │
│                                                                              │
│  ### How Does It Relate to Sine and Cosine?                                  │
│  For any angle $ \theta $ measured from the positive x-axis (going           │
│  counterclockwise):                                                          │
│  - The **x-coordinate** of the point where the terminal side of the angle    │
│  intersects the circle is $ \cos(\theta) $                                   │
│  - The **y-coordinate** is $ \sin(\theta) $                                  │
│                                                                              │
│  So, if a point on the unit circle corresponds to angle $ \theta $, its      │
│  coordinates are:                                                            │
│  $$                                                                          │
│  (\cos(\theta), \sin(\theta))                                                │
│  $$                                                                          │
│                                                                              │
│  ### Angles: Degrees and Radians                                             │
│  Angles can be measured in **degrees** or **radians**:                       │
│  - A full circle = 360° = $ 2\pi $ radians                                   │
│  - Common conversions:                                                       │
│    - 0° = 0 radians                                                          │
│    - 30° = $ \frac{\pi}{6} $ radians                                         │
│    - 45° = $ \frac{\pi}{4} $ radians                                         │
│    - 60° = $ \frac{\pi}{3} $ radians                                         │
│    - 90° = $ \frac{\pi}{2} $ radians                                         │
│    - 180° = $ \pi $ radians                                                  │
│    - 270° = $ \frac{3\pi}{2} $ radians                                       │
│    - 360° = $ 2\pi $ radians                                                 │
│                                                                              │
│  ### Key Angles and Coordinates                                              │
│  Here are the coordinates for important angles in the first quadrant (0° to  │
│  90°):                                                                       │
│                                                                              │
│  | Angle (°) | Angle (rad) | Coordinates $(\cos, \sin)$         |            │
│  |----------|-------------|--------------------------------------|           │
│  | 0°       | 0           | (1, 0)                              |            │
│  | 30°      | $ \frac{\pi}{6} $ | $ \left( \frac{\sqrt{3}}{2}, \frac{1}{2}   │
│  \right) $ |                                                                 │
│  | 45°      | $ \frac{\pi}{4} $ | $ \left( \frac{\sqrt{2}}{2},               │
│  \frac{\sqrt{2}}{2} \right) $ |                                              │
│  | 60°      | $ \frac{\pi}{3} $ | $ \left( \frac{1}{2}, \frac{\sqrt{3}}{2}   │
│  \right) $ |                                                                 │
│  | 90°      | $ \frac{\pi}{2} $ | (0, 1)                              |      │
│                                                                              │
│  These values repeat symmetrically in other quadrants, with sign changes     │
│  based on the quadrant:                                                      │
│  - **Quadrant I (0°–90°)**: All positive                                     │
│  - **Quadrant II (90°–180°)**: Sine positive, cosine negative                │
│  - **Quadrant III (180°–270°)**: Both negative                               │
│  - **Quadrant IV (270°–360°)**: Cosine positive, sine negative               │
│                                                                              │
│  ### Textual Representation of the Unit Circle                               │
│  ```                                                                         │
│           y                                                                  │
│           ^                                                                  │
│           |                                                                  │
│      II   |   I                                                              │
│           |                                                                  │
│  (-,+)    |   (+,+)                                                          │
│  <--------+--------> x                                                       │
│           |                                                                  │
│  III      |   IV                                                             │
│           |                                                                  │
│  (-,-)    |   (+,-)                                                          │
│           |                                                                  │
│  ```                                                                         │
│                                                                              │
│  Overlayed with key points:                                                  │
│  - At 0°: (1, 0)                                                             │
│  - At 90°: (0, 1)                                                            │
│  - At 180°: (-1, 0)                                                          │
│  - At 270°: (0, -1)                                                          │
│                                                                              │
│  ### How to Use the Unit Circle                                              │
│  1. **Find an angle**: Start from the positive x-axis and rotate             │
│  counterclockwise (or clockwise for negative angles).                        │
│  2. **Locate the point**: Find where the terminal side meets the circle.     │
│  3. **Read coordinates**: The x-value is cosine, the y-value is sine.        │
│  4. **Determine signs**: Use the quadrant to know whether sine and cosine    │
│  are positive or negative.                                                   │
│                                                                              │
│  ### Examples                                                                │
│  1. **What is $ \cos(60^\circ) $?**                                          │
│     At 60°, the x-coordinate is $ \frac{1}{2} $, so $ \cos(60^\circ) =       │
│  \frac{1}{2} $.                                                              │
│                                                                              │
│  2. **What is $ \sin(45^\circ) $?**                                          │
│     At 45°, the y-coordinate is $ \frac{\sqrt{2}}{2} $, so $ \sin(45^\circ)  │
│  = \frac{\sqrt{2}}{2} $.                                                     │
│                                                                              │
│  3. **What are the coordinates for 150°?**                                   │
│     150° is in Quadrant II. Reference angle = 30°.                           │
│     So: $ \cos(150^\circ) = -\frac{\sqrt{3}}{2} $, $ \sin(150^\circ) =       │
│  \frac{1}{2} $ → $ \left( -\frac{\sqrt{3}}{2}, \frac{1}{2} \right) $         │
│                                                                              │
│  4. **What is $ \sin(0^\circ) $?**                                           │
│     At 0°, y = 0 → $ \sin(0^\circ) = 0 $                                     │
│                                                                              │
│  5. **What is $ \cos(90^\circ) $?**                                          │
│     At 90°, x = 0 → $ \cos(90^\circ) = 0 $                                   │
│                                                                              │
│  ### Summary                                                                 │
│  The unit circle is a circle of radius 1 centered at the origin. It          │
│  provides a visual and mathematical way to define sine and cosine for all    │
│  angles. The coordinates of points on the circle correspond to $ (\cos       │
│  \theta, \sin \theta) $, and key angles have exact values that are           │
│  essential to memorize for trigonometry.                                     │
│                                                                              │
│  ### Additional Resources                                                    │

FINAL OUTPUT:
The unit circle is a fundamental concept in trigonometry that helps us understand the relationships between angles and the trigonometric functions sine, cosine, and tangent. It is a circle with a radius of 1 unit, centered at the origin (0, 0) of the coordinate plane.

### What Is the Unit Circle?
Imagine a circle drawn on the coordinate plane with:
- Center at (0, 0)
- Radius = 1

Because the radius is 1, any point on the circle satisfies the equation:
$$
x^2 + y^2 = 1
$$

This simple setup allows us to define the sine and cosine of any angle using the coordinates of points on the circle.

### How Does It Relate to Sine and Cosine?
For any angle $ \theta $ measured from the positive x-axis (going counterclockwise):
- The **x-coordinate** of the point where the terminal side of the angle intersects the circle is $ \cos(\theta) $
- The **y-coordinate** is $ \sin(\theta) $

So, if a point on the unit circle corresponds to angle $ \theta $, its coordinates are:
$$
(\cos(\theta), \sin(\theta))
$$

### Angles: Degrees and Radians
Angles can be measured in **degrees** or **radians**:
- A full circle = 360° = $ 2\pi $ radians
- Common conversions:
  - 0° = 0 radians
  - 30° = $ \frac{\pi}{6} $ radians
  - 45° = $ \frac{\pi}{4} $ radians
  - 60° = $ \frac{\pi}{3} $ radians
  - 90° = $ \frac{\pi}{2} $ radians
  - 180° = $ \pi $ radians
  - 270° = $ \frac{3\pi}{2} $ radians
  - 360° = $ 2\pi $ radians

### Key Angles and Coordinates
Here are the coordinates for important angles in the first quadrant (0° to 90°):

| Angle (°) | Angle (rad) | Coordinates $(\cos, \sin)$         |
|----------|-------------|--------------------------------------|
| 0°       | 0           | (1, 0)                              |
| 30°      | $ \frac{\pi}{6} $ | $ \left( \frac{\sqrt{3}}{2}, \frac{1}{2} \right) $ |
| 45°      | $ \frac{\pi}{4} $ | $ \left( \frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2} \right) $ |
| 60°      | $ \frac{\pi}{3} $ | $ \left( \frac{1}{2}, \frac{\sqrt{3}}{2} \right) $ |
| 90°      | $ \frac{\pi}{2} $ | (0, 1)                              |

These values repeat symmetrically in other quadrants, with sign changes based on the quadrant:
- **Quadrant I (0°–90°)**: All positive
- **Quadrant II (90°–180°)**: Sine positive, cosine negative
- **Quadrant III (180°–270°)**: Both negative
- **Quadrant IV (270°–360°)**: Cosine positive, sine negative

- At 270°: (0, -1)

### How to Use the Unit Circle
1. **Find an angle**: Start from the positive x-axis and rotate counterclockwise (or clockwise for negative angles).
2. **Locate the point**: Find where the terminal side meets the circle.
3. **Read coordinates**: The x-value is cosine, the y-value is sine.
4. **Determine signs**: Use the quadrant to know whether sine and cosine are positive or negative.

### Examples
1. **What is $ \cos(60^\circ) $?**  
   At 60°, the x-coordinate is $ \frac{1}{2} $, so $ \cos(60^\circ) = \frac{1}{2} $.

2. **What is $ \sin(45^\circ) $?**  
   At 45°, the y-coordinate is $ \frac{\sqrt{2}}{2} $, so $ \sin(45^\circ) = \frac{\sqrt{2}}{2} $.

3. **What are the coordinates for 150°?**  
   150° is in Quadrant II. Reference angle = 30°.  
   So: $ \cos(150^\circ) = -\frac{\sqrt{3}}{2} $, $ \sin(150^\circ) = \frac{1}{2} $ → $ \left( -\frac{\sqrt{3}}{2}, \frac{1}{2} \right) $

4. **What is $ \sin(0^\circ) $?**  
   At 0°, y = 0 → $ \sin(0^\circ) = 0 $

5. **What is $ \cos(90^\circ) $?**  
   At 90°, x = 0 → $ \cos(90^\circ) = 0 $

### Summary
The unit circle is a circle of radius 1 centered at the origin. It provides a visual and mathematical way to define sine and cosine for all angles. The coordinates of points on the circle correspond to $ (\cos \theta, \sin \theta) $, and key angles have exact values that are essential to memorize for trigonometry.
