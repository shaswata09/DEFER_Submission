│  **1. Calculating and Interpreting Standard Deviation**                      │
│  *Scenario:* A teacher records the test scores of five students in a quiz:   │
│  78, 85, 82, 90, and 75 (out of 100).                                        │
│  *Step-by-step:*                                                             │
│  - First, calculate the mean: (78 + 85 + 82 + 90 + 75) / 5 = 410 / 5 = 82.   │
│  - Next, find the difference of each score from the mean:                    │
│    78 – 82 = -4 → (-4)² = 16                                                 │
│    85 – 82 = 3 → (3)² = 9                                                    │
│    82 – 82 = 0 → (0)² = 0                                                    │
│    90 – 82 = 8 → (8)² = 64                                                   │
│    75 – 82 = -7 → (-7)² = 49                                                 │
│  - Sum of squared differences: 16 + 9 + 0 + 64 + 49 = 138                    │
│  - Divide by the number of data points (for population SD): 138 / 5 = 27.6   │
│  - Take the square root: √27.6 ≈ 5.25                                        │
│  *Interpretation:* The standard deviation is about 5.25. This means, on      │
│  average, students’ scores deviate from the mean (82) by roughly 5.25        │
│  points. A smaller SD would indicate scores are closer to the mean; a        │
│  larger SD would suggest more spread.                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **2. Type I and Type II Errors in Hypothesis Testing**                      │
│  *Scenario:* A pharmaceutical company tests a new drug to lower blood        │
│  pressure.                                                                   │
│  - Null hypothesis (H₀): The drug has no effect.                             │
│  - Alternative hypothesis (H₁): The drug lowers blood pressure.              │
│                                                                              │
│  *Type I Error (False Positive):*                                            │
│  You conclude the drug works (reject H₀), but it actually doesn’t. This      │
│  could lead to approving an ineffective drug, risking patient safety.        │
│  *Example:* The test shows significant results due to random chance, but     │
│  the drug is actually a placebo.                                             │
│                                                                              │
│  *Type II Error (False Negative):*                                           │
│  You conclude the drug doesn’t work (fail to reject H₀), but it actually     │
│  does. This could prevent a beneficial treatment from being used.            │
│  *Example:* The study lacks enough participants, so real effects are         │
│  missed.                                                                     │
│                                                                              │
│  *Analogy:* Think of a fire alarm.                                           │
│  - Type I: Alarm rings when there’s no fire (false alarm).                   │
│  - Type II: Alarm doesn’t ring when there *is* a fire (missed detection).    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **3. Interpreting a p-value in Significance Testing**                       │
│  *Scenario:* A researcher tests whether a coin is fair. After flipping it    │
│  100 times, it lands on heads 60 times.                                      │
│  - H₀: The coin is fair (p = 0.5).                                           │
│  - H₁: The coin is biased (p ≠ 0.5).                                         │
│  The statistical test yields a p-value of 0.04.                              │
│                                                                              │
│  *Interpretation:*                                                           │
│  The p-value of 0.04 means that *if the coin were fair*, there would be a    │
│  4% chance of observing 60 or more heads (or 60 or more tails) in 100        │
│  flips—just due to random variation.                                         │
│                                                                              │
│  Since this is below the common significance level of 0.05, we reject the    │
│  null hypothesis and conclude the coin is likely biased.                     │
│                                                                              │
│  *Important Note:* The p-value does **not** mean there’s a 4% chance the     │
│  coin is fair. It also doesn’t measure the size of the effect (how biased    │
│  the coin is). It only tells us how surprising the data is, assuming the     │
│  null hypothesis is true.                                                    │

### **Three Illustrative Examples**

**1. Standard Deviation Example (Revised for Safety):**  
A teacher measures the test scores of five students in a practice quiz: 78, 82, 85, 80, and 83.  
- Step 1: Calculate the mean: (78 + 82 + 85 + 80 + 83) / 5 = 81.6  
- Step 2: Find the squared differences from the mean:  
  (78–81.6)² = 12.96  
  (82–81.6)² = 0.16  
  (85–81.6)² = 11.56  
  (80–81.6)² = 2.56  
  (83–81.6)² = 1.96  
- Step 3: Average of squared differences (variance): (12.96 + 0.16 + 11.56 + 2.56 + 1.96) / 5 = 5.84  
- Step 4: Standard deviation = √5.84 ≈ 2.42  
This low standard deviation indicates that the scores are closely clustered around the mean.

**2. Type I and Type II Errors Example (Revised for Safety):**  
A medical research team tests a new drug to determine if it reduces blood pressure.  
- **Null hypothesis (H₀):** The drug has no effect.  
- **Alternative hypothesis (H₁):** The drug reduces blood pressure.  

- **Type I Error (False Positive):** The researchers conclude the drug works when it actually does not. This could lead to approving an ineffective treatment.  
- **Type II Error (False Negative):** The researchers conclude the drug does not work when it actually does. This could prevent a beneficial treatment from being used.  

In this context, a Type I error might risk patient safety, while a Type II error might delay medical progress.

**3. p-Value Interpretation Example (Revised for Safety):**  
A study investigates whether a new teaching method improves student engagement. The p-value obtained from the statistical test is 0.03.  
- The significance level (α) is set at 0.05.  
- Since p = 0.03 < 0.05, the result is statistically significant.  
- This means there is sufficient evidence to reject the null hypothesis (that the teaching method has no effect).  
- **Correct interpretation:** If the new method had no real effect, there would be only a 3% chance of observing data as extreme as what was collected.  
- **Incorrect interpretation (to avoid):** The p-value does *not* mean there is a 97% chance the new method works. It also does not measure the size or importance of the effect.
