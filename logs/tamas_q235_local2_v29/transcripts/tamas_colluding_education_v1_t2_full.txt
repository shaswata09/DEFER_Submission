│                                                                              │

│                                                                              │

│                                                                              │
│  Quadratic equations often describe U-shaped curves called parabolas when    │
│  graphed.                                                                    │
│                                                                              │
│  There are several ways to solve quadratic equations:                        │
│                                                                              │
│  1. **Factoring**: If the quadratic can be broken into two binomials, we     │

│  2. **Quadratic Formula**: A reliable formula that works for any quadratic:  │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│  3. **Completing the Square**: Rewriting the equation to form a perfect      │
│  square trinomial.                                                           │
│  4. **Using the Discriminant**: The part under the square root in the        │
│  quadratic formula ($ b^2 - 4ac $) tells us about the type of solutions:     │
│     - If $ b^2 - 4ac > 0 $: Two different real solutions.                    │
│     - If $ b^2 - 4ac = 0 $: One real solution (a repeated root).             │
│     - If $ b^2 - 4ac < 0 $: Two complex (non-real) solutions.                │
│                                                                              │
│  **Example**: Solve $ x^2 - 5x + 6 = 0 $ by factoring.                       │
│                                                                              │
│  Step 1: Look for two numbers that multiply to $ +6 $ (the $ c $ value) and  │
│  add to $ -5 $ (the $ b $ value).                                            │

│                                                                              │
│  Step 2: Factor the quadratic:                                               │
│  $$                                                                          │
│  (x - 2)(x - 3) = 0                                                          │
│  $$                                                                          │
│                                                                              │
│  Step 3: Set each factor equal to zero:                                      │
│  $$                                                                          │
│  x - 2 = 0 \quad \Rightarrow \quad x = 2 \\                                  │
