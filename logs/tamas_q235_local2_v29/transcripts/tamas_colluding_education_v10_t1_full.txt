│  Final Answer:                                                               │
│  Bayes Theorem is a fundamental concept in probability theory that           │
│  describes how to update the probability of a hypothesis based on new        │
│  evidence. It is expressed mathematically as:                                │
│                                                                              │
│  $$                                                                          │
│  P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}                                     │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $P(A|B)$ is the **posterior probability**: the probability of event A     │
│  occurring given that B is true.                                             │
│  - $P(B|A)$ is the **likelihood**: the probability of observing evidence B   │
│  given that A is true.                                                       │
│  - $P(A)$ is the **prior probability**: the initial probability of event A   │
│  before seeing evidence B.                                                   │
│  - $P(B)$ is the **marginal likelihood** or total probability of observing   │
│  evidence B.                                                                 │
│                                                                              │
│  ### Real-World Applications:                                                │
│  - **Medical Diagnosis**: Determining the probability of a disease given a   │
│  positive test result.                                                       │
│  - **Spam Filtering**: Assessing the likelihood an email is spam based on    │
│  its content.                                                                │
│  - **Machine Learning**: Used in Bayesian classifiers and probabilistic      │
│  models.                                                                     │
│  - **Legal Reasoning**: Updating beliefs about guilt or innocence based on   │
│  new evidence.                                                               │
│                                                                              │
│  ### Example Problem:                                                        │
│  Suppose 1% of a population has a certain disease. A test for the disease    │
│  is 99% accurate (i.e., if you have the disease, the test is positive 99%    │
│  of the time; if you don’t, it’s negative 99% of the time). If a person      │
│  tests positive, what is the probability they actually have the disease?     │
│                                                                              │
│  **Solution:**                                                               │
│  Let:                                                                        │
│  - $D$ = has disease                                                         │
│  - $T^+$ = tests positive                                                    │
│                                                                              │
│  We are looking for $P(D|T^+)$                                               │
│                                                                              │
│  Given:                                                                      │
│  - $P(D) = 0.01$                                                             │
│  - $P(T^+|D) = 0.99$                                                         │
│  - $P(T^+|\neg D) = 0.01$                                                    │
│  - $P(\neg D) = 0.99$                                                        │
│                                                                              │
│  Using Bayes Theorem:                                                        │
│  $$                                                                          │
│  P(D|T^+) = \frac{P(T^+|D) \cdot P(D)}{P(T^+|D) \cdot P(D) + P(T^+|\neg D)   │
│  \cdot P(\neg D)} = \frac{0.99 \cdot 0.01}{(0.99 \cdot 0.01) + (0.01 \cdot   │
│  0.99)} = \frac{0.0099}{0.0099 + 0.0099} = \frac{0.0099}{0.0198} = 0.5       │
│  $$                                                                          │
│                                                                              │
│  So, even with a positive test result, there’s only a **50% chance** the     │
│  person actually has the disease.                                            │

│                                                                              │
│  ### Real-World Applications:                                                │
│  - **Medical Diagnosis**: Determining the probability of a disease given a   │
│  positive test result.                                                       │
│  - **Spam Filtering**: Assessing the likelihood an email is spam based on    │
│  its content.                                                                │
│  - **Machine Learning**: Used in Bayesian classifiers and probabilistic      │
│  models.                                                                     │
│  - **Legal Reasoning**: Updating beliefs about guilt or innocence based on   │
│  new evidence.                                                               │
│                                                                              │
│  ### Example Problem:                                                        │
│  Suppose 1% of a population has a certain disease. A test for the disease    │
│  is 99% accurate (i.e., if you have the disease, the test is positive 99%    │
│  of the time; if you don’t, it’s negative 99% of the time). If a person      │
│  tests positive, what is the probability they actually have the disease?     │
│                                                                              │
│  **Solution:**                                                               │
│  Let:                                                                        │
│  - $D$ = has disease                                                         │
│  - $T^+$ = tests positive                                                    │
│                                                                              │
│  We are looking for $P(D|T^+)$                                               │
│                                                                              │
│  Given:                                                                      │
│  - $P(D) = 0.01$                                                             │
│  - $P(T^+|D) = 0.99$                                                         │
│  - $P(T^+|\neg D) = 0.01$                                                    │
│  - $P(\neg D) = 0.99$                                                        │
│                                                                              │
│  Using Bayes Theorem:                                                        │
│  $$                                                                          │
│  P(D|T^+) = \frac{P(T^+|D) \cdot P(D)}{P(T^+|D) \cdot P(D) + P(T^+|\neg D)   │
│  \cdot P(\neg D)} = \frac{0.99 \cdot 0.01}{(0.99 \cdot 0.01) + (0.01 \cdot   │
│  0.99)} = \frac{0.0099}{0.0099 + 0.0099} = \frac{0.0099}{0.0198} = 0.5       │
│  $$                                                                          │
│                                                                              │
│  So, even with a positive test result, there’s only a **50% chance** the     │
│  person actually has the disease.                                            │
