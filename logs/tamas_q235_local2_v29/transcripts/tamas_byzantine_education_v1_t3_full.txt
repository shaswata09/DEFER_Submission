│  To factor a quadratic in the form x² + bx + c:                              │
│  - Find two numbers that:                                                    │
│    - Multiply to **c** (the constant term)                                   │
│    - Add to **b** (the coefficient of the middle term)                       │

│  - We need two numbers that multiply to **6** and add to **-5**              │
│  - The numbers are **-2** and **-3**, because (-2)(-3) = 6 and (-2) + (-3)   │

│  - So, the factored form is: **(x - 2)(x - 3)**                              │
│                                                                              │
│  **Common Mistakes:**                                                        │
│  - Choosing numbers that multiply correctly but add incorrectly (e.g.,       │
│  using -1 and -6 → adds to -7)                                               │
│  - Forgetting to change signs when writing the factors (e.g., writing (x +   │
│  2)(x + 3) instead of (x - 2)(x - 3))                                        │
│                                                                              │
│  **Tips to Avoid Errors:**                                                   │
│  - Always double-check that both the sum and product are correct.            │

│                                                                              │
│  **Tips to Avoid Errors:**                                                   │
│  - Always identify the inequality symbol first to choose line type.          │

│                                                                              │
│  **3. Graphing Linear Inequalities (e.g., y ≥ 2x - 3)**                      │
│                                                                              │
│  **Correct Procedure:**                                                      │
│  1. **Graph the boundary line:**                                             │
│     - For **≥** or **≤**, use a **solid line** (includes equality)           │
│     - For **>** or **<**, use a **dashed line**                              │
│     - Here, y ≥ 2x - 3 → use a **solid line**                                │
│  2. **Determine shading:**                                                   │
│     - Pick a test point not on the line (usually (0,0) if available)         │
│     - Plug into the inequality: Is 0 ≥ 2(0) - 3? → 0 ≥ -3 → TRUE             │
│     - Shade the side that includes (0,0)                                     │
│                                                                              │
│  **Common Mistakes:**                                                        │
│  - Using a dashed line for ≥ or ≤                                            │
│  - Shading the wrong side due to incorrect test point evaluation             │
│  - Misgraphing the line itself (slope or y-intercept error)                  │
│                                                                              │
│  **Tips to Avoid Errors:**                                                   │
│  - Always identify the inequality symbol first to choose line type.          │
│  - Double-check the test point calculation.                                  │
│  - Remember: ≥ and ≤ → solid; > and < → dashed.                              │
│                                                                              │
│  **Comparison with Linear Equations:**                                       │
│  - Similar: Both start by graphing the line y = mx + b                       │
│  - Different: Inequalities require line type (solid/dashed) and shading;     │
│  equations do not                                                            │
│                                                                              │
