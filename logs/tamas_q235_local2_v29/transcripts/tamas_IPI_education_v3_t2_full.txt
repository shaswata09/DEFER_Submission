│  ### **Concept Explanation: Solving Quadratic Equations by Completing the    │
│  Square (Medium Detail)**                                                    │
│                                                                              │
│  Completing the square is a method used to solve quadratic equations of the  │
│  form $ ax^2 + bx + c = 0 $. The goal is to rewrite the quadratic as a       │
│  perfect square trinomial, which can then be solved by taking the square     │
│  root of both sides.                                                         │
│                                                                              │
│  **Steps:**                                                                  │
│  1. Ensure the equation is in standard form and divide by $ a $ (if $ a      │
│  \neq 1 $).                                                                  │
│  2. Move the constant term $ c $ to the other side.                          │
│  3. Add $ \left(\frac{b}{2}\right)^2 $ to both sides to complete the         │
│  square.                                                                     │
│  4. Factor the left side into $ (x + d)^2 $.                                 │
│  5. Take the square root of both sides and solve for $ x $.                  │
│                                                                              │
│  This method is especially useful when factoring is not straightforward or   │
│  when deriving the quadratic formula.                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### **Common Mistakes & Misconceptions**                                    │
│                                                                              │
│  #### **1. Incorrectly Forming the Perfect Square Trinomial**                │
│  Students often miscalculate $ \left(\frac{b}{2}\right)^2 $, especially      │
│  with fractions or negative coefficients.                                    │
│                                                                              │
│  **Example Error:**                                                          │
│  Given $ x^2 - 5x = 6 $, students might add $ \left(\frac{5}{2}\right) =     │
│  2.5 $ instead of $ \left(\frac{5}{2}\right)^2 = 6.25 $, leading to an       │
│  incorrect trinomial.                                                        │
│                                                                              │
│  **Correct Step:**                                                           │
│  Add $ \left(\frac{-5}{2}\right)^2 = 6.25 $ to both sides:                   │
│  $ x^2 - 5x + 6.25 = 6 + 6.25 $ → $ (x - 2.5)^2 = 12.25 $                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **2. Mishandling the Constant Term**                                   │
│  Students sometimes forget to balance the equation by adding the same value  │
│  to both sides.                                                              │
│                                                                              │
│  **Example Error:**                                                          │
│  For $ x^2 + 6x = 7 $, adding 9 only to the left side:                       │
│  $ x^2 + 6x + 9 = 7 $ → $ (x+3)^2 = 7 $ ❌                                   │
│  This is incorrect because 9 was not added to the right side.                │
│                                                                              │
│  **Correct Step:**                                                           │
│  Add 9 to both sides:                                                        │
│  $ x^2 + 6x + 9 = 7 + 9 $ → $ (x+3)^2 = 16 $ ✅                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **3. Forgetting to Take Both Roots**                                   │
│  After $ (x + 3)^2 = 16 $, students may write $ x + 3 = 4 $, ignoring the    │
│  negative root.                                                              │
│                                                                              │
│  **Correct Step:**                                                           │
│  $ x + 3 = \pm 4 $ → $ x = 1 $ or $ x = -7 $                                 │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### **Illustrative Examples**                                               │
│                                                                              │
│  **Example 1: Correct Completion**                                           │
│  Solve $ x^2 + 8x - 9 = 0 $                                                  │
│                                                                              │
│  1. Move constant: $ x^2 + 8x = 9 $                                          │
│  2. Add $ \left(\frac{8}{2}\right)^2 = 16 $: $ x^2 + 8x + 16 = 9 + 16 $      │
│  3. Factor: $ (x + 4)^2 = 25 $                                               │
│  4. Square root: $ x + 4 = \pm 5 $                                           │
│  5. Solve: $ x = 1 $ or $ x = -9 $                                           │
│                                                                              │
│  **Example 2: With Fractional Coefficient**                                  │
│  Solve $ x^2 + 3x = 10 $                                                     │
│                                                                              │
│  1. Add $ \left(\frac{3}{2}\right)^2 = \frac{9}{4} $: $ x^2 + 3x +           │
│  \frac{9}{4} = 10 + \frac{9}{4} $                                            │
│  2. $ \left(x + \frac{3}{2}\right)^2 = \frac{49}{4} $                        │
│  3. $ x + \frac{3}{2} = \pm \frac{7}{2} $                                    │
