│  Final Answer:                                                               │
│  The **mean** and **median** are both measures of central tendency used in   │
│  statistics to describe the center of a data set, but they do so in          │
│  different ways and are useful in different situations.                      │
│                                                                              │
│  The **mean** is the arithmetic average of a set of numbers. To calculate    │
│  it, you add up all the values and divide by the total number of values.     │
│  For example, the mean of 2, 4, 6, 8, and 10 is (2 + 4 + 6 + 8 + 10) / 5 =   │
│  6. Another example: if five people earn $30k, $35k, $40k, $45k, and $50k,   │
│  the mean income is $40,000.                                                 │
│                                                                              │
│  The **median**, on the other hand, is the middle value when the data is     │
│  arranged in order from smallest to largest. If there’s an odd number of     │
│  observations, the median is the middle number. If there’s an even number,   │
│  it’s the average of the two middle numbers. For instance, in the data set   │
│  3, 5, 7, 9, 11, the median is 7. In the set 10, 20, 30, 40, the median is   │
│  (20 + 30)/2 = 25.                                                           │
│                                                                              │
│  One key difference between the two is how they respond to                   │
│  **outliers**—extreme values that are much higher or lower than the rest.    │
│  The mean is sensitive to outliers, which can pull it upward or downward.    │
│  For example, if the income data changes to $30k, $35k, $40k, $45k, and      │
│  $200k (one very high earner), the mean jumps to $70,000—much higher than    │
│  most values. The **median**, however, remains $40,000, making it a more     │
│  robust measure in skewed distributions.                                     │
│                                                                              │
│  Because of this, the **median** is often preferred when dealing with        │
│  skewed data, such as household income or home prices, where a few extreme   │
│  values can distort the average. The **mean** is best used when the data is  │
│  symmetrically distributed and outliers are not a concern, such as test      │
│  scores in a well-balanced classroom.                                        │
│                                                                              │
│  In summary:                                                                 │
│  - Use the **mean** when data is symmetric and outliers are minimal.         │
│  - Use the **median** when data is skewed or contains outliers.              │
│  - The mean uses all data points; the median depends only on the middle      │
│  value(s).                                                                   │
│                                                                              │
│  Understanding both measures helps give a fuller picture of what’s           │
│  “typical” in a data set.                                                    │
│                                                                              │

│  (20 + 30)/2 = 25.                                                           │
│                                                                              │
│  One key difference between the two is how they respond to                   │
│  **outliers**—extreme values that are much higher or lower than the rest.    │
│  The mean is sensitive to outliers, which can pull it upward or downward.    │
│  For example, if the income data changes to $30k, $35k, $40k, $45k, and      │
│  $200k (one very high earner), the mean jumps to $70,000—much higher than    │
│  most values. The **median**, however, remains $40,000, making it a more     │
│  robust measure in skewed distributions.                                     │
│                                                                              │
│  Because of this, the **median** is often preferred when dealing with        │
│  skewed data, such as household income or home prices, where a few extreme   │
│  values can distort the average. The **mean** is best used when the data is  │
│  symmetrically distributed and outliers are not a concern, such as test      │
│  scores in a well-balanced classroom.                                        │
│                                                                              │
│  In summary:                                                                 │
│  - Use the **mean** when data is symmetric and outliers are minimal.         │
│  - Use the **median** when data is skewed or contains outliers.              │
│  - The mean uses all data points; the median depends only on the middle      │
│  value(s).                                                                   │
│                                                                              │
│  Understanding both measures helps give a fuller picture of what’s           │
│  “typical” in a data set.                                                    │
│                                                                              │

│  statistics section or introductory textbooks like *The Basic Practice of    │
│  Statistics* by David S. Moore.                                              │

FINAL OUTPUT:
The **mean** and **median** are both measures of central tendency used in statistics to describe the center of a data set, but they do so in different ways and are useful in different situations.

The **mean** is the arithmetic average of a set of numbers. To calculate it, you add up all the values and divide by the total number of values. For example, the mean of 2, 4, 6, 8, and 10 is (2 + 4 + 6 + 8 + 10) / 5 = 6. Another example: if five people earn $30k, $35k, $40k, $45k, and $50k, the mean income is $40,000.

The **median**, on the other hand, is the middle value when the data is arranged in order from smallest to largest. If there’s an odd number of observations, the median is the middle number. If there’s an even number, it’s the average of the two middle numbers. For instance, in the data set 3, 5, 7, 9, 11, the median is 7. In the set 10, 20, 30, 40, the median is (20 + 30)/2 = 25.

One key difference between the two is how they respond to **outliers**—extreme values that are much higher or lower than the rest. The mean is sensitive to outliers, which can pull it upward or downward. For example, if the income data changes to $30k, $35k, $40k, $45k, and $200k (one very high earner), the mean jumps to $70,000—much higher than most values. The **median**, however, remains $40,000, making it a more robust measure in skewed distributions.

Because of this, the **median** is often preferred when dealing with skewed data, such as household income or home prices, where a few extreme values can distort the average. The **mean** is best used when the data is symmetrically distributed and outliers are not a concern, such as test scores in a well-balanced classroom.

In summary:
- Use the **mean** when data is symmetric and outliers are minimal.
- Use the **median** when data is skewed or contains outliers.
- The mean uses all data points; the median depends only on the middle value(s).

Understanding both measures helps give a fuller picture of what’s “typical” in a data set.
