│  ### Introduction to Fractions (Easy Level)                                  │
│                                                                              │
│  #### What is a Fraction?                                                    │
│  A **fraction** represents a part of a whole. Imagine you have a pizza cut   │
│  into equal slices. If you eat 1 slice out of 8, you have eaten **1/8** of   │
│  the pizza.                                                                  │
│                                                                              │
│  A fraction has two parts:                                                   │
│  - **Numerator**: The number on top. It tells how many parts we have.        │
│  - **Denominator**: The number on the bottom. It tells how many equal parts  │
│  the whole is divided into.                                                  │
│                                                                              │
│  For example:                                                                │
│  In the fraction **3/4**,                                                    │
│  - 3 is the **numerator** (we have 3 parts),                                 │
│  - 4 is the **denominator** (the whole is divided into 4 equal parts).       │
│                                                                              │
│  #### Visualizing Fractions                                                  │
│                                                                              │
│  Let’s look at a few examples with shapes:                                   │
│                                                                              │
│  1. **Circle divided into 2 equal parts**                                    │
│     🟡🟡 → If one part is shaded: **1/2**                                    │
│     This is called "one-half."                                               │
│                                                                              │
│  2. **Rectangle divided into 4 equal parts**                                 │
│     [🟨][ ][ ][ ] → If one part is shaded: **1/4**                           │
│     This is called "one-fourth" or "one-quarter."                            │
│                                                                              │
│  3. **Bar divided into 3 equal parts**                                       │
│     [🟩][🟩][ ] → If two parts are shaded: **2/3**                           │
│     This is called "two-thirds."                                             │
│                                                                              │
│  #### Common Fractions and Their Names                                       │
│                                                                              │
│  | Fraction | Name             |                                             │
│  |--------|------------------|                                               │
│  | 1/2    | One-half         |                                               │
│  | 1/3    | One-third        |                                               │
│  | 1/4    | One-fourth       |                                               │
│  | 2/3    | Two-thirds       |                                               │
│  | 3/4    | Three-fourths    |                                               │

│                                                                              │
│  **Answers:**                                                                │

│                                                                              │
│  **Exercise 2: Shade the Fraction**                                          │
│  Draw a square and divide it into 4 equal parts. Shade **1/4** of it.        │
│                                                                              │
│  **Exercise 3: Real-Life Example**                                           │
│  You have 5 candies. You give 2 to your friend. What fraction of the         │
│  candies did you give away?                                                  │
│  Answer: **2/5**                                                             │
│                                                                              │
│  #### Key Points to Remember                                                 │
│  - A fraction shows part of a whole.                                         │
│  - The top number (numerator) = how many parts you have.                     │
│  - The bottom number (denominator) = how many equal parts the whole is       │
│  split into.                                                                 │
│  - Always make sure the parts are equal!                                     │
│                                                                              │
│  #### Fun Tip                                                                │

### Introduction to Fractions (Easy Level)

#### What is a Fraction?
A **fraction** represents a part of a whole. Imagine you have a pizza cut into equal slices. If you eat 1 slice out of 8, you have eaten **1/8** of the pizza.

A fraction has two parts:
- **Numerator**: The number on top. It tells how many parts we have.
- **Denominator**: The number on the bottom. It tells how many equal parts the whole is divided into.

For example:  
In the fraction **3/4**,  
- 3 is the **numerator** (we have 3 parts),  
- 4 is the **denominator** (the whole is divided into 4 equal parts).

#### Visualizing Fractions

Let’s look at a few examples with shapes:

1. **Circle divided into 2 equal parts**  
   🟡🟡 → If one part is shaded: **1/2**  
   This is called "one-half."

2. **Rectangle divided into 4 equal parts**  
   [🟨][ ][ ][ ] → If one part is shaded: **1/4**  
   This is called "one-fourth" or "one-quarter."

3. **Bar divided into 3 equal parts**  
   [🟩][🟩][ ] → If two parts are shaded: **2/3**  
   This is called "two-thirds."

#### Common Fractions and Their Names

| Fraction | Name             |
|--------|------------------|
| 1/2    | One-half         |
| 1/3    | One-third        |
| 1/4    | One-fourth       |
| 2/3    | Two-thirds       |
| 3/4    | Three-fourths    |

#### Key Points to Remember
- A fraction shows part of a whole.
- The top number (numerator) = how many parts you have.
- The bottom number (denominator) = how many equal parts the whole is split into.
- Always make sure the parts are equal!

#### Fun Tip
Think of fractions like sharing:  
“If I share 1 cookie with 1 friend equally, each gets **1/2**!”
