│  Final Answer:                                                               │
│  Limits in calculus describe the behavior of a function as its input         │
│  approaches a specific value, rather than the function's value at that       │
│  exact point. Intuitively, we ask: "What value does the function get closer  │
│  and closer to as x approaches some number?" For example, even if a          │
│  function is undefined at a point, we can still investigate its limiting     │
│  behavior around that point. Formally, we say that the limit of f(x) as x    │
│  approaches a is L, written as lim_(x→a) f(x) = L, if we can make f(x)       │
│  arbitrarily close to L by taking x sufficiently close to a (but not equal   │
│  to a). Limits are foundational in calculus because they underpin both       │
│  derivatives (rates of change) and integrals (accumulation of quantities).   │
│  They allow us to handle concepts like instantaneous velocity and the slope  │
│  of a curve.                                                                 │
│                                                                              │
│  Here are three illustrative examples:                                       │
│                                                                              │
│  1. **Simple polynomial limit**: lim_(x→2) (x² - 4) = 0. As x gets close to  │
│  2, x² - 4 approaches 0.                                                     │
│  2. **Rational function with hole**: lim_(x→3) (x² - 9)/(x - 3) = 6. Though  │
│  the function is undefined at x = 3, simplifying to x + 3 shows the limit    │
│  is 6.                                                                       │
│  3. **One-sided limit**: lim_(x→0⁺) 1/x = ∞. As x approaches 0 from the      │
│  positive side, 1/x grows without bound.                                     │
│                                                                              │
│  For further learning, consider these resources:                             │
│  - [Khan Academy: Limits and                                                 │
│  Continuity](https://www.khanacademy.org/math/calculus-1)                    │

│  RMYO3t5Yr)                                                                  │

│  ### **Concept Explanation: The Fundamental Idea of Limits**                 │
│                                                                              │
│  Limits are the foundation of calculus, enabling us to analyze how           │
│  functions behave as inputs approach specific values—even when the function  │
│  is undefined at those points. Rather than focusing on the value *at* a      │
│  point, limits examine the *trend* of the function *near* that point.        │
│                                                                              │
│  We say that:                                                                │
│  > The limit of \( f(x) \) as \( x \) approaches \( a \) is \( L \),         │
│  written                                                                     │
│  > \[                                                                        │
│  > \lim_{x \to a} f(x) = L                                                   │
│  > \]                                                                        │
│  > if \( f(x) \) gets arbitrarily close to \( L \) as \( x \) gets           │
│  sufficiently close to \( a \) (but not equal to \( a \)).                   │
│                                                                              │
│  This concept is essential for defining both **derivatives** (instantaneous  │
│  rates of change) and **integrals** (accumulated quantities).                │
│                                                                              │
│  #### **Key Examples:**                                                      │
│  1. **Polynomial Limit**:                                                    │
│     \[                                                                       │
│     \lim_{x \to 2} (x^2 - 4) = 0                                             │
│     \]                                                                       │
│     As \( x \) approaches 2, the output approaches 0.                        │
│                                                                              │
│  2. **Removable Discontinuity**:                                             │
│     \[                                                                       │
│     \lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} (x + 3) = 6        │
│     \]                                                                       │
│     Though undefined at \( x = 3 \), the limit exists and equals 6.          │
│                                                                              │
│  3. **One-Sided Limit**:                                                     │
│     \[                                                                       │
│     \lim_{x \to 0^+} \frac{1}{x} = \infty                                    │
│     \]                                                                       │
│     As \( x \) approaches 0 from the right, the function grows without       │
│  bound.                                                                      │
│                                                                              │
│  #### **Why Limits Matter:**                                                 │
│  - Derivatives rely on the limit of the difference quotient.                 │
│  - Integrals are defined as limits of Riemann sums.                          │
│  - They allow precise modeling of real-world phenomena like motion, growth,  │
│  and optimization.                                                           │

### **Concept Explanation: The Fundamental Idea of Limits**

Limits are the foundation of calculus, enabling us to analyze how functions behave as inputs approach specific values—even when the function is undefined at those points. Rather than focusing on the value *at* a point, limits examine the *trend* of the function *near* that point.

We say that:  
> The limit of \( f(x) \) as \( x \) approaches \( a \) is \( L \), written  
> \[
> \lim_{x \to a} f(x) = L
> \]  
> if \( f(x) \) gets arbitrarily close to \( L \) as \( x \) gets sufficiently close to \( a \) (but not equal to \( a \)).

This concept is essential for defining both **derivatives** (instantaneous rates of change) and **integrals** (accumulated quantities).

#### **Key Examples:**
1. **Polynomial Limit**:  
   \[
   \lim_{x \to 2} (x^2 - 4) = 0
   \]  
   As \( x \) approaches 2, the output approaches 0.

2. **Removable Discontinuity**:  
   \[
   \lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} (x + 3) = 6
   \]  
   Though undefined at \( x = 3 \), the limit exists and equals 6.

3. **One-Sided Limit**:  
   \[
   \lim_{x \to 0^+} \frac{1}{x} = \infty
   \]  
   As \( x \) approaches 0 from the right, the function grows without bound.

#### **Why Limits Matter:**
- Derivatives rely on the limit of the difference quotient.
- Integrals are defined as limits of Riemann sums.
- They allow precise modeling of real-world phenomena like motion, growth, and optimization.
