│  **2. Example: Using a P-Value in Hypothesis Testing**                       │
│                                                                              │
│  *Scenario:*                                                                 │
│  A company claims its lightbulbs last 1,200 hours on average. A consumer     │
│  group tests a sample of 30 bulbs and finds a sample mean of 1,170 hours     │
│  with a standard deviation of 100 hours. Is there evidence to suggest the    │
│  bulbs last less than claimed?                                               │
│                                                                              │
│  *Step-by-Step Hypothesis Test:*                                             │
│                                                                              │
│  1. **Set hypotheses:**                                                      │
│     - Null hypothesis (H₀): μ = 1,200 (bulbs last 1,200 hours)               │
│     - Alternative hypothesis (H₁): μ < 1,200 (bulbs last less than 1,200     │
│  hours)                                                                      │
│                                                                              │
│  2. **Calculate test statistic (t-score):**                                  │
│     t = (1,170 – 1,200) / (100 / √30) = (–30) / (18.26) ≈ –1.64              │
│                                                                              │
│  3. **Find p-value:**                                                        │
│     Using a t-distribution table with 29 degrees of freedom, a t-score of    │
│  –1.64 corresponds to a p-value of approximately 0.056.                      │
│                                                                              │
│  4. **Decision at α = 0.05:**                                                │
│     Since 0.056 > 0.05, we fail to reject the null hypothesis.               │
│                                                                              │
│  *Interpretation:*                                                           │
│  The p-value of 0.056 means there’s a 5.6% chance of observing a sample      │
│  mean of 1,170 hours or less if the true average is 1,200 hours. This is     │
│  not strong enough evidence to conclude the bulbs last significantly less    │
│  than claimed at the 5% significance level.                                  │

│  city. A random sample of 50 men has an average height of 175 cm, with a     │
│  known population standard deviation of 8 cm.                                │
│                                                                              │
│  *Step-by-Step Confidence Interval (95%):*                                   │
│                                                                              │
│  1. **Find the standard error (SE):**                                        │
│     SE = σ / √n = 8 / √50 ≈ 8 / 7.07 ≈ 1.13                                  │
│                                                                              │
│  2. **Use z* for 95% confidence (z* ≈ 1.96):**                               │
│     Margin of error = 1.96 × 1.13 ≈ 2.21                                     │
│                                                                              │
│  3. **Build the interval:**                                                  │
│     175 ± 2.21 → (172.79, 177.21)                                            │
│                                                                              │
│  *Interpretation:*                                                           │

│  true mean.                                                                  │

### **Three Illustrative Examples of Key Statistical Concepts**

---

**1. Example: Calculating and Interpreting Standard Deviation**

*Scenario:*  
A teacher measures the test scores of five students: 78, 85, 88, 90, and 94. She wants to understand how spread out the scores are.

*Step-by-Step Calculation:*

1. **Mean:** (78 + 85 + 88 + 90 + 94) / 5 = 435 / 5 = 87  
2. **Squared differences from mean:**  
   (78–87)² = 81, (85–87)² = 4, (88–87)² = 1, (90–87)² = 9, (94–87)² = 49  
3. **Variance:** (81 + 4 + 1 + 9 + 49) / 5 = 144 / 5 = 28.8  
4. **Standard Deviation:** √28.8 ≈ **5.37**

*Interpretation:*  
The standard deviation is about 5.37. This means scores typically deviate from the average (87) by about 5.37 points. A small standard deviation suggests consistent performance.

---

**2. Example: Using a P-Value in Hypothesis Testing**

*Scenario:*  
A company claims lightbulbs last 1,200 hours. A sample of 30 bulbs has a mean of 1,170 hours and standard deviation of 100 hours. Is the claim supported?

*Step-by-Step Hypothesis Test:*

1. **Hypotheses:**  
   - H₀: μ = 1,200 (claim is true)  
   - H₁: μ < 1,200 (bulbs last less)  
2. **Test Statistic (t-score):**  
   t = (1,170 – 1,200) / (100 / √30) = –30 / 18.26 ≈ –1.64  
3. **P-value:** ≈ 0.056 (from t-distribution, df = 29)  
4. **Decision (α = 0.05):** 0.056 > 0.05 → **Fail to reject H₀**

*Interpretation:*  
The p-value of 0.056 means there’s a 5.6% chance of getting such a low sample mean if the true average is 1,200. This is not strong enough evidence to reject the company’s claim at the 5% level.

---

**3. Example: Interpreting a Confidence Interval**

*Scenario:*  
Estimate average height of adult males. A sample of 50 men has mean = 175 cm, population standard deviation = 8 cm.

*Step-by-Step (95% CI):*

1. **Standard Error (SE):** 8 / √50 ≈ 1.13  
2. **Margin of Error:** 1.96 × 1.13 ≈ 2.21  
3. **Confidence Interval:** 175 ± 2.21 → **(172.79, 177.21)**

*Interpretation:*  
We are **95% confident** that the true average height of adult males in the city is between **172.79 cm and 177.21 cm**. This means the method used would capture the true mean in 95% of repeated samples.
