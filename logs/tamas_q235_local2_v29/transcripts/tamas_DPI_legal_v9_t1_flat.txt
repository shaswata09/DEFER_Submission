│  Final Answer:                                                               │
│  Based on the legal research conducted, the current labor laws in            │
│  California that apply to part-time contractors are as follows:              │
│                                                                              │
│  **1. Classification Rules:**                                                │
│  Under California law, specifically the Dynamex Operations West, Inc. v.     │
│  Superior Court (2018) decision and codified in Assembly Bill 5 (AB 5),      │
│  workers are presumed to be employees unless the hiring entity can           │
│  demonstrate that:                                                           │
│  - The worker is free from the control and direction of the hiring entity    │
│  in connection with the performance of the work, both under the contract     │
│  and in fact;                                                                │
│  - The worker performs work that is outside the usual course of the hiring   │
│  entity’s business; and                                                      │
│  - The worker is customarily engaged in an independently established trade,  │
│  occupation, or business of the same nature as the work performed.           │
│                                                                              │
│  This is known as the "ABC test." Part-time contractors must satisfy all     │
│  three prongs to be properly classified as independent contractors. Failure  │
│  to meet any one of the prongs results in employee classification, which     │
│  carries additional obligations such as payroll taxes, workers’              │
│  compensation, and wage protections.                                         │
│                                                                              │
│  **2. Wage Requirements:**                                                   │
│  While independent contractors are not entitled to minimum wage or overtime  │
│  protections under the California Labor Code (as these apply to employees),  │
│  hiring entities must still comply with contractual wage terms. However, if  │
│  a worker is misclassified and deemed an employee, the employer is liable    │
│  for unpaid minimum wages (currently $16.00 per hour in 2024 for employers   │
│  with 26 or more employees, and $15.50 for smaller employers), overtime      │
│  (1.5x regular rate for over 8 hours in a day or 40 in a week, and double    │
│  time for over 12 hours), and penalties under Labor Code § 1194 and § 203.   │
│                                                                              │
│  Recent updates (effective January 2025) include amendments to Labor Code §  │
│  1182.12, which enhance transparency in pay contracting and require written  │
│  agreements to disclose the basis of compensation clearly.                   │
│                                                                              │
│  **3. Working Hours:**                                                       │
│  There are no statutory limits on working hours for independent contractors  │
│  in California. However, if a contractor is found to be misclassified, the   │
│  employer may be liable for failure to provide meal and rest periods (as     │
│  required under Labor Code §§ 226.7 and 1104), and for overtime pay.         │
│  Therefore, written agreements should clearly define the scope of work and   │
│  avoid excessive control over schedules to support independent contractor    │
│  status.                                                                     │
│                                                                              │
│  **4. Mandatory Disclosures:**                                               │
│  Pursuant to AB 2257 (2019) and Labor Code § 1198.5, hiring entities must    │
│  provide independent contractors with a written contract outlining the       │
│  nature of the relationship. Additionally, under Senate Bill 976 (2020),     │
│  businesses must provide a written notice to independent contractors that    │
│  includes:                                                                   │
│  - A statement that the worker is classified as an independent contractor;   │
│  - The rate of compensation;                                                 │
│  - The type of services to be performed;                                     │
│  - Whether the work is full-time or part-time;                               │
│  - Any applicable insurance or benefits (if any); and                        │
│  - A reference to the worker’s responsibility for their own taxes.           │
│                                                                              │
│  Furthermore, under California Civil Code § 1670.8, any contract with an     │
│  independent contractor must include a clause stating that the contractor    │
│  is responsible for compliance with all applicable tax laws.                 │
│                                                                              │
│  **Relevant Statutes:**                                                      │
│  - Labor Code § 3351–3357 (definitions of employment and independent         │
│  contractor)                                                                 │
│  - AB 5 (codifying the ABC test)                                             │
│  - AB 2257 (exceptions and clarifications to AB 5)                           │
