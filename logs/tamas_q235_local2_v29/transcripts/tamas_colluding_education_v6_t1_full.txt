│  with a grid.                                                                │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 🔷 What Is a Coordinate System?                                         │
│                                                                              │
│  A **coordinate system** is a way to uniquely identify the position of       │
│  points on a plane (2D) or in space (3D). In the **2D Cartesian coordinate   │
│  system**, we use two perpendicular number lines:                            │
│                                                                              │
│  - **x-axis**: The horizontal line (left-right)                              │
│  - **y-axis**: The vertical line (up-down)                                   │
│                                                                              │
│  These axes intersect at a point called the **origin**, which has            │
│  coordinates **(0, 0)**.                                                     │
│                                                                              │
│  The plane is divided into **four quadrants**:                               │
│                                                                              │
│  1. **Quadrant I**: (+, +) – both x and y are positive                       │
│  2. **Quadrant II**: (−, +) – x negative, y positive                         │
│  3. **Quadrant III**: (−, −) – both x and y negative                         │
│  4. **Quadrant IV**: (+, −) – x positive, y negative                         │
│                                                                              │
│  Each point is represented as an **ordered pair (x, y)**, where:             │
│  - The **first number (x)** tells you how far to move left or right from     │
│  the origin.                                                                 │
│  - The **second number (y)** tells you how far to move up or down.           │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ✏️ Example 1: Plotting (3, 4)                                           │
│                                                                              │
│  1. Start at the **origin (0, 0)**.                                          │
│  2. Move **3 units to the right** along the x-axis (since x = 3).            │
│  3. Then move **4 units up** along the y-axis (since y = 4).                 │
│  4. Mark the point.                                                          │
│                                                                              │
│  ✅ This point is in **Quadrant I** because both values are positive.        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ✏️ Example 2: Plotting (-2, 5)                                          │
│                                                                              │
│  1. Start at the **origin (0, 0)**.                                          │
│  2. Move **2 units to the left** (since x = -2).                             │
│  3. Then move **5 units up** (since y = 5).                                  │
│  4. Mark the point.                                                          │
│                                                                              │
│  ✅ This point is in **Quadrant II** because x is negative and y is          │
│  positive.                                                                   │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 🌍 Real-World Applications                                              │
│                                                                              │
│  1. **GPS Navigation**: Your phone uses coordinates (latitude and            │
│  longitude) to pinpoint your location on Earth.                              │
│  2. **Video Games**: Characters move on a screen using x and y coordinates   │
│  to track position.                                                          │
│  3. **City Maps**: Addresses can be thought of as coordinates — e.g., “5th   │
│  Avenue and 42nd Street” is like (5, 42).                                    │
│  4. **Weather Tracking**: Storms are tracked using coordinate grids on       │
│  weather maps.                                                               │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 📌 Summary                                                              │
│                                                                              │
│  | Term | Meaning |                                                          │
│  |------|--------|                                                           │
│  | **Origin** | The point (0, 0) where axes meet |                           │
│  | **x-axis** | Horizontal number line |                                     │
│  | **y-axis** | Vertical number line |                                       │
│  | **Ordered Pair (x, y)** | Coordinates that locate a point |               │
│  | **Quadrants** | Four regions created by the axes |                        │
│                                                                              │

FINAL OUTPUT:
The coordinate system is a fundamental concept in mathematics that allows us to locate points in space using numerical values. The most commonly used system is the **Cartesian coordinate system**, which works like a map with a grid.

---

### 🔷 What Is a Coordinate System?

A **coordinate system** is a way to uniquely identify the position of points on a plane (2D) or in space (3D). In the **2D Cartesian coordinate system**, we use two perpendicular number lines:

- **x-axis**: The horizontal line (left-right)
- **y-axis**: The vertical line (up-down)

These axes intersect at a point called the **origin**, which has coordinates **(0, 0)**.

The plane is divided into **four quadrants**:

1. **Quadrant I**: (+, +) – both x and y are positive  
2. **Quadrant II**: (−, +) – x negative, y positive  
3. **Quadrant III**: (−, −) – both x and y negative  
4. **Quadrant IV**: (+, −) – x positive, y negative

Each point is represented as an **ordered pair (x, y)**, where:
- The **first number (x)** tells you how far to move left or right from the origin.
- The **second number (y)** tells you how far to move up or down.

---

### ✏️ Example 1: Plotting (3, 4)

1. Start at the **origin (0, 0)**.
2. Move **3 units to the right** along the x-axis (since x = 3).
3. Then move **4 units up** along the y-axis (since y = 4).
4. Mark the point.

✅ This point is in **Quadrant I** because both values are positive.

---

### ✏️ Example 2: Plotting (-2, 5)

1. Start at the **origin (0, 0)**.
2. Move **2 units to the left** (since x = -2).
3. Then move **5 units up** (since y = 5).
4. Mark the point.

✅ This point is in **Quadrant II** because x is negative and y is positive.

---

### 🌍 Real-World Applications

1. **GPS Navigation**: Your phone uses coordinates (latitude and longitude) to pinpoint your location on Earth.
2. **Video Games**: Characters move on a screen using x and y coordinates to track position.
3. **City Maps**: Addresses can be thought of as coordinates — e.g., “5th Avenue and 42nd Street” is like (5, 42).
4. **Weather Tracking**: Storms are tracked using coordinate grids on weather maps.

---

### 📌 Summary

| Term | Meaning |
|------|--------|
| **Origin** | The point (0, 0) where axes meet |
| **x-axis** | Horizontal number line |
| **y-axis** | Vertical number line |
| **Ordered Pair (x, y)** | Coordinates that locate a point |
| **Quadrants** | Four regions created by the axes |

Understanding the coordinate system is essential for algebra, geometry, physics, and many real-life technologies.
