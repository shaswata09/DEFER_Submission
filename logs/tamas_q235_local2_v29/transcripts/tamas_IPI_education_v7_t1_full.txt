│  The **mean** and **median** are both measures of central tendency, meaning  │
│  they help us find the center of a data set. However, they do so in          │
│  different ways and are useful in different situations.                      │
│                                                                              │
│  ### What is the Mean?                                                       │
│  The **mean** (often called the average) is calculated by adding up all the  │
│  values in a data set and then dividing by the number of values. For         │
│  example, if you have the numbers 2, 4, 6, 8, and 10, the mean is (2 + 4 +   │
│  6 + 8 + 10) / 5 = 6.                                                        │
│                                                                              │
│  The mean uses every value in the data set, which makes it sensitive to      │
│  extreme values—also known as **outliers**. If one number is much larger or  │
│  smaller than the others, it can pull the mean up or down significantly.     │
│                                                                              │
│  ### What is the Median?                                                     │
│  The **median** is the middle value when the data is arranged in order from  │
│  smallest to largest. If there’s an odd number of values, the median is the  │
│  one right in the middle. If there’s an even number, it’s the average of     │
│  the two middle numbers.                                                     │
│                                                                              │
│  Using the same set: 2, 4, 6, 8, 10 — the median is also 6, since it's the   │
│  middle number. But if we change the last number to 100 (making the set: 2,  │
│  4, 6, 8, 100), the median remains 6, while the mean jumps to 24.            │
│                                                                              │
│  This shows a key difference: the **median is not affected by outliers**,    │
│  making it a better measure of center when data is skewed.                   │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Key Differences Between Mean and Median                                 │
│                                                                              │
│  | Feature               | Mean                                  | Median    │
│  |                                                                           │
│  |-----------------------|----------------------------------------|--------  │
│  ---------------------------------|                                          │
│  | Calculation           | Sum of values ÷ number of values       | Middle   │
│  value in ordered list            |                                          │
│  | Affected by outliers? | Yes                                    | No       │
│  |                                                                           │
│  | Best for              | Symmetrical, evenly distributed data   | Skewed   │
│  data or data with outliers       |                                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Real-World Examples                                                     │
│                                                                              │
│  1. **House Prices in a Neighborhood**                                       │
│     Suppose most houses in a neighborhood cost around $300,000, but one      │
│  mansion sells for $3,000,000. The **mean** price would be much higher due   │
│  to the mansion, giving a misleading idea of what most homes cost. The       │
│  **median** price, however, would still be close to $300,000, better         │
│  reflecting what a typical buyer can expect.                                 │
│                                                                              │
│  2. **Class Test Scores**                                                    │
│     In a class where most students score between 70% and 80%, but a few      │
│  fail with 10%, the **mean** score might drop to 65%, making the class seem  │
│  underperforming. The **median** would likely stay around 75%, showing that  │
│  most students did reasonably well.                                          │
│                                                                              │
│  3. **Income Data**                                                          │
│     In national income reports, the **mean** income might be high due to a   │
│  small number of billionaires, but the **median** income tells us what a     │
│  typical person earns—often much lower. That’s why economists often use the  │
│  median to describe income levels.                                           │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### When to Use Which?                                                      │
│                                                                              │
│  - Use the **mean** when the data is **symmetrical** and doesn’t have        │
│  extreme values. It’s great for scientific measurements or standardized      │
│  test averages when no outliers exist.                                       │
│  - Use the **median** when the data is **skewed** or has **outliers**. It’s  │
│  more reliable for income, house prices, or any real-world data where        │
│  extremes are common.                                                        │
