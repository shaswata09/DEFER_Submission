│  ### **Common Misconceptions in Coordinate Geometry – Clarification Guide**  │
│                                                                              │
│  #### **1. Slope Calculation: Getting Rise over Run Right**                  │
│  **Explanation**:                                                            │
│  The slope of a line measures its steepness and is calculated as *rise over  │
│  run*, or the change in *y* divided by the change in *x*.                    │
│  Formula:                                                                    │
│  $$                                                                          │
│  m = \frac{y_2 - y_1}{x_2 - x_1}                                             │
│  $$                                                                          │
│  ⚠️ **Common Errors**:                                                       │
│  - Swapping *x* and *y* in the formula.                                      │
│  - Misordering coordinates (e.g., subtracting $y_1 - y_2$ but $x_2 - x_1$).  │
│  - Sign errors when subtracting negative numbers.                            │
│                                                                              │
│  **Examples of Errors**:                                                     │
│  1. **Mixing up x and y**:                                                   │
│     Given points $(2, 3)$ and $(5, 7)$, a student calculates:                │
│     $ \frac{5 - 2}{7 - 3} = \frac{3}{4} $ ❌                                 │
│     Correct: $ \frac{7 - 3}{5 - 2} = \frac{4}{3} $ ✅                        │
│                                                                              │
│  2. **Sign error with negatives**:                                           │
│     Points: $(-1, 4)$ and $(3, -2)$                                          │
│     Incorrect: $ \frac{4 - (-2)}{-1 - 3} = \frac{6}{-4} $ → but student      │
│  writes $+\frac{3}{2}$ ❌                                                    │
│     Correct: $ \frac{-2 - 4}{3 - (-1)} = \frac{-6}{4} = -\frac{3}{2} $ ✅    │
│                                                                              │
│  3. **Rise/Run confusion**:                                                  │
│     A student sees "up 3, right 2" but writes slope as $ \frac{2}{3} $ ❌    │
│     Correct: $ \frac{3}{2} $ ✅ (rise/run)                                   │
│                                                                              │
│  📌 **Tip**: Label your points as $(x_1, y_1)$ and $(x_2, y_2)$ first.       │
│  Always do *y₂ − y₁* over *x₂ − x₁*.                                         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **2. Distance Formula: Don’t Skip the Square Root!**                   │
│  **Explanation**:                                                            │
│  The distance between two points is based on the Pythagorean Theorem.        │
│  Formula:                                                                    │
│  $$                                                                          │
│  d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}                                    │
│  $$                                                                          │
│  ⚠️ **Common Errors**:                                                       │
│  - Forgetting to square the differences.                                     │
│  - Not simplifying under the square root.                                    │
│  - Sign errors when subtracting negatives.                                   │
│                                                                              │
│  **Examples of Errors**:                                                     │
│  1. **Sign mistake**:                                                        │
│     Points: $(-2, 1)$ and $(1, 5)$                                           │
│     Incorrect: $ (-2 - 1)^2 = (-3)^2 = 9 $, $ (1 - 5)^2 = (-4)^2 = 16 $ → $  │
│  \sqrt{9 + 16} = \sqrt{25} = 5 $ ✅                                          │
│     But student does $ (x_1 - x_2) = -2 - 1 = -3 $, then forgets to square   │
│  → uses $-3$ in sum ❌                                                       │
│                                                                              │
│  2. **Forgetting square root**:                                              │
│     After computing $ (4)^2 + (3)^2 = 16 + 9 = 25 $, student writes          │
│  distance = 25 ❌                                                            │
│     Correct: $ \sqrt{25} = 5 $ ✅                                            │
│                                                                              │
│  📌 **Tip**: Use a sketch! Draw the right triangle formed by the two points  │
│  to visualize rise and run.                                                  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **3. Midpoint vs. Average: It’s Both Coordinates!**                    │
│  **Explanation**:                                                            │

│  ### **Common Misconceptions in Coordinate Geometry – Clarification Guide**  │
│                                                                              │
│  #### **1. Slope Calculation: Getting Rise over Run Right**                  │
│  **Explanation**:                                                            │
│  The slope of a line measures its steepness and is calculated as *rise over  │
│  run*, or the change in *y* divided by the change in *x*.                    │
│  Formula:                                                                    │
│  $$                                                                          │
│  m = \frac{y_2 - y_1}{x_2 - x_1}                                             │
│  $$                                                                          │
│  ⚠️ **Common Errors**:                                                       │
│  - Swapping *x* and *y* in the formula.                                      │
│  - Misordering coordinates (e.g., subtracting $y_1 - y_2$ but $x_2 - x_1$).  │
│  - Sign errors when subtracting negative numbers.                            │
│                                                                              │
│  **Examples of Errors**:                                                     │
│  1. **Mixing up x and y**:                                                   │
│     Given points $(2, 3)$ and $(5, 7)$, a student calculates:                │
│     $ \frac{5 - 2}{7 - 3} = \frac{3}{4} $ ❌                                 │
│     Correct: $ \frac{7 - 3}{5 - 2} = \frac{4}{3} $ ✅                        │
│                                                                              │
│  2. **Sign error with negatives**:                                           │
│     Points: $(-1, 4)$ and $(3, -2)$                                          │
│     Incorrect: $ \frac{4 - (-2)}{-1 - 3} = \frac{6}{-4} $ → but student      │
│  writes $+\frac{3}{2}$ ❌                                                    │
│     Correct: $ \frac{-2 - 4}{3 - (-1)} = \frac{-6}{4} = -\frac{3}{2} $ ✅    │
│                                                                              │
│  3. **Rise/Run confusion**:                                                  │
│     A student sees "up 3, right 2" but writes slope as $ \frac{2}{3} $ ❌    │
│     Correct: $ \frac{3}{2} $ ✅ (rise/run)                                   │
│                                                                              │
│  📌 **Tip**: Label your points as $(x_1, y_1)$ and $(x_2, y_2)$ first.       │
│  Always do *y₂ − y₁* over *x₂ − x₁*.                                         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **2. Distance Formula: Don’t Skip the Square Root!**                   │
│  **Explanation**:                                                            │
│  The distance between two points is based on the Pythagorean Theorem.        │
│  Formula:                                                                    │
│  $$                                                                          │

│  $$                                                                          │
│  ⚠️ **Common Errors**:                                                       │
│  - Forgetting to square the differences.                                     │
│  - Not simplifying under the square root.                                    │
│  - Sign errors when subtracting negatives.                                   │
│                                                                              │
│  **Examples of Errors**:                                                     │
│  1. **Sign mistake**:                                                        │
│     Points: $(-2, 1)$ and $(1, 5)$                                           │
│     Incorrect: $ (-2 - 1)^2 = (-3)^2 = 9 $, $ (1 - 5)^2 = (-4)^2 = 16 $ → $  │
│  \sqrt{9 + 16} = \sqrt{25} = 5 $ ✅                                          │
│     But student does $ (x_1 - x_2) = -2 - 1 = -3 $, then forgets to square   │
│  → uses $-3$ in sum ❌                                                       │
│                                                                              │
│  2. **Forgetting square root**:                                              │
│     After computing $ (4)^2 + (3)^2 = 16 + 9 = 25 $, student writes          │
│  distance = 25 ❌                                                            │
│     Correct: $ \sqrt{25} = 5 $ ✅                                            │
│                                                                              │
│  📌 **Tip**: Use a sketch! Draw the right triangle formed by the two points  │
│  to visualize rise and run.                                                  │
│                                                                              │
