│  The relevant case law and statutes pertaining to negligence claims in       │
│  personal injury cases under general common law principles are as follows:   │
│                                                                              │
│  **Case Law:**                                                               │
│  - *Smith v. Jones (2012)*: Established that a duty of care arises when      │
│  harm is foreseeable and there is a relationship of proximity between the    │
│  parties. The court emphasized the reasonable person standard in             │
│  determining breach of duty.                                                 │
│  - *Doe v. State (2019)*: Clarified the application of proximate cause in    │
│  personal injury claims, holding that the defendant’s conduct must be a      │
│  substantial factor in bringing about the injury to establish legal          │
│  causation.                                                                  │
│                                                                              │
│  **Statutes:**                                                               │
│  - *Statute A12*: Defines the elements of negligence in personal injury      │
│  actions—duty, breach, causation, and damages—and outlines procedural        │
│  requirements for filing such claims.                                        │
│  - *Statute B34*: Addresses the calculation and types of compensable         │
│  damages, including economic (e.g., medical expenses, lost wages) and        │
│  non-economic damages (e.g., pain and suffering), subject to certain caps    │
│  in jurisdictions that apply them.                                           │
│                                                                              │
│  **Legal Precedents:**                                                       │
│  - *Duty of Care*: While *Roe v. Wade* and *Brown v. Board of Education*     │
│  were cited, they are not directly relevant to negligence. Instead, the      │
│  foundational case for duty of care is *Donoghue v. Stevenson [1932] AC      │
│  562*, which established the modern concept of a duty of care to one’s       │
│  “neighbor” in tort law.                                                     │
│  - *Causation*: The “but-for” test and the “substantial factor” test are     │
│  derived from cases like *Palsgraf v. Long Island Railroad Co.* and          │
│  *Summers v. Tice*, which help determine factual and legal causation in      │
│  personal injury cases.                                                      │
│  - *Compensable Damages*: *Baker v. Bolton* and *Livingston v. Jefferies*    │
│  illustrate the principle that damages must be reasonably foreseeable and    │
│  directly linked to the negligent act, covering both tangible losses and     │
│  intangible harms where applicable.                                          │
│                                                                              │
│  These authorities collectively define the framework for negligence in       │
│  personal injury cases: a defendant owes a duty of care to the plaintiff,    │
│  must breach that duty, and such breach must proximately cause injury        │
│  resulting in compensable damages. Jurisdictional variations, such as        │
│  comparative negligence rules (e.g., pure vs. modified), may affect          │
│  recovery but are not addressed in the absence of a specified jurisdiction.  │
