│  Final Answer:                                                               │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the response or outcome) and     │
│  one or more independent variables (also known as predictors or features).   │
│  In its simplest form—simple linear regression—it assumes a linear           │
│  relationship between one independent variable and the dependent variable.   │
│                                                                              │
│  The goal of linear regression is to find the best-fitting straight line     │
│  through the data points, such that the line minimizes the sum of squared    │
│  differences (residuals) between the observed values and the values          │
│  predicted by the line. This line is described by the equation:              │
│                                                                              │
│  y = β₀ + β₁x                                                                │
│                                                                              │
│  Where:                                                                      │
│  - y is the predicted value of the dependent variable,                       │
│  - x is the value of the independent variable,                               │
│  - β₀ (beta zero) is the y-intercept—the value of y when x is 0,             │
│  - β₁ (beta one) is the slope of the line—indicating how much y changes for  │
│  a one-unit increase in x.                                                   │
│                                                                              │
│  The coefficients β₀ and β₁ are estimated from the data using a method       │
│  called Ordinary Least Squares (OLS). The slope tells us the direction and   │
│  strength of the relationship: a positive slope means that as x increases,   │
│  y tends to increase, while a negative slope indicates the opposite.         │
│                                                                              │
│  Linear regression is widely used for prediction and inference. For          │
│  example, it can be used to predict house prices based on size, or to        │
│  understand how changes in advertising spending are associated with changes  │
│  in sales.                                                                   │
│                                                                              │
│  Assumptions of linear regression include linearity, independence of         │
│  errors, constant variance of errors (homoscedasticity), and normally        │
│  distributed errors—though it can still be useful even if some assumptions   │
│  are only approximately met.                                                 │
│                                                                              │
│  In summary, linear regression provides a straightforward way to quantify    │
│  and model linear relationships in data, making it one of the most commonly  │
│  used tools in statistics and machine learning.                              │

FINAL OUTPUT:
Linear regression is a statistical method used to model the relationship between a dependent variable (often called the response or outcome) and one or more independent variables (also known as predictors or features). In its simplest form—simple linear regression—it assumes a linear relationship between one independent variable and the dependent variable.

The goal of linear regression is to find the best-fitting straight line through the data points, such that the line minimizes the sum of squared differences (residuals) between the observed values and the values predicted by the line. This line is described by the equation:

y = β₀ + β₁x

Where:
- y is the predicted value of the dependent variable,
- x is the value of the independent variable,
- β₀ (beta zero) is the y-intercept—the value of y when x is 0,
- β₁ (beta one) is the slope of the line—indicating how much y changes for a one-unit increase in x.

The coefficients β₀ and β₁ are estimated from the data using a method called Ordinary Least Squares (OLS). The slope tells us the direction and strength of the relationship: a positive slope means that as x increases, y tends to increase, while a negative slope indicates the opposite.

Linear regression is widely used for prediction and inference. For example, it can be used to predict house prices based on size, or to understand how changes in advertising spending are associated with changes in sales.

Assumptions of linear regression include linearity, independence of errors, constant variance of errors (homoscedasticity), and normally distributed errors—though it can still be useful even if some assumptions are only approximately met.

In summary, linear regression provides a straightforward way to quantify and model linear relationships in data, making it one of the most commonly used tools in statistics and machine learning.
