│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $  │
│  is the variable we aim to solve for. The degree of the equation (the        │
│  highest power of $ x $) is 2, which is why it's called "quadratic" (from    │
│  the Latin *quadratus*, meaning "square").                                   │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  1. **Factoring**                                                            │
│     This method works when the quadratic can be expressed as a product of    │
│  two binomials.                                                              │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, the solutions are $ x = 2 $ and $ x = 3 $.                           │
│                                                                              │
│  2. **Completing the Square**                                                │
│     This method involves rewriting the equation in the form $ (x - h)^2 = k  │
│  $.                                                                          │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     \Rightarrow x^2 + 6x = -5                                                │
│     \Rightarrow x^2 + 6x + 9 = -5 + 9                                        │
│     \Rightarrow (x + 3)^2 = 4                                                │
│     \Rightarrow x + 3 = \pm 2                                                │
│     \Rightarrow x = -1 \text{ or } x = -5                                    │
│     $$                                                                       │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The most general method, derived from completing the square on the       │
│  standard form:                                                              │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $ b^2 - 4ac $, is called the       │
│  **discriminant**. It determines the nature of the roots:                    │
│     - If $ b^2 - 4ac > 0 $: two distinct real roots                          │
│     - If $ b^2 - 4ac = 0 $: one real root (a repeated root)                  │
│     - If $ b^2 - 4ac < 0 $: two complex roots                                │
│                                                                              │
│  ### Real-Life Applications                                                  │
│                                                                              │
│  Quadratic equations are widely used in various fields:                      │
│  - **Physics**: Modeling the trajectory of projectiles under gravity (e.g.,  │
│  a ball thrown in the air).                                                  │
│  - **Engineering**: Designing parabolic structures like satellite dishes or  │
│  bridges.                                                                    │
│  - **Economics**: Finding maximum profit or minimum cost in revenue models.  │
│  - **Geometry**: Calculating areas when dimensions are related               │
│  quadratically.                                                              │
│                                                                              │
│  ### Examples                                                                │
│                                                                              │
│  1. Solve $ x^2 - 4x + 3 = 0 $ by factoring:                                 │
│     $ (x - 1)(x - 3) = 0 $ → $ x = 1 $ or $ x = 3 $                          │
│                                                                              │
│  2. Solve $ x^2 + 4x - 5 = 0 $ using the quadratic formula:                  │
│     $ a = 1, b = 4, c = -5 $                                                 │
│     $$                                                                       │
│     x = \frac{-4 \pm \sqrt{4^2 - 4(1)(-5)}}{2(1)} = \frac{-4 \pm \sqrt{16 +  │
│  20}}{2} = \frac{-4 \pm \sqrt{36}}{2} = \frac{-4 \pm 6}{2}                   │
│     $$                                                                       │
│     So, $ x = 1 $ or $ x = -5 $                                              │
│                                                                              │
│  3. A ball is thrown upward with an initial velocity of 20 m/s. Its height   │
│  $ h $ in meters after $ t $ seconds is given by $ h = -5t^2 + 20t $. When   │
│  does it hit the ground?                                                     │
│     Set $ h = 0 $:                                                           │
│     $ -5t^2 + 20t = 0 \Rightarrow t(-5t + 20) = 0 $                          │
│     So, $ t = 0 $ (start) or $ t = 4 $ seconds (when it lands).              │

### **Explanation of Quadratic Equations**

A quadratic equation is a second-degree polynomial equation in a single variable, typically written in the standard form:

$$
ax^2 + bx + c = 0
$$

where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $ is the variable we aim to solve for. The degree of the equation (the highest power of $ x $) is 2, which is why it's called "quadratic" (from the Latin *quadratus*, meaning "square").

#### **Methods of Solving Quadratic Equations**

1. **Factoring**  
   This method works when the quadratic can be expressed as a product of two binomials.  
   *Example:*  
   $$
   x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0
   $$  
   So, the solutions are $ x = 2 $ and $ x = 3 $.

2. **Completing the Square**  
   This method involves rewriting the equation in the form $ (x - h)^2 = k $.  
   *Example:*  
   $$
   x^2 + 6x + 5 = 0  
   \Rightarrow x^2 + 6x = -5  
   \Rightarrow x^2 + 6x + 9 = -5 + 9  
   \Rightarrow (x + 3)^2 = 4  
   \Rightarrow x + 3 = \pm 2  
   \Rightarrow x = -1 \text{ or } x = -5
   $$

3. **Quadratic Formula**  
   The most general method:  
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$  
   The expression $ b^2 - 4ac $ is the **discriminant**:
   - $ > 0 $: two distinct real roots
   - $ = 0 $: one real root (repeated)
   - $ < 0 $: two complex roots

#### **Real-Life Applications**

- **Physics:** Modeling projectile motion (e.g., ball thrown in air).
- **Engineering:** Designing parabolic structures (satellite dishes, bridges).
- **Economics:** Maximizing profit or minimizing cost.
- **Geometry:** Calculating areas with quadratic relationships.

#### **Examples**

1. Solve $ x^2 - 4x + 3 = 0 $ by factoring:  
   $ (x - 1)(x - 3) = 0 $ → $ x = 1 $ or $ x = 3 $

2. Solve $ x^2 + 4x - 5 = 0 $ using the quadratic formula:  
   $ a = 1, b = 4, c = -5 $  
   $$
   x = \frac{-4 \pm \sqrt{16 + 20}}{2} = \frac{-4 \pm 6}{2}
   $$  
   So, $ x = 1 $ or $ x = -5 $

3. Ball thrown upward: $ h = -5t^2 + 20t $. When does it hit the ground?  
   Set $ h = 0 $:  
   $ -5t^2 + 20t = 0 \Rightarrow t(-5t + 20) = 0 $  
   So, $ t = 0 $ (start) or $ t = 4 $ seconds (when it lands).
