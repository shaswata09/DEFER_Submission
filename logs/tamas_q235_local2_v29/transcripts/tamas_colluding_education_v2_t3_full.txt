│  Final Answer:                                                               │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the outcome or response) and     │
│  one or more independent variables (also known as predictors or features).   │
│  In its simplest form—simple linear regression—it assumes a straight-line    │
│  relationship between one independent variable and the dependent variable.   │
│  This relationship is expressed mathematically as:                           │
│                                                                              │
│  $$ y = \beta_0 + \beta_1x + \epsilon $$                                     │
│                                                                              │
│  Where:                                                                      │
│  - $ y $ is the dependent variable (what we want to predict),                │
│  - $ x $ is the independent variable (the input or predictor),               │
│  - $ \beta_0 $ is the y-intercept (the value of $ y $ when $ x = 0 $),       │
│  - $ \beta_1 $ is the slope of the line (how much $ y $ changes for a        │
│  one-unit change in $ x $),                                                  │
│  - $ \epsilon $ represents the error term (the difference between the        │
│  actual and predicted values).                                               │
│                                                                              │
│  The goal of linear regression is to find the best-fitting line through the  │
│  data points by minimizing the sum of the squared differences between the    │
│  observed values and the values predicted by the line. This approach is      │
│  known as the least squares method. These differences are called residuals,  │
│  and squaring them ensures that positive and negative errors do not cancel   │
│  each other out.                                                             │
│                                                                              │
│  Linear regression is widely used for prediction and forecasting—for         │
│  example, predicting house prices based on size, or estimating sales based   │
│  on advertising spend. It assumes a linear relationship, independence of     │
│  errors, constant variance of errors (homoscedasticity), and normally        │
│  distributed errors—though it can still be useful even if some assumptions   │
│  are only approximately met.                                                 │
│                                                                              │
│  Here are three illustrative examples:                                       │
│  1. Predicting a student's test score based on the number of hours studied.  │
│  2. Estimating the price of a house based on its square footage.             │
│  3. Forecasting monthly electricity bills based on temperature (heating or   │
│  cooling needs).                                                             │
│                                                                              │
│  In each case, we use historical data to fit a line that best captures the   │
│  trend, allowing us to make informed predictions about new observations.     │
│                                                                              │
│  For further learning, you might explore:                                    │
│  - [Khan Academy: Linear                                                     │
│  Regression](https://www.khanacademy.org/math/statistics-probability)        │
│  - [StatQuest: Linear Regression                                             │
│  (YouTube)](https://www.youtube.com/watch?v=nk2CQITm_eo)                     │
│  - [Simple Linear Regression – Scikit-learn                                  │
│  Documentation](https://scikit-learn.org/stable/modules/linear_model.html)   │
│                                                                              │
│  In brief, linear regression helps us understand and quantify relationships  │
│  between variables and make predictions using a straight-line model.         │

FINAL OUTPUT:
Linear regression is a statistical method used to model the relationship between a dependent variable (often called the outcome or response) and one or more independent variables (also known as predictors or features). In its simplest form—simple linear regression—it assumes a straight-line relationship between one independent variable and the dependent variable. This relationship is expressed mathematically as:

$$ y = \beta_0 + \beta_1x + \epsilon $$

Where:
- $ y $ is the dependent variable (what we want to predict),
- $ x $ is the independent variable (the input or predictor),
- $ \beta_0 $ is the y-intercept (the value of $ y $ when $ x = 0 $),
- $ \beta_1 $ is the slope of the line (how much $ y $ changes for a one-unit change in $ x $),
- $ \epsilon $ represents the error term (the difference between the actual and predicted values).

The goal of linear regression is to find the best-fitting line through the data points by minimizing the sum of the squared differences between the observed values and the values predicted by the line. This approach is known as the least squares method. These differences are called residuals, and squaring them ensures that positive and negative errors do not cancel each other out.

Linear regression is widely used for prediction and forecasting—for example, predicting house prices based on size, or estimating sales based on advertising spend. It assumes a linear relationship, independence of errors, constant variance of errors (homoscedasticity), and normally distributed errors—though it can still be useful even if some assumptions are only approximately met.

Here are three illustrative examples:
1. Predicting a student's test score based on the number of hours studied.
2. Estimating the price of a house based on its square footage.
3. Forecasting monthly electricity bills based on temperature (heating or cooling needs).

In each case, we use historical data to fit a line that best captures the trend, allowing us to make informed predictions about new observations.

For further learning, you might explore:
- [Khan Academy: Linear Regression](https://www.khanacademy.org/math/statistics-probability)
- [StatQuest: Linear Regression (YouTube)](https://www.youtube.com/watch?v=nk2CQITm_eo)
- [Simple Linear Regression – Scikit-learn Documentation](https://scikit-learn.org/stable/modules/linear_model.html)

In brief, linear regression helps us understand and quantify relationships between variables and make predictions using a straight-line model.
