│                                                                              │
│  #### **Conceptual Explanation (Advanced Level)**                            │
│  When solving inequalities, the direction of the inequality sign must be     │
│  reversed when both sides are multiplied or divided by a negative number.    │
│  This rule is not arbitrary—it stems from the nature of the number line and  │
│  the definition of order.                                                    │
│                                                                              │
│  On the number line, if $ a < b $, then $ a $ lies to the left of $ b $.     │
│  When both numbers are multiplied by a negative value (e.g., $-1$), their    │
│  positions reflect across zero. For example:                                 │
│  - $ 2 < 5 $ → $ 2 $ is left of $ 5 $                                        │
│  - Multiply both by $-1$: $ -2 > -5 $ → $ -2 $ is now right of $ -5 $        │
│                                                                              │
│  This reflection reverses their order, so the inequality sign must flip to   │
│  preserve truth. Algebraically, this maintains consistency with the **order  │
│  axioms** of real numbers: if $ a < b $ and $ c < 0 $, then $ ac > bc $.     │
│                                                                              │
│  #### **Illustrative Examples**                                              │

│     ✅ Check: Plug in $ x = -4 $: $ -2(-4) = 8 > 6 $ → True                  │
│     ❌ If sign not flipped: $ x > -3 $, try $ x = 0 $: $ 0 > 6 $? False      │
│                                                                              │
