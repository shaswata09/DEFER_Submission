│  Final Answer:                                                               │
│  A linear equation is an algebraic equation in which the highest power of    │
│  the variable is 1. This means there are no squared terms, cubed terms, or   │
│  higher — just variables raised to the first power. The standard form of a   │
│  linear equation in one variable is:                                         │
│                                                                              │
│  **ax + b = 0**                                                              │
│                                                                              │
│  where *a* and *b* are constants, and *x* is the variable we want to solve   │
│  for.                                                                        │
│                                                                              │
│  For example:                                                                │
│  - 2x + 3 = 7                                                                │
│  - x – 4 = 10                                                                │
│  - 5x = 15                                                                   │
│                                                                              │
│  These are all linear equations because the variable *x* appears only to     │
│  the first power.                                                            │
│                                                                              │
│  To solve a linear equation, the goal is to **isolate the variable** on one  │
│  side of the equation using inverse operations:                              │
│  1. Add or subtract constants from both sides.                               │
│  2. Multiply or divide both sides by the coefficient of the variable.        │
│                                                                              │
│  For instance, to solve 2x + 3 = 7:                                          │
│  - Subtract 3 from both sides: 2x = 4                                        │
│  - Divide both sides by 2: x = 2                                             │
│                                                                              │
│  Linear equations are widely used in real life. For example:                 │
│  - Calculating total costs (e.g., cell phone plans with a base fee plus      │
│  usage charges)                                                              │
│  - Determining distances and travel times at constant speeds                 │
│  - Predicting earnings based on hourly wages                                 │
│                                                                              │
│  In short, linear equations model relationships where a change in one        │
│  quantity results in a proportional change in another.                       │
│                                                                              │

Examples of linear equations include:
- 2x + 3 = 7
- x – 4 = 10
- 5x = 15

To solve a linear equation, the goal is to **isolate the variable** using inverse operations:
1. Perform addition or subtraction on both sides to move constants.
2. Perform multiplication or division to eliminate the coefficient of the variable.

For example, solving 2x + 3 = 7:
- Subtract 3 from both sides: 2x = 4
- Divide both sides by 2: x = 2

Linear equations are widely used in everyday situations such as:
- Calculating total costs (e.g., monthly phone bills with fixed and variable charges)
- Determining travel time at constant speed
- Predicting earnings based on hourly wages

They model relationships where a change in one quantity results in a proportional change in another, making them foundational for both algebra and real-world problem-solving.
