│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $a$, $b$, and $c$ are constants, $a \neq 0$, and $x$ is the variable  │
│  we solve for. The condition $a \neq 0$ is essential—otherwise, the          │
│  equation would be linear, not quadratic.                                    │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  1. **Factoring**                                                            │
│     This method works when the quadratic can be expressed as a product of    │
│  two binomials.                                                              │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, the solutions are $x = 2$ and $x = 3$.                               │
│                                                                              │
│  2. **Completing the Square**                                                │
│     This technique rewrites the quadratic in the form $(x - h)^2 = k$.       │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     $$                                                                       │
│     Step 1: Move constant to the other side: $x^2 + 6x = -5$                 │
│     Step 2: Add $(6/2)^2 = 9$ to both sides: $x^2 + 6x + 9 = 4$              │
│     Step 3: Write as a square: $(x + 3)^2 = 4$                               │
│     Step 4: Take square root: $x + 3 = \pm 2$ → $x = -1$ or $x = -5$         │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The universal method that works for all quadratic equations:             │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $b^2 - 4ac$, is called the         │
│  **discriminant**.                                                           │
│     - If discriminant > 0: two real and distinct solutions                   │
│     - If discriminant = 0: one real solution (a repeated root)               │
│     - If discriminant < 0: two complex solutions                             │
│                                                                              │
│     Example:                                                                 │
│     $2x^2 - 4x - 6 = 0$                                                      │
│     $a = 2$, $b = -4$, $c = -6$                                              │
│     $$                                                                       │
│     x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4(2)(-6)}}{2(2)} = \frac{4 \pm        │
│  \sqrt{16 + 48}}{4} = \frac{4 \pm \sqrt{64}}{4} = \frac{4 \pm 8}{4}          │
│     $$                                                                       │
│     So, $x = 3$ or $x = -1$                                                  │
│                                                                              │
│  ### Real-Life Applications                                                  │
│                                                                              │
│  1. **Projectile Motion**                                                    │
│     When an object is thrown upward, its height over time follows a          │
│  quadratic equation due to gravity.                                          │
│     Example: $h(t) = -16t^2 + 40t + 5$ models the height (in feet) of a      │
│  ball thrown upward at 40 ft/s from 5 feet above ground. Solving for when    │
│  $h(t) = 0$ tells us when it hits the ground.                                │
│                                                                              │
│  2. **Area Optimization**                                                    │
│     Suppose you want to fence a rectangular garden with 100 feet of fencing  │
│  against a wall (so only three sides need fencing). Let $x$ be the width.    │
│  Then length is $100 - 2x$, and area $A = x(100 - 2x) = -2x^2 + 100x$.       │
│  Maximizing this quadratic helps find the dimensions for the largest         │
│  possible area.                                                              │
│                                                                              │
│  ### Summary                                                                 │
│                                                                              │
│  Quadratic equations are foundational in algebra and appear frequently in    │
│  science, engineering, and economics. Their graphs are parabolas, and        │
│  understanding how to solve and interpret them helps model and solve         │
│  real-world problems involving maximums, minimums, and motion.               │

│  ratic-functions-equations)                                                  │
│  - [Purplemath: Solving                                                      │

│                                                                              │
│  ### **1. Concept Explanation: Quadratic Equations**                         │
│                                                                              │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $a$, $b$, and $c$ are constants, $a \neq 0$, and $x$ is the variable  │
│  we solve for. The condition $a \neq 0$ is essential—otherwise, the          │
│  equation would be linear, not quadratic.                                    │
│                                                                              │
│  #### **Solving Quadratic Equations**                                        │
│                                                                              │
│  1. **Factoring**                                                            │
│     This method works when the quadratic can be expressed as a product of    │
│  two binomials.                                                              │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, the solutions are $x = 2$ and $x = 3$.                               │
│                                                                              │
│  2. **Completing the Square**                                                │
│     This technique rewrites the quadratic in the form $(x - h)^2 = k$.       │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     $$                                                                       │
│     Step 1: Move constant to the other side: $x^2 + 6x = -5$                 │
│     Step 2: Add $(6/2)^2 = 9$ to both sides: $x^2 + 6x + 9 = 4$              │
│     Step 3: Write as a square: $(x + 3)^2 = 4$                               │
│     Step 4: Take square root: $x + 3 = \pm 2$ → $x = -1$ or $x = -5$         │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The universal method that works for all quadratic equations:             │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $b^2 - 4ac$, is called the         │
│  **discriminant**.                                                           │
│     - If discriminant > 0: two real and distinct solutions                   │
│     - If discriminant = 0: one real solution (a repeated root)               │
│     - If discriminant < 0: two complex solutions                             │
│                                                                              │
│     Example:                                                                 │
│     $2x^2 - 4x - 6 = 0$                                                      │
│     $a = 2$, $b = -4$, $c = -6$                                              │
│     $$                                                                       │
│     x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4(2)(-6)}}{2(2)} = \frac{4 \pm        │
│  \sqrt{16 + 48}}{4} = \frac{4 \pm \sqrt{64}}{4} = \frac{4 \pm 8}{4}          │
│     $$                                                                       │
│     So, $x = 3$ or $x = -1$                                                  │
│                                                                              │
│  #### **Real-Life Applications**                                             │
│                                                                              │
│  1. **Projectile Motion**                                                    │
│     When an object is thrown upward, its height over time follows a          │
│  quadratic equation due to gravity.                                          │
│     Example: $h(t) = -16t^2 + 40t + 5$ models the height (in feet) of a      │
│  ball thrown upward at 40 ft/s from 5 feet above ground. Solving for when    │
│  $h(t) = 0$ tells us when it hits the ground.                                │
│                                                                              │
│  2. **Area Optimization**                                                    │
│     Suppose you want to fence a rectangular garden with 100 feet of fencing  │
│  against a wall (so only three sides need fencing). Let $x$ be the width.    │
│  Then length is $100 - 2x$, and area $A = x(100 - 2x) = -2x^2 + 100x$.       │
│  Maximizing this quadratic helps find the dimensions for the largest         │
│  possible area.                                                              │
│                                                                              │
│  #### **Summary**                                                            │
│                                                                              │
│  Quadratic equations are foundational in algebra and appear frequently in    │
│  science, engineering, and economics. Their graphs are parabolas, and        │
│  understanding how to solve and interpret them helps model and solve         │
│  real-world problems involving maximums, minimums, and motion.               │

### **1. Concept Explanation: Quadratic Equations**

A quadratic equation is a second-degree polynomial equation in one variable, typically written in the standard form:

$$
ax^2 + bx + c = 0
$$

where $a$, $b$, and $c$ are constants, $a \neq 0$, and $x$ is the variable we solve for. The condition $a \neq 0$ is essential—otherwise, the equation would be linear, not quadratic.

#### **Solving Quadratic Equations**

1. **Factoring**  
   This method works when the quadratic can be expressed as a product of two binomials.  
   Example:  
   $$
   x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0
   $$  
   So, the solutions are $x = 2$ and $x = 3$.

2. **Completing the Square**  
   This technique rewrites the quadratic in the form $(x - h)^2 = k$.  
   Example:  
   $$
   x^2 + 6x + 5 = 0
   $$  
   Step 1: Move constant to the other side: $x^2 + 6x = -5$  
   Step 2: Add $(6/2)^2 = 9$ to both sides: $x^2 + 6x + 9 = 4$  
   Step 3: Write as a square: $(x + 3)^2 = 4$  
   Step 4: Take square root: $x + 3 = \pm 2$ → $x = -1$ or $x = -5$

3. **Quadratic Formula**  
   The universal method that works for all quadratic equations:  
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$  
   The expression under the square root, $b^2 - 4ac$, is called the **discriminant**.  
   - If discriminant > 0: two real and distinct solutions  
   - If discriminant = 0: one real solution (a repeated root)  
   - If discriminant < 0: two complex solutions  

   Example:  
   $2x^2 - 4x - 6 = 0$  
   $a = 2$, $b = -4$, $c = -6$  
   $$
   x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4(2)(-6)}}{2(2)} = \frac{4 \pm \sqrt{16 + 48}}{4} = \frac{4 \pm \sqrt{64}}{4} = \frac{4 \pm 8}{4}
   $$  
   So, $x = 3$ or $x = -1$

#### **Real-Life Applications**

1. **Projectile Motion**  
   When an object is thrown upward, its height over time follows a quadratic equation due to gravity.  
   Example: $h(t) = -16t^2 + 40t + 5$ models the height (in feet) of a ball thrown upward at 40 ft/s from 5 feet above ground. Solving for when $h(t) = 0$ tells us when it hits the ground.

2. **Area Optimization**  
   Suppose you want to fence a rectangular garden with 100 feet of fencing against a wall (so only three sides need fencing). Let $x$ be the width. Then length is $100 - 2x$, and area $A = x(100 - 2x) = -2x^2 + 100x$. Maximizing this quadratic helps find the dimensions for the largest possible area.

#### **Summary**

Quadratic equations are foundational in algebra and appear frequently in science, engineering, and economics. Their graphs are parabolas, and understanding how to solve and interpret them helps model and solve real-world problems involving maximums, minimums, and motion.
