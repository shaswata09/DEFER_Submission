│  Final Answer:                                                               │
│  The **mean** and **median** are both measures of central tendency used in   │
│  statistics to describe the center of a data set, but they do so in          │
│  different ways and are appropriate in different contexts.                   │
│                                                                              │
│  ### Mean – Definition and Use                                               │
│  The **mean**, often referred to as the arithmetic average, is calculated    │
│  by summing all the values in a data set and dividing by the total number    │
│  of values. The formula is:                                                  │
│                                                                              │
│  $$                                                                          │
│  \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}                                  │
│  $$                                                                          │
│                                                                              │
│  where $x_i$ represents each value in the data set and $n$ is the total      │
│  number of values.                                                           │
│                                                                              │
│  The mean is most useful when the data is symmetrically distributed and      │
│  does not contain extreme outliers. It takes into account every value in     │
│  the data set, making it sensitive to extreme values (very high or very low  │
│  observations).                                                              │
│                                                                              │
│  **Example**:                                                                │
│  For the data set: 2, 4, 6, 8, 10                                            │
│  Mean = (2 + 4 + 6 + 8 + 10) / 5 = 30 / 5 = **6**                            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Median – Definition and Use                                             │
│  The **median** is the middle value in an ordered data set. To find it,      │
│  arrange the data in ascending order. If the number of observations is odd,  │
│  the median is the middle number. If even, it is the average of the two      │
│  middle numbers.                                                             │
│                                                                              │
│  The median is less affected by outliers and skewed data, making it a        │
│  better measure of central tendency in such cases.                           │
│                                                                              │
│  **Example (odd count)**:                                                    │
│  Data: 3, 5, 7, 9, 11                                                        │
│  Ordered: same → median = **7** (middle value)                               │
│                                                                              │
│  **Example (even count)**:                                                   │
│  Data: 3, 5, 7, 9                                                            │
│  Ordered: same → median = (5 + 7) / 2 = **6**                                │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Comparison: Mean vs Median                                              │
│                                                                              │
│  | Feature | Mean | Median |                                                 │
│  |--------|------|--------|                                                  │
│  | **Definition** | Average of all values | Middle value when data is        │
│  ordered |                                                                   │
│  | **Sensitivity to Outliers** | High – influenced by extreme values | Low   │
│  – resistant to outliers |                                                   │
│  | **Use Case** | Symmetric distributions, interval/ratio data | Skewed      │
│  distributions, ordinal data |                                               │
│  | **Calculation** | Requires all values | Only depends on position |        │
│  | **Mathematical Properties** | Used in further statistical analysis        │
│  (e.g., variance) | Robust, but less amenable to algebraic treatment |       │
│                                                                              │
│  **Key Difference**:                                                         │
│  The mean can be "pulled" toward extreme values, while the median remains    │
│  stable. This makes the median a better representation of the "typical"      │
│  value in skewed distributions.                                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Examples Illustrating When to Use Each                                  │
│                                                                              │
│  1. **Household Income in a Neighborhood**                                   │
│     Data (in thousands): 40, 45, 50, 55, 60, 65, **500** (one millionaire)   │
│     - Mean = (40+45+50+55+60+65+500)/7 ≈ **116.4**                           │
│     - Median = **55**                                                        │
│     → The mean is misleadingly high due to the outlier. The median better    │
│  represents the typical income.                                              │
│                                                                              │
│  2. **Test Scores in a Class**                                               │
│     Data: 70, 72, 75, 76, 78, 80, 82 (symmetric)                             │
│     - Mean = 76.14                                                           │
│     - Median = 76                                                            │
│     → Both are nearly identical. Either can be used, but the mean is         │
│  preferred for further analysis.                                             │
│                                                                              │
│  3. **Home Prices in a City**                                                │
│     Most homes cost $200K–$300K, but a few luxury homes cost $2M+.           │
│     → The median home price is commonly reported because it reflects what a  │
│  typical buyer can expect, unlike the inflated mean.                         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│  - Use the **mean** when data is symmetric and free of significant           │
│  outliers.                                                                   │
│  - Use the **median** when data is skewed or contains outliers.              │
│  - The median is **robust**; the mean is **efficient** but sensitive.        │
│                                                                              │

│  ### **1. Comparison of Mean vs Median**                                     │
│                                                                              │
│  The **mean** and **median** are both measures of central tendency used in   │
│  statistics to describe the center of a data set, but they do so in          │
│  different ways and are appropriate in different contexts.                   │
│                                                                              │
│  #### **Mean – Definition and Use**                                          │
│  The **mean**, often referred to as the arithmetic average, is calculated    │
│  by summing all the values in a data set and dividing by the total number    │
│  of values. The formula is:                                                  │
│                                                                              │
│  $$                                                                          │
│  \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}                                  │
│  $$                                                                          │
│                                                                              │
│  where $x_i$ represents each value in the data set and $n$ is the total      │
│  number of values.                                                           │
│                                                                              │
│  The mean is most useful when the data is symmetrically distributed and      │
│  does not contain extreme outliers. It takes into account every value in     │
│  the data set, making it sensitive to extreme values (very high or very low  │
│  observations).                                                              │
│                                                                              │
│  **Example**:                                                                │
│  For the data set: 2, 4, 6, 8, 10                                            │
│  Mean = (2 + 4 + 6 + 8 + 10) / 5 = 30 / 5 = **6**                            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Median – Definition and Use**                                        │
│  The **median** is the middle value in an ordered data set. To find it,      │
│  arrange the data in ascending order. If the number of observations is odd,  │
│  the median is the middle number. If even, it is the average of the two      │
│  middle numbers.                                                             │
│                                                                              │
│  The median is less affected by outliers and skewed data, making it a        │
│  better measure of central tendency in such cases.                           │
│                                                                              │
│  **Example (odd count)**:                                                    │
│  Data: 3, 5, 7, 9, 11                                                        │
│  Ordered: same → median = **7** (middle value)                               │
│                                                                              │
│  **Example (even count)**:                                                   │
│  Data: 3, 5, 7, 9                                                            │
│  Ordered: same → median = (5 + 7) / 2 = **6**                                │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Comparison: Mean vs Median**                                         │
│                                                                              │
│  | Feature | Mean | Median |                                                 │
│  |--------|------|--------|                                                  │
│  | **Definition** | Average of all values | Middle value when data is        │
│  ordered |                                                                   │
│  | **Sensitivity to Outliers** | High – influenced by extreme values | Low   │
│  – resistant to outliers |                                                   │
│  | **Use Case** | Symmetric distributions, interval/ratio data | Skewed      │
│  distributions, ordinal data |                                               │
│  | **Calculation** | Requires all values | Only depends on position |        │
│  | **Mathematical Properties** | Used in further statistical analysis        │
│  (e.g., variance) | Robust, but less amenable to algebraic treatment |       │
│                                                                              │
│  **Key Difference**:                                                         │
│  The mean can be "pulled" toward extreme values, while the median remains    │
│  stable. This makes the median a better representation of the "typical"      │
│  value in skewed distributions.                                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Examples Illustrating When to Use Each**                             │
│                                                                              │
│  1. **Household Income in a Neighborhood**                                   │
│     Data (in thousands): 40, 45, 50, 55, 60, 65, **500** (one millionaire)   │
│     - Mean = (40+45+50+55+60+65+500)/7 ≈ **116.4**                           │
│     - Median = **55**                                                        │
│     → The mean is misleadingly high due to the outlier. The median better    │
│  represents the typical income.                                              │
│                                                                              │
│  2. **Test Scores in a Class**                                               │
│     Data: 70, 72, 75, 76, 78, 80, 82 (symmetric)                             │
│     - Mean = 76.14                                                           │
│     - Median = 76                                                            │
│     → Both are nearly identical. Either can be used, but the mean is         │
│  preferred for further analysis.                                             │
│                                                                              │
│  3. **Home Prices in a City**                                                │
│     Most homes cost $200K–$300K, but a few luxury homes cost $2M+.           │
│     → The median home price is commonly reported because it reflects what a  │
│  typical buyer can expect, unlike the inflated mean.                         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Summary**                                                            │
│  - Use the **mean** when data is symmetric and free of significant           │
│  outliers.                                                                   │
│  - Use the **median** when data is skewed or contains outliers.              │
│  - The median is **robust**; the mean is **efficient** but sensitive.        │
│                                                                              │

### **1. Comparison of Mean vs Median**

The **mean** and **median** are both measures of central tendency used in statistics to describe the center of a data set, but they do so in different ways and are appropriate in different contexts.

#### **Mean – Definition and Use**
The **mean**, often referred to as the arithmetic average, is calculated by summing all the values in a data set and dividing by the total number of values. The formula is:

$$
\text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}
$$

where $x_i$ represents each value in the data set and $n$ is the total number of values.

The mean is most useful when the data is symmetrically distributed and does not contain extreme outliers. It takes into account every value in the data set, making it sensitive to extreme values (very high or very low observations).

**Example**:  
For the data set: 2, 4, 6, 8, 10  
Mean = (2 + 4 + 6 + 8 + 10) / 5 = 30 / 5 = **6**

---

#### **Median – Definition and Use**
The **median** is the middle value in an ordered data set. To find it, arrange the data in ascending order. If the number of observations is odd, the median is the middle number. If even, it is the average of the two middle numbers.

The median is less affected by outliers and skewed data, making it a better measure of central tendency in such cases.

**Example (odd count)**:  
Data: 3, 5, 7, 9, 11  
Ordered: same → median = **7** (middle value)

**Example (even count)**:  
Data: 3, 5, 7, 9  
Ordered: same → median = (5 + 7) / 2 = **6**

---

#### **Comparison: Mean vs Median**

| Feature | Mean | Median |
|--------|------|--------|
| **Definition** | Average of all values | Middle value when data is ordered |
| **Sensitivity to Outliers** | High – influenced by extreme values | Low – resistant to outliers |
| **Use Case** | Symmetric distributions, interval/ratio data | Skewed distributions, ordinal data |
| **Calculation** | Requires all values | Only depends on position |
| **Mathematical Properties** | Used in further statistical analysis (e.g., variance) | Robust, but less amenable to algebraic treatment |

**Key Difference**:  
The mean can be "pulled" toward extreme values, while the median remains stable. This makes the median a better representation of the "typical" value in skewed distributions.

---

#### **Examples Illustrating When to Use Each**

1. **Household Income in a Neighborhood**  
   Data (in thousands): 40, 45, 50, 55, 60, 65, **500** (one millionaire)  
   - Mean = (40+45+50+55+60+65+500)/7 ≈ **116.4**  
   - Median = **55**  
   → The mean is misleadingly high due to the outlier. The median better represents the typical income.

2. **Test Scores in a Class**  
   Data: 70, 72, 75, 76, 78, 80, 82 (symmetric)  
   - Mean = 76.14  
   - Median = 76  
   → Both are nearly identical. Either can be used, but the mean is preferred for further analysis.

3. **Home Prices in a City**  
   Most homes cost $200K–$300K, but a few luxury homes cost $2M+.  
   → The median home price is commonly reported because it reflects what a typical buyer can expect, unlike the inflated mean.

---

#### **Summary**
- Use the **mean** when data is symmetric and free of significant outliers.
- Use the **median** when data is skewed or contains outliers.
- The median is **robust**; the mean is **efficient** but sensitive.
