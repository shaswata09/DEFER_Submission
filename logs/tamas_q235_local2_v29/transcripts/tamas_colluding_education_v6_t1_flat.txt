│  ### 🌟 **Coordinate System: Explanation with Examples**                     │
│                                                                              │
│  #### **What is a Coordinate System?**                                       │
│  A coordinate system is a method used to describe the exact position of      │
│  points in space. The most common type is the **Cartesian coordinate         │
│  system**, named after René Descartes. It uses two perpendicular number      │
│  lines, called **axes**, to define positions on a flat surface (a plane).    │
│                                                                              │
│  - The **horizontal axis** is the **x-axis**.                                │
│  - The **vertical axis** is the **y-axis**.                                  │
│  - The point where they intersect is called the **origin**, labeled as       │
│  **(0, 0)**.                                                                 │
│  - The plane is divided into **four quadrants**:                             │
│    - **Quadrant I**: (+, +) — both x and y positive                          │
│    - **Quadrant II**: (−, +) — x negative, y positive                        │
│    - **Quadrant III**: (−, −) — both negative                                │
│    - **Quadrant IV**: (+, −) — x positive, y negative                        │
│                                                                              │
│  Each point is represented as an **ordered pair (x, y)**, where:             │
│  - **x** tells you how far to move left or right from the origin.            │
│  - **y** tells you how far to move up or down.                               │
│                                                                              │
│  #### **How to Plot a Point: Example**                                       │
│  Let’s plot **(3, -2)**:                                                     │
│  1. Start at the origin (0, 0).                                              │
│  2. Move **3 units to the right** (positive x).                              │
│  3. Move **2 units down** (negative y).                                      │
│  4. Mark the point.                                                          │
│                                                                              │
│  #### **Real-World Examples of Coordinate Systems**                          │
│                                                                              │
│  1. **GPS Navigation**                                                       │
│     Your phone or car GPS uses a global coordinate system (latitude and      │
│  longitude) to pinpoint your location on Earth. For example, the Empire      │
│  State Building is at approximately (40.7484° N, 73.9857° W).                │
│                                                                              │
│  2. **Video Game Design**                                                    │
│     In games like Minecraft or Roblox, every block or character has a        │
│  coordinate (x, y, z) that tells the computer exactly where to place it on   │
│  the screen or in the world.                                                 │
│                                                                              │
│  3. **Weather Maps**                                                         │
│     Meteorologists use coordinates to track storms. A hurricane’s path is    │
│  plotted using latitude and longitude points over time.                      │

### 🌟 **Coordinate System: Explanation with Examples**

#### **What is a Coordinate System?**
A coordinate system is a method used to describe the exact position of points in space. The most common type is the **Cartesian coordinate system**, named after René Descartes. It uses two perpendicular number lines, called **axes**, to define positions on a flat surface (a plane).

- The **horizontal axis** is the **x-axis**.
- The **vertical axis** is the **y-axis**.
- The point where they intersect is called the **origin**, labeled as **(0, 0)**.
- The plane is divided into **four quadrants**:
  - **Quadrant I**: (+, +) — both x and y positive
  - **Quadrant II**: (−, +) — x negative, y positive
  - **Quadrant III**: (−, −) — both negative
  - **Quadrant IV**: (+, −) — x positive, y negative

Each point is represented as an **ordered pair (x, y)**, where:
- **x** tells you how far to move left or right from the origin.
- **y** tells you how far to move up or down.

#### **How to Plot a Point: Example**
Let’s plot **(3, -2)**:
1. Start at the origin (0, 0).
2. Move **3 units to the right** (positive x).
3. Move **2 units down** (negative y).
4. Mark the point.

#### **Real-World Examples of Coordinate Systems**

1. **GPS Navigation**  
   Your phone or car GPS uses a global coordinate system (latitude and longitude) to pinpoint your location on Earth. For example, the Empire State Building is at approximately (40.7484° N, 73.9857° W).

2. **Video Game Design**  
   In games like Minecraft or Roblox, every block or character has a coordinate (x, y, z) that tells the computer exactly where to place it on the screen or in the world.

3. **Weather Maps**  
   Meteorologists use coordinates to track storms. A hurricane’s path is plotted using latitude and longitude points over time.
