│  The coordinate system, specifically the Cartesian coordinate system, is a   │
│  method used to locate points on a plane using two perpendicular number      │
│  lines: the x-axis (horizontal) and the y-axis (vertical). These axes        │
│  intersect at a point called the **origin**, which has coordinates (0, 0).   │
│                                                                              │
│  The plane is divided into four regions called **quadrants**:                │
│  - **Quadrant I**: Top-right, where both x and y are positive (+, +)         │
│  - **Quadrant II**: Top-left, where x is negative and y is positive (−, +)   │
│  - **Quadrant III**: Bottom-left, where both x and y are negative (−, −)     │
│  - **Quadrant IV**: Bottom-right, where x is positive and y is negative (+,  │
│  −)                                                                          │
│                                                                              │
│  Each point on the plane is represented by an **ordered pair** (x, y),       │
│  where:                                                                      │
│  - The **first number (x)** tells you how far to move left or right from     │
│  the origin along the x-axis.                                                │
│  - The **second number (y)** tells you how far to move up or down from the   │
│  origin along the y-axis.                                                    │
│                                                                              │
│  ### Example 1: Plotting the point (3, 4)                                    │

### 📌 What Is a Coordinate System?

We use a **Cartesian coordinate plane** to locate points in two dimensions. Here’s how it works:

- **Two perpendicular lines** form the axes:
  - The **x-axis** runs horizontally (left-right).
  - The **y-axis** runs vertically (up-down).
- The point where they cross is the **origin**, labeled (0, 0).
- The plane is divided into **four quadrants**:
  - Quadrant I: (+, +) — both x and y positive
  - Quadrant II: (−, +) — x negative, y positive
  - Quadrant III: (−, −) — both negative
  - Quadrant IV: (+, −) — x positive, y negative

Each point is written as an **ordered pair (x, y)**.

#### 🔹 Example 1: Plotting (3, 4)
- Start at the origin.
- Move **3 units right** (positive x).
- Move **4 units up** (positive y).
- That’s where (3, 4) lives — in Quadrant I.

#### 🔹 Example 2: Identifying (−2, 5)
- Move **2 units left** (negative x).
- Move **5 units up** (positive y).
- This point is in Quadrant II.

With a little practice, you’ll be plotting and interpreting points like a pro!
