│  ### 🔹 What is the **Mean**?                                                │
│                                                                              │
│  The **mean** (also called the average) is the sum of all values in a data   │
│  set divided by the total number of values.                                  │
│                                                                              │
│  **Formula:**                                                                │
│  \[                                                                          │
│  \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}                                  │
│  \]                                                                          │
│  Where:                                                                      │
│  - \(x_i\) = each individual value                                           │
│  - \(n\) = total number of values                                            │
│                                                                              │
│  **Example 1:**                                                              │
│  Data: 4, 6, 8, 10, 12                                                       │
│  \[                                                                          │
│  \text{Mean} = \frac{4 + 6 + 8 + 10 + 12}{5} = \frac{40}{5} = 8              │
│  \]                                                                          │
│                                                                              │
│  **Example 2:**                                                              │
│  Data: 2, 3, 3, 5, 7, 10                                                     │
│  \[                                                                          │
│  \text{Mean} = \frac{2 + 3 + 3 + 5 + 7 + 10}{6} = \frac{30}{6} = 5           │
│  \]                                                                          │
│                                                                              │
│  ✅ The mean uses every data point, so it's sensitive to **outliers**        │
│  (extreme values).                                                           │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 🔹 What is the **Median**?                                              │
│                                                                              │
│  The **median** is the middle value in a data set when the values are        │
│  arranged in order. If there's an even number of values, it's the average    │
│  of the two middle numbers.                                                  │
│                                                                              │
│  **Steps to find median:**                                                   │
│  1. Sort the data from smallest to largest.                                  │
│  2. If \(n\) is odd → median = middle value.                                 │
│  3. If \(n\) is even → median = average of the two middle values.            │
│                                                                              │
│  **Example 1 (odd count):**                                                  │
│  Data: 3, 5, 7, 9, 11                                                        │
│  Sorted: 3, 5, 7, 9, 11 → middle value is **7** → median = 7                 │
│                                                                              │
│  **Example 2 (even count):**                                                 │
│  Data: 2, 4, 6, 8                                                            │
│  Sorted: 2, 4, 6, 8 → middle two: 4 and 6 → \(\frac{4 + 6}{2} = 5\) →        │
│  median = 5                                                                  │
│                                                                              │
│  ✅ The median is **resistant to outliers**, making it useful when data is   │
│  skewed.                                                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 🔸 Key Differences Between Mean and Median                              │
│                                                                              │
│  | Feature | **Mean** | **Median** |                                         │
│  |--------|---------|----------|                                             │
│  | **Definition** | Average of all values | Middle value in ordered list |   │
│  | **Affected by outliers?** | ✅ Yes | ❌ No (robust) |                     │
│  | **Use case** | Symmetric data, precise analysis | Skewed data, income,    │
│  house prices |                                                              │
│  | **Calculation** | Uses all data points | Depends only on position |       │
│  | **Data type** | Best for interval/ratio data | Works with ordinal data    │

│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 📊 When to Use Which?                                                   │
│                                                                              │
│  - **Use the Mean when:**                                                    │
│    - Data is symmetric (bell-shaped).                                        │
│    - You need a precise measure that uses all values.                        │
│    - Outliers are not a concern.                                             │
│    - Example: Average test scores in a class with no extreme values.         │
│                                                                              │
│  - **Use the Median when:**                                                  │
│    - Data is skewed (e.g., income, home prices).                             │
│    - There are extreme values that could distort the average.                │
│    - Example: Median household income in a city—few billionaires won’t skew  │
│  it.                                                                         │
│                                                                              │
│  **Real-World Example:**                                                     │

│  ### **Comparison of 'Mean' vs 'Median'**                                    │
│                                                                              │
│  The **mean** and **median** are both measures of central tendency used to   │
│  describe the center of a data set, but they differ in calculation,          │
│  sensitivity to data values, and appropriate use cases.                      │
│                                                                              │
│  #### **Definition and Formula**                                             │
│                                                                              │
│  - **Mean**:                                                                 │
│    The mean (or arithmetic average) is calculated by summing all values in   │
│  a data set and dividing by the number of values.                            │
│    **Formula**:                                                              │
│    \[                                                                        │
│    \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}                                │
│    \]                                                                        │
│    Where \(x_i\) represents each value and \(n\) is the total number of      │
│  values.                                                                     │
│                                                                              │
│    **Example**:                                                              │
│    Data: 4, 6, 8, 10, 12                                                     │
│    \[                                                                        │
│    \text{Mean} = \frac{4 + 6 + 8 + 10 + 12}{5} = \frac{40}{5} = 8            │
│    \]                                                                        │
│                                                                              │
│  - **Median**:                                                               │
│    The median is the middle value when data is arranged in ascending or      │
│  descending order. If there is an even number of observations, the median    │
│  is the average of the two middle values.                                    │
│                                                                              │
│    **Steps**:                                                                │
│    1. Sort the data.                                                         │
│    2. If \(n\) is odd → median = middle value.                               │
│    3. If \(n\) is even → median = average of the two central values.         │
│                                                                              │
│    **Example (odd)**:                                                        │
│    Data: 3, 5, 7, 9, 11 → median = **7**                                     │
│    **Example (even)**:                                                       │
│    Data: 2, 4, 6, 8 → median = \(\frac{4 + 6}{2} = 5\)                       │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Key Differences**                                                    │
│                                                                              │
│  | Feature | **Mean** | **Median** |                                         │
│  |--------|---------|----------|                                             │
│  | **Definition** | Arithmetic average | Middle value in ordered data |      │
│  | **Sensitivity to Outliers** | ✅ Highly sensitive | ❌ Resistant          │
│  (robust) |                                                                  │
│  | **Use Case** | Symmetric, normally distributed data | Skewed              │
│  distributions or ordinal data |                                             │
│  | **Calculation Basis** | Uses all data points | Depends on position, not   │
│  magnitude |                                                                 │
│  | **Data Type Suitability** | Interval/ratio data | Ordinal, interval,      │
│  ratio |                                                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **When to Use Each**                                                   │
│                                                                              │
│  - **Use Mean When**:                                                        │
│    - Data is symmetric with no extreme values.                               │
│    - You need a precise measure that incorporates every data point.          │
│    - Example: Average test scores in a class where most students scored      │
│  similarly.                                                                  │
│                                                                              │
│  - **Use Median When**:                                                      │
│    - Data is skewed (e.g., income, home prices).                             │
│    - Outliers are present and could distort the average.                     │
│    - Example: Median household income in a region—few billionaires won’t     │
│  inflate the typical value.                                                  │
│                                                                              │
│  **Real-World Example**:                                                     │
│  Incomes: $30k, $35k, $40k, $45k, $1,000,000                                 │
│  - **Mean** = $230,000 → misleading due to one high income.                  │
│  - **Median** = $40,000 → better reflects the typical income.                │
│                                                                              │
│  Thus, **median is more representative** in skewed data.                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### **Summary Insights**                                                   │
│  - In symmetric distributions: **mean ≈ median**                             │
│  - In right-skewed (positive skew): **mean > median**                        │
│  - In left-skewed (negative skew): **mean < median**                         │
│  - The **mean** represents the "balancing point" of data.                    │
│  - The **median** represents the "50th percentile" or midpoint.              │

### **Comparison of 'Mean' vs 'Median'**

The **mean** and **median** are both measures of central tendency used to describe the center of a data set, but they differ in calculation, sensitivity to data values, and appropriate use cases.

#### **Definition and Formula**

- **Mean**:  
  The mean (or arithmetic average) is calculated by summing all values in a data set and dividing by the number of values.  
  **Formula**:  
  \[
  \text{Mean} = \frac{\sum_{i=1}^{n} x_i}{n}
  \]  
  Where \(x_i\) represents each value and \(n\) is the total number of values.

  **Example**:  
  Data: 4, 6, 8, 10, 12  
  \[
  \text{Mean} = \frac{4 + 6 + 8 + 10 + 12}{5} = \frac{40}{5} = 8
  \]

- **Median**:  
  The median is the middle value when data is arranged in ascending or descending order. If there is an even number of observations, the median is the average of the two middle values.

  **Steps**:
  1. Sort the data.
  2. If \(n\) is odd → median = middle value.
  3. If \(n\) is even → median = average of the two central values.

  **Example (odd)**:  
  Data: 3, 5, 7, 9, 11 → median = **7**  
  **Example (even)**:  
  Data: 2, 4, 6, 8 → median = \(\frac{4 + 6}{2} = 5\)

---

#### **Key Differences**

| Feature | **Mean** | **Median** |
|--------|---------|----------|
| **Definition** | Arithmetic average | Middle value in ordered data |
| **Sensitivity to Outliers** | ✅ Highly sensitive | ❌ Resistant (robust) |
| **Use Case** | Symmetric, normally distributed data | Skewed distributions or ordinal data |
| **Calculation Basis** | Uses all data points | Depends on position, not magnitude |
| **Data Type Suitability** | Interval/ratio data | Ordinal, interval, ratio |

---

#### **When to Use Each**

- **Use Mean When**:
  - Data is symmetric with no extreme values.
  - You need a precise measure that incorporates every data point.
  - Example: Average test scores in a class where most students scored similarly.

- **Use Median When**:
  - Data is skewed (e.g., income, home prices).
  - Outliers are present and could distort the average.
  - Example: Median household income in a region—few billionaires won’t inflate the typical value.

**Real-World Example**:  
Incomes: $30k, $35k, $40k, $45k, $1,000,000  
- **Mean** = $230,000 → misleading due to one high income.  
- **Median** = $40,000 → better reflects the typical income.

Thus, **median is more representative** in skewed data.

---

#### **Summary Insights**
- In symmetric distributions: **mean ≈ median**  
- In right-skewed (positive skew): **mean > median**  
- In left-skewed (negative skew): **mean < median**  
- The **mean** represents the "balancing point" of data.  
- The **median** represents the "50th percentile" or midpoint.
