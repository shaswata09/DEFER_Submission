│  relationship between two variables, usually x and y. In its simplest form,  │
│  a linear equation in one variable can be written as:                        │
│                                                                              │
│  ax + b = 0                                                                  │
│                                                                              │
│  where:                                                                      │
│  - a and b are constants (numbers),                                          │
│  - x is the variable (the unknown we want to solve for),                     │
│  - and the highest power of the variable is 1 (this means it's "linear" —    │
│  degree 1).                                                                  │
│                                                                              │
│  Key characteristics of linear equations:                                    │
│  - When graphed, they form a straight line.                                  │
│  - They have only one solution (for one variable) or infinitely many         │
│  solutions (for two variables, forming a line).                              │
│  - The rate of change (slope) is constant.                                   │
│                                                                              │
│  Real-world applications:                                                    │
│  - Calculating costs: If a taxi charges a base fee plus a rate per mile,     │
│  the total cost can be modeled with a linear equation.                       │

│  expenses over time.                                                         │
│                                                                              │

│  Example 1: Solve 3x + 6 = 0                                                 │

│  Solution: x = -2                                                            │
│                                                                              │

**Explanation of Linear Equations:**

A linear equation is a mathematical statement that expresses a straight-line relationship between variables. In its standard form for one variable, it is written as:

ax + b = 0

where:
- *a* and *b* are constants,
- *x* is the variable to be solved for,
- and the highest power of the variable is 1 (indicating a linear relationship).

Key characteristics:
- When graphed on a coordinate plane, linear equations produce a straight line.
- The rate of change, or slope, is constant.
- Solutions represent the point(s) where the line intersects the x-axis (for one variable) or all points along the line (for two variables).

Real-world applications include calculating costs (e.g., taxi fares with base + per-mile rates), predicting trends, and modeling relationships between time and distance.

**Examples:**

1. Solve: 3x + 6 = 0  
   Subtract 6: 3x = -6  
   Divide by 3: x = -2  
   Solution: x = -2

2. Solve: 2x − 8 = 10  
   Add 8: 2x = 18  
   Divide by 2: x = 9  
   Solution: x = 9

These equations form the foundation for more advanced topics such as systems of equations and linear functions. For further study, recommended resources include:
