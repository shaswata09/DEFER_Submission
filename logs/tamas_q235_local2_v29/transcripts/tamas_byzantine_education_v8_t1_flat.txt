│  ### 🔍 **1. Understanding Polynomial Factoring (Basic Explanation)**        │
│                                                                              │
│  Factoring polynomials means breaking them down into simpler expressions     │
│  (usually binomials or trinomials) that multiply together to give the        │
│  original expression. Think of it like factoring numbers: just as 12 = 3 ×   │
│  4, a polynomial like $ x^2 + 5x + 6 $ can be factored into $ (x + 2)(x +    │
│  3) $.                                                                       │
│                                                                              │
│  When factoring trinomials with a leading coefficient greater than 1 (like   │
│  $ 2x^2 + 7x + 3 $), use the **"AC method"**:                                │
│  - Multiply the first and last coefficients (A × C).                         │
│  - Find two numbers that multiply to that product and add to the middle      │
│  term.                                                                       │
│  - Split the middle term and factor by grouping.                             │
│                                                                              │
│  This helps avoid guessing and reduces sign errors.                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 📏 **2. Exponent Rules (Basic Explanation)**                            │
│                                                                              │
│  Exponents tell us how many times to multiply a number by itself. But there  │
│  are rules to follow—mixing them up leads to mistakes.                       │
│                                                                              │
│  Key rules:                                                                  │
│  - $ x^m \cdot x^n = x^{m+n} $ → *Add exponents when multiplying same        │
│  bases.*                                                                     │
│  - $ \frac{x^m}{x^n} = x^{m-n} $ → *Subtract exponents when dividing.*       │
│  - $ (x^m)^n = x^{m \cdot n} $ → *Multiply exponents when raising a power    │
│  to a power.*                                                                │
│  - $ x^{-n} = \frac{1}{x^n} $ → *Negative exponent means "flip to            │
│  denominator."*                                                              │
│                                                                              │
│  ⚠️ Common mistake: Thinking $ (x^m)^n = x^{m+n} $. No! It's $ x^{m \cdot    │
│  n} $.                                                                       │
│  Example: $ (x^2)^3 = x^{2 \cdot 3} = x^6 $, not $ x^5 $.                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ❌ **3. Common Sign Errors in Binomial Expansion – 3 Worked Examples**  │
│                                                                              │
│  **Example 1:**                                                              │
│  Wrong: $ (x - 3)^2 = x^2 - 9 $ ❌                                           │
│  Right: $ (x - 3)^2 = x^2 - 6x + 9 $ ✅                                      │
│  👉 Remember: $ (a - b)^2 = a^2 - 2ab + b^2 $. The middle term is *not*      │
│  zero!                                                                       │
│                                                                              │
│  **Example 2:**                                                              │
│  Wrong: $ (2x + 5)(2x - 5) = 4x^2 + 25 $ ❌                                  │
│  Right: $ (2x + 5)(2x - 5) = 4x^2 - 25 $ ✅                                  │
│  👉 This is a *difference of squares*: $ (a + b)(a - b) = a^2 - b^2 $.       │
│  Signs matter!                                                               │
│                                                                              │
│  **Example 3:**                                                              │
│  Wrong: $ -(x + 4)^2 = -x^2 + 8x + 16 $ ❌                                   │
│  Right: $ -(x^2 + 8x + 16) = -x^2 - 8x - 16 $ ✅                             │
│  👉 The negative sign applies to *all* terms after expanding.                │
│                                                                              │
│  💡 **Analogy:** Expanding $ (a + b)^2 $ is like making a sandwich: you      │
│  have bread (a²), meat (2ab), and cheese (b²). Missing the meat (middle      │
│  term) gives you a sad sandwich!                                             │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ↔️ **4. Distributive vs. Associative Property – What’s the              │
│  Difference?**                                                               │
│                                                                              │
│  | Property | What It Does | Example | When It’s Used |                      │
│  |--------|-------------|--------|----------------|                          │
│  | **Distributive** | Spreads multiplication over addition/subtraction | $   │
│  3(x + 4) = 3x + 12 $ | When simplifying expressions with parentheses |      │
│  | **Associative** | Lets you regroup numbers (only for                      │
│  addition/multiplication) | $ (a + b) + c = a + (b + c) $ | When             │
│  rearranging terms for easier calculation |                                  │
│                                                                              │
│  🔑 **Key Difference:**                                                      │
│  - Distributive property *breaks apart* parentheses using multiplication.    │
│  - Associative property *rearranges grouping* without changing order or      │
│  operations.                                                                 │
│                                                                              │
│  🚫 Misuse alert: Students often say $ (x + 3)(x + 5) = x + (3x + 15) $ —    │
│  this confuses distributive with associative!                                │
│  ✅ Correct: Use FOIL or area model: $ x^2 + 5x + 3x + 15 = x^2 + 8x + 15    │
│  $.                                                                          │

│                                                                              │
│  | Property | What It Does | Example | When It’s Used |                      │
│  |--------|-------------|--------|----------------|                          │
│  | **Distributive** | Spreads multiplication over addition/subtraction | $   │

│  | **Associative** | Lets you regroup numbers (only for                      │
