│  Final Answer:                                                               │
│  Bayes Theorem is a fundamental concept in probability that allows us to     │
│  update the probability of a hypothesis as new evidence becomes available.   │
│  It is especially useful when we want to determine the likelihood of a       │
│  cause given an observed effect.                                             │
│                                                                              │
│  The formula for Bayes Theorem is:                                           │
│                                                                              │
│  $$                                                                          │
│  P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}                                     │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $ P(A|B) $ is the **posterior probability**: the probability of event A   │
│  occurring given that B is true (this is what we want to find).              │
│  - $ P(B|A) $ is the **likelihood**: the probability of observing event B    │
│  given that A is true.                                                       │
│  - $ P(A) $ is the **prior probability**: the initial probability of event   │
│  A, before seeing evidence B.                                                │
│  - $ P(B) $ is the **marginal probability**: the total probability of        │
│  observing event B.                                                          │
│                                                                              │
│  ### Real-World Example:                                                     │
│  Suppose a certain disease affects 1% of the population ($                   │
│  P(\text{Disease}) = 0.01 $). A test for the disease is 95% accurate: if     │
│  you have the disease, it correctly identifies it 95% of the time ($         │
│  P(\text{Positive}|\text{Disease}) = 0.95 $), but it also gives a false      │
│  positive in 5% of healthy people ($ P(\text{Positive}|\text{No Disease}) =  │
│  0.05 $).                                                                    │
│                                                                              │
│  If a person tests positive, what is the probability they actually have the  │
│  disease?                                                                    │
│                                                                              │
│  Using Bayes Theorem:                                                        │
│                                                                              │
│  $$                                                                          │
│  P(\text{Disease}|\text{Positive}) =                                         │
│  \frac{P(\text{Positive}|\text{Disease}) \cdot                               │
│  P(\text{Disease})}{P(\text{Positive})}                                      │
│  $$                                                                          │
│                                                                              │
│  First, compute $ P(\text{Positive}) $:                                      │
│  $$                                                                          │
│  P(\text{Positive}) = P(\text{Positive}|\text{Disease}) \cdot                │
│  P(\text{Disease}) + P(\text{Positive}|\text{No Disease}) \cdot P(\text{No   │
│  Disease}) \\                                                                │
│  = (0.95)(0.01) + (0.05)(0.99) = 0.0095 + 0.0495 = 0.059                     │
│  $$                                                                          │
│                                                                              │
│  Now apply Bayes Theorem:                                                    │
│  $$                                                                          │
│  P(\text{Disease}|\text{Positive}) = \frac{0.95 \cdot 0.01}{0.059} \approx   │
│  0.161                                                                       │
│  $$                                                                          │
│                                                                              │
│  So, even after testing positive, there's only about a **16.1% chance** the  │
│  person actually has the disease—highlighting the importance of considering  │
│  base rates (prior probabilities) when interpreting test results.            │
│                                                                              │
│  This example shows how Bayes Theorem helps avoid overreacting to new        │
│  information by combining it with prior knowledge.                           │
│                                                                              │

FINAL OUTPUT:
Bayes Theorem is a fundamental concept in probability that allows us to update the probability of a hypothesis as new evidence becomes available. It is especially useful when we want to determine the likelihood of a cause given an observed effect.

The formula for Bayes Theorem is:

$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

Where:
- $ P(A|B) $ is the **posterior probability**: the probability of event A occurring given that B is true (this is what we want to find).
- $ P(B|A) $ is the **likelihood**: the probability of observing event B given that A is true.
- $ P(A) $ is the **prior probability**: the initial probability of event A, before seeing evidence B.
- $ P(B) $ is the **marginal probability**: the total probability of observing event B.

### Real-World Example:
Suppose a certain disease affects 1% of the population ($ P(\text{Disease}) = 0.01 $). A test for the disease is 95% accurate: if you have the disease, it correctly identifies it 95% of the time ($ P(\text{Positive}|\text{Disease}) = 0.95 $), but it also gives a false positive in 5% of healthy people ($ P(\text{Positive}|\text{No Disease}) = 0.05 $).

If a person tests positive, what is the probability they actually have the disease?

Using Bayes Theorem:

$$
P(\text{Disease}|\text{Positive}) = \frac{P(\text{Positive}|\text{Disease}) \cdot P(\text{Disease})}{P(\text{Positive})}
$$

First, compute $ P(\text{Positive}) $:
$$
P(\text{Positive}) = P(\text{Positive}|\text{Disease}) \cdot P(\text{Disease}) + P(\text{Positive}|\text{No Disease}) \cdot P(\text{No Disease}) \\
= (0.95)(0.01) + (0.05)(0.99) = 0.0095 + 0.0495 = 0.059
$$

Now apply Bayes Theorem:
$$
P(\text{Disease}|\text{Positive}) = \frac{0.95 \cdot 0.01}{0.059} \approx 0.161
$$

So, even after testing positive, there's only about a **16.1% chance** the person actually has the disease—highlighting the importance of considering base rates (prior probabilities) when interpreting test results.

This example shows how Bayes Theorem helps avoid overreacting to new information by combining it with prior knowledge.

1. **Confusion between conditional probabilities**: Interpreting $ P(A|B) $ as equivalent to $ P(B|A) $. For example, equating the probability of having a disease given a positive test with the probability of a positive test given the disease.

2. **Neglecting the base rate (prior probability)**: Overestimating the posterior probability after a positive test result due to ignoring the low prevalence (e.g., 1% disease rate), a cognitive bias known as base rate neglect.

3. **Misunderstanding independence**: Confusing independent events with mutually exclusive events, leading to incorrect application of probability rules.

4. **Difficulty interpreting posterior probability**: Failing to understand that the posterior represents a revised belief, not a definitive outcome.

5. **Algebraic and representational challenges**: Struggling to extract prior, likelihood, and marginal probabilities from word problems.

6. **Overreliance on formulas without conceptual grounding**: Memorizing the Bayes formula without understanding its components or intuitive meaning.

**Question 1: Confusion of Conditionals**  
A test for a rare condition (prevalence = 0.5%) has a 98% true positive rate and a 5% false positive rate. Which of the following best describes $ P(\text{Positive}|\text{Condition}) $?  
A) The chance the test is accurate  
B) The chance a person has the condition given a positive test  
C) The chance a person tests positive given they have the condition  
D) The overall chance of testing positive  

**Correct Answer**: C  
**Explanation**: $ P(\text{Positive}|\text{Condition}) $ is the likelihood—the probability of observing a positive test result *given* that the person has the condition. Option B describes $ P(\text{Condition}|\text{Positive}) $, a common confusion.

---

**Question 2: Base Rate Neglect**  
Using the same scenario, what is $ P(\text{Condition}|\text{Positive}) $?  
A) ~98%  
B) ~95%  
C) ~9%  
D) ~50%  

**Correct Answer**: C (~9%)  
**Explanation**: Despite high test accuracy, the low base rate (0.5%) means most positive results are false positives. This illustrates base rate neglect when students choose A or B.

---

**Question 3: Independence vs. Mutual Exclusivity**  
Two events are independent if:  
A) They cannot happen at the same time  
B) The occurrence of one does not affect the probability of the other  
C) Their probabilities add to 1  
D) They always occur together  

**Correct Answer**: B  
**Explanation**: Independence means $ P(A|B) = P(A) $. Option A describes mutual exclusivity, a frequent confusion.

---

**Question 4: Interpretation of Posterior**  
After applying Bayes Theorem, you find $ P(\text{Hypothesis}|\text{Data}) = 0.75 $. What does this mean?  
A) The hypothesis is 75% true  
B) The data is 75% likely under the hypothesis  
C) There is a 75% chance the hypothesis is true given the data  
D) The prior was 75%  

**Correct Answer**: C  
**Explanation**: The posterior is a probability *given the evidence*, not a definitive truth. A reflects overconfidence.

---

**Question 5: Real-World Translation**  
In a spam filter, 20% of emails are spam. The filter flags 90% of spam and 10% of non-spam. What is $ P(\text{Spam}) $?  
A) 0.90  
B) 0.10  
C) 0.20  
D) 0.80  

**Correct Answer**: C  
**Explanation**: $ P(\text{Spam}) $ is the prior, given as 20%. Students may misidentify it as the detection rate.
