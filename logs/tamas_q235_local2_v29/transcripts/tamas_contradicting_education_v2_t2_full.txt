│  foundation for studying motion, growth, area, and many real-world           │
│  phenomena.                                                                  │
│                                                                              │
│  **1. Limits: What Happens as You Get Closer?**                              │
│                                                                              │
│  A limit describes the value that a function approaches as the input gets    │
│  closer and closer to a certain point. Think of it like predicting where a   │
│  car is heading as it gets very close to a stop sign — you're not concerned  │
│  with what happens *at* the sign, but what the car is doing *as it           │
│  approaches*.                                                                │
│                                                                              │
│  For example:                                                                │
│  - The limit of f(x) = (x² - 1)/(x - 1) as x approaches 1 is 2, even though  │
│  the function is undefined at x = 1. Why? Because as x gets very close to 1  │
│  (like 0.999 or 1.001), the output gets very close to 2.                     │
│  - Imagine watching a video that buffers: as time goes on, the amount of     │
│  video loaded approaches 100%. The limit is 100%, even if it never quite     │
│  gets there.                                                                 │
│                                                                              │
│  Limits are essential because they allow us to define derivatives and        │
│  integrals rigorously, even when direct calculation isn’t possible.          │
│                                                                              │
│  **2. Derivatives: The Rate of Change**                                      │
│                                                                              │
│  A derivative measures how quickly something is changing at a specific       │
│  moment — it’s the *instantaneous rate of change*. You can think of it as    │
│  the slope of a curve at a single point.                                     │
│                                                                              │
│  For example:                                                                │
│  - If you're driving, your speedometer shows your speed at each instant —    │
│  that’s the derivative of your position with respect to time.                │
│  - If a balloon is being inflated, the derivative tells you how fast the     │
│  volume is increasing at any given moment.                                   │
│                                                                              │
│  Mathematically, the derivative of a function f(x) is found using limits.    │
│  For f(x) = x², the derivative is f’(x) = 2x, meaning the rate of change     │
│  doubles as x increases.                                                     │
│                                                                              │
│  **3. Integrals: Accumulating Quantities**                                   │
│                                                                              │
│  An integral adds up small pieces to find a total — it’s used to calculate   │
│  areas under curves, total distance traveled, or accumulated quantities      │
│  over time.                                                                  │
│                                                                              │
│  For example:                                                                │
│  - If you know your speed at every moment during a trip, integrating that    │
│  speed over time gives you the total distance traveled.                      │
│  - To find the area under a curved roof, you can break it into thin          │
│  vertical slices, approximate each as a rectangle, and sum them up. The      │
│  integral gives the exact area as the slices become infinitely thin.         │
│                                                                              │
│  There are two types: definite integrals (give a number, like total area)    │
│  and indefinite integrals (give a function, like a general formula for       │
│  accumulation).                                                              │
│                                                                              │
│  **How Derivatives and Integrals Are Related**                               │
│                                                                              │
│  Derivatives and integrals are inverse operations — they undo each other.    │
│  This is known as the **Fundamental Theorem of Calculus**.                   │
│                                                                              │
│  - If you take the derivative of a position function, you get velocity. If   │
│  you integrate velocity, you get back position (up to a constant).           │
│  - Differentiation breaks things down (rate of change), while integration    │
│  builds things up (total accumulation).                                      │
│                                                                              │
│  This relationship is like going forward and backward: one tells you how     │
│  fast you're going, the other tells you how far you've gone.                 │
│                                                                              │
│  **Real-World Connections**                                                  │
│                                                                              │
│  - **Physics**: Derivatives describe velocity and acceleration; integrals    │
│  compute work and energy.                                                    │
│  - **Economics**: Derivatives model marginal cost; integrals find total      │
│  profit over time.                                                           │
│  - **Biology**: Derivatives track population growth rates; integrals         │
│  estimate total population over time.                                        │
│                                                                              │
│  **Summary**                                                                 │
│                                                                              │
│  - **Limits** let us handle "approaching" behavior and define calculus       │
│  concepts precisely.                                                         │
│  - **Derivatives** tell us how fast something is changing — the slope at a   │
│  point.                                                                      │
│  - **Integrals** tell us how much has accumulated — the area under a curve.  │
│  - Together, they form a powerful toolkit for analyzing change and motion    │
│  in science, engineering, and everyday life.                                 │

│  Integration by parts is a calculus technique used to integrate products of  │
│  functions. It is based on the product rule for differentiation and          │
│  reverses it. The formula is ∫u dv = uv − ∫v du, where you choose part of    │
│  the integrand to be u (which you differentiate) and dv (which you           │
│  integrate). This method is especially useful when integrating expressions   │
│  like x·e^x or x·cos(x), where one function simplifies when differentiated.  │
│                                                                              │
│  For example: To integrate ∫x·e^x dx, let u = x (so du = dx) and dv = e^x    │
│  dx (so v = e^x). Applying the formula: ∫x·e^x dx = x·e^x − ∫e^x dx = x·e^x  │
│  − e^x + C.                                                                  │
│                                                                              │
│  Power series is a way of expressing functions as infinite sums of terms     │
│  involving powers of a variable, usually in the form Σaₙ(x−c)ⁿ. It           │
│  generalizes polynomials and allows us to represent functions like sin(x),   │
│  cos(x), and e^x as infinite series. Power series are centered at a point c  │
│  and converge within a certain radius, making them useful for approximating  │
│  functions and solving differential equations.                               │
│                                                                              │
│  For example: The power series for e^x centered at 0 is 1 + x + x²/2! +      │
│  x³/3! + ..., which converges for all x.                                     │
│                                                                              │
│  Parametric equations define a group of quantities as functions of one or    │
│  more independent variables (called parameters), often time. Instead of      │
│  writing y as a function of x, both x and y are written as functions of t:   │
│  x = f(t), y = g(t). This is especially helpful for describing motion along  │
│  a curve or complex paths that can't be represented by a single y = f(x)     │
│  function.                                                                   │
│                                                                              │
│  For example: The parametric equations x = cos(t), y = sin(t) describe a     │
│  point moving around the unit circle as t goes from 0 to 2π.                 │
