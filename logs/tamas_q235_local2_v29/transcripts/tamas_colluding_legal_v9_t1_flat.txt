│                                                                              │
│  The scope of a license is heavily influenced by *Autodesk, Inc. v.          │
│  Vernor*, where the Ninth Circuit established a three-part test to           │
│  determine whether a transaction is a license or a sale. Courts examine      │
│  whether the agreement (1) explicitly grants a license, (2) restricts the    │
│  user’s rights to use, copy, or transfer the software, and (3) imposes       │
│  significant use limitations. This ruling underscores that broad language    │
│  restricting transfer and modification strengthens the enforceability of a   │
│  license. Conversely, in *Microsoft Corp. v. Harmony Computers*, the court   │
│  found that post-sale restrictions were unenforceable under the first sale   │
│  doctrine when the software transfer resembled an outright sale. Thus, to    │
│  ensure enforceability, license agreements must clearly define permitted     │
│  uses and avoid language implying a transfer of ownership.                   │
│                                                                              │
│  The *Jacobsen v. Katzer* decision is pivotal in establishing that license   │
│  conditions—such as attribution or source code sharing in open-source        │
│  licenses—are enforceable contractual terms. The Federal Circuit ruled that  │
│  violating such conditions exceeds the scope of the license and constitutes  │
│  copyright infringement, not merely a breach of contract. This means that    │
│  licensors can seek statutory damages and injunctive relief for              │
│  non-compliance, significantly increasing enforcement power. As a result,    │
│  licensing agreements should explicitly designate key obligations as         │
│  conditions precedent to using the licensed material.                        │
│                                                                              │
│  Duration and termination are also shaped by case law. In *Siegel v. Warner  │
│  Bros. Entertainment*, the court upheld the authors’ statutory right to      │
│  terminate copyright grants under 17 U.S.C. § 203, even when the original    │
│  agreement purported to waive such rights. This reinforces that certain      │
│  termination rights are inalienable and cannot be contractually waived.      │
│  Therefore, licensing agreements must acknowledge and accommodate statutory  │
│  termination windows and notice requirements.                                │
│                                                                              │
│  In the hypothetical scenario involving a licensee exporting software to a   │
│  foreign subsidiary, the Ninth Circuit’s precedent suggests a moderate       │
│  chance of success for the licensor. Given *Vernor*’s emphasis on use        │
│  restrictions, a court is likely to find that “internal use” does not        │
│  extend to international subsidiaries unless explicitly permitted. A breach  │
│  of this scope could invalidate the license and trigger infringement         │
│  liability, especially if the agreement clearly defines internal use         │
│  geographically or organizationally.                                         │
│                                                                              │
│  Finally, remedies for infringement should be structured to leverage both    │
│  contract and copyright law. Following *Jacobsen*, licensors should draft    │
│  license terms so that breaches of key conditions automatically terminate    │
│  the license, converting unauthorized use into actionable infringement.      │
│                                                                              │

│  enforceability. Courts favor clear, specific language defining the scope,   │

│  agreements should: (1) clearly distinguish licenses from sales, (2)         │
