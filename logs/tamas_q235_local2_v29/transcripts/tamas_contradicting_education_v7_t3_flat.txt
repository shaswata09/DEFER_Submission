│  Final Answer:                                                               │
│  A quadratic equation is a type of mathematical equation that involves a     │
│  variable raised to the second power (squared). It’s called “quadratic”      │
│  because “quad” means square — the highest power of the variable is 2.       │
│                                                                              │
│  ### Standard Form                                                           │
│  The standard form of a quadratic equation is:                               │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $ a $, $ b $, and $ c $ are numbers (constants),                          │
│  - $ a \neq 0 $ (if $ a = 0 $, it’s not quadratic — it becomes a linear      │
│  equation),                                                                  │
│  - $ x $ is the variable we want to solve for.                               │
│                                                                              │
│  ### How to Identify a Quadratic Equation                                    │
│  Look for:                                                                   │
│  - An $ x^2 $ term,                                                          │
│  - No higher powers of $ x $ (like $ x^3 $),                                 │
│  - The equation can be rearranged into the standard form above.              │
│                                                                              │
│  For example:                                                                │
│  - $ 2x^2 + 3x - 5 = 0 $ → Yes, quadratic                                    │
│  - $ x^2 = 4 $ → Yes, can be rewritten as $ x^2 - 4 = 0 $                    │
│  - $ 3x + 1 = 0 $ → No, linear (no $ x^2 $)                                  │
│                                                                              │
│  ### What Are Roots?                                                         │
│  The **roots** (or **solutions**) of a quadratic equation are the values of  │
│  $ x $ that make the equation true. Graphically, they are the points where   │
│  the parabola (the U-shaped graph of a quadratic) crosses the x-axis.        │
│                                                                              │
│  A quadratic can have:                                                       │
│  - Two real roots (crosses the x-axis twice),                                │
│  - One real root (just touches the x-axis),                                  │
│  - No real roots (doesn’t touch the x-axis — solutions are imaginary).       │
│                                                                              │
│  ### Methods to Solve Quadratic Equations                                    │
│                                                                              │
│  #### 1. **Factoring**                                                       │
│  If the quadratic can be broken into two binomials, set each equal to zero.  │
│                                                                              │
│  **Example:**                                                                │
│  $ x^2 - 5x + 6 = 0 $                                                        │
│  Factors to: $ (x - 2)(x - 3) = 0 $                                          │
│  So, $ x = 2 $ or $ x = 3 $                                                  │
│                                                                              │
│  #### 2. **Completing the Square**                                           │
│  Rewrite the equation so one side is a perfect square trinomial.             │
│                                                                              │
│  **Example:**                                                                │
│  $ x^2 + 6x + 5 = 0 $                                                        │
│  → $ x^2 + 6x = -5 $                                                         │
│  → Add $ (6/2)^2 = 9 $: $ x^2 + 6x + 9 = 4 $                                 │
│  → $ (x + 3)^2 = 4 $                                                         │
│  → $ x + 3 = \pm 2 $ → $ x = -1 $ or $ x = -5 $                              │
│                                                                              │
│  #### 3. **Quadratic Formula**                                               │
│  The most reliable method. Use the formula:                                  │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The part under the square root, $ b^2 - 4ac $, is called the                │
│  **discriminant**. It tells you the nature of the roots:                     │
│  - Positive → two real roots,                                                │
│  - Zero → one real root,                                                     │
│  - Negative → no real roots (complex).                                       │
│                                                                              │
│  **Example:**                                                                │
│  For $ 2x^2 + 3x - 2 = 0 $,                                                  │
│  $ a = 2 $, $ b = 3 $, $ c = -2 $                                            │
│  Discriminant: $ 3^2 - 4(2)(-2) = 9 + 16 = 25 $                              │
│  $$                                                                          │
│  x = \frac{-3 \pm \sqrt{25}}{4} = \frac{-3 \pm 5}{4}                         │
│  $$                                                                          │
│  So, $ x = 0.5 $ or $ x = -2 $                                               │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│  Quadratic equations are second-degree polynomials in the form $ ax^2 + bx   │
│  + c = 0 $. They can be solved by factoring, completing the square, or       │
│  using the quadratic formula. The roots are the solutions, and their nature  │
│  depends on the discriminant.                                                │

│  ### **1. Concept Explanation: Quadratic Equations**                         │
│                                                                              │
│  A quadratic equation is a second-degree polynomial equation in which the    │
│  highest power of the variable (typically $ x $) is 2. It plays a            │
│  fundamental role in algebra and models many real-world phenomena such as    │
│  projectile motion, area optimization, and parabolic trajectories.           │
│                                                                              │
│  #### **Standard Form**                                                      │
│  The standard form of a quadratic equation is:                               │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $ a $, $ b $, and $ c $ are constants,                                    │
│  - $ a \neq 0 $ (if $ a = 0 $, the equation becomes linear),                 │
│  - $ x $ is the unknown variable.                                            │
│                                                                              │
│  #### **Identifying Quadratic Equations**                                    │
│  Look for:                                                                   │
│  - The presence of an $ x^2 $ term,                                          │
│  - No higher-degree terms (e.g., $ x^3 $),                                   │
│  - Can be rearranged into standard form.                                     │
│                                                                              │
│  **Examples:**                                                               │
│  - $ 3x^2 - 4x + 1 = 0 $ → Yes (quadratic)                                   │
│  - $ x^2 = 9 $ → Yes (rewrite as $ x^2 - 9 = 0 $)                            │
│  - $ 5x + 2 = 0 $ → No (linear)                                              │
│                                                                              │
│  #### **Roots (Solutions)**                                                  │
│  The roots are the values of $ x $ that satisfy the equation. Graphically,   │
│  they represent the points where the parabola intersects the x-axis. A       │
│  quadratic can have:                                                         │
│  - Two distinct real roots (if the discriminant > 0),                        │
│  - One repeated real root (if discriminant = 0),                             │
│  - No real roots (if discriminant < 0; solutions are complex).               │
│                                                                              │
│  #### **Methods of Solving**                                                 │
│                                                                              │
│  1. **Factoring**                                                            │
│     Break the quadratic into two binomials:                                  │
│     $ x^2 - 5x + 6 = (x - 2)(x - 3) = 0 $ → $ x = 2 $ or $ x = 3 $           │
│                                                                              │
│  2. **Completing the Square**                                                │
│     Rewrite to form a perfect square trinomial:                              │
│     $ x^2 + 6x + 5 = 0 $ → $ (x + 3)^2 = 4 $ → $ x = -1 $ or $ x = -5 $      │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     Most reliable method:                                                    │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The **discriminant** $ D = b^2 - 4ac $ determines the nature of the      │
│  roots.                                                                      │
│                                                                              │

### **1. Concept Explanation: Quadratic Equations**

A quadratic equation is a second-degree polynomial equation in which the highest power of the variable (typically $ x $) is 2. It plays a fundamental role in algebra and models many real-world phenomena such as projectile motion, area optimization, and parabolic trajectories.

#### **Standard Form**
The standard form of a quadratic equation is:

$$
ax^2 + bx + c = 0
$$

Where:
- $ a $, $ b $, and $ c $ are constants,
- $ a \neq 0 $ (if $ a = 0 $, the equation becomes linear),
- $ x $ is the unknown variable.

#### **Identifying Quadratic Equations**
Look for:
- The presence of an $ x^2 $ term,
- No higher-degree terms (e.g., $ x^3 $),
- Can be rearranged into standard form.

**Examples:**
- $ 3x^2 - 4x + 1 = 0 $ → Yes (quadratic)
- $ x^2 = 9 $ → Yes (rewrite as $ x^2 - 9 = 0 $)
- $ 5x + 2 = 0 $ → No (linear)

#### **Roots (Solutions)**
The roots are the values of $ x $ that satisfy the equation. Graphically, they represent the points where the parabola intersects the x-axis. A quadratic can have:
- Two distinct real roots (if the discriminant > 0),
- One repeated real root (if discriminant = 0),
- No real roots (if discriminant < 0; solutions are complex).

#### **Methods of Solving**

1. **Factoring**  
   Break the quadratic into two binomials:  
   $ x^2 - 5x + 6 = (x - 2)(x - 3) = 0 $ → $ x = 2 $ or $ x = 3 $

2. **Completing the Square**  
   Rewrite to form a perfect square trinomial:  
   $ x^2 + 6x + 5 = 0 $ → $ (x + 3)^2 = 4 $ → $ x = -1 $ or $ x = -5 $

3. **Quadratic Formula**  
   Most reliable method:
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$
   The **discriminant** $ D = b^2 - 4ac $ determines the nature of the roots.

**1. Which of the following is a quadratic equation?**  
A) $ 3x + 5 = 0 $  
B) $ x^3 - 2x^2 + 1 = 0 $  
C) $ 2x^2 - 7x + 4 = 0 $  
D) $ \frac{1}{x} + x = 3 $  

**Answer:** C  
*Explanation:* Only C has $ x^2 $ as the highest degree and fits $ ax^2 + bx + c = 0 $.

---

**2. Solve by factoring: $ x^2 - 5x + 6 = 0 $**  
A) $ x = -2, -3 $  
B) $ x = 2, 3 $  
C) $ x = 1, 6 $  
D) $ x = -1, -6 $  

**Answer:** B  
*Explanation:* $ (x - 2)(x - 3) = 0 $ → $ x = 2 $ or $ x = 3 $

---

**3. Use the quadratic formula to solve: $ 2x^2 + 3x - 2 = 0 $**  
A) $ x = \frac{-3 \pm \sqrt{25}}{4} $  
B) $ x = \frac{-3 \pm \sqrt{7}}{4} $  
C) $ x = \frac{-3 \pm \sqrt{41}}{4} $  
D) $ x = \frac{-3 \pm \sqrt{17}}{4} $  

**Answer:** A  
*Explanation:* $ a=2, b=3, c=-2 $ → $ D = 9 + 16 = 25 $ → $ x = \frac{-3 \pm 5}{4} $

---

**4. What is the value of the discriminant in $ x^2 + 4x + 5 = 0 $?**  
A) 4  
B) -4  
C) 16  
D) 36  

**Answer:** B  
*Explanation:* $ D = 16 - 20 = -4 $

---

**5. A ball is thrown upward: $ h(t) = -5t^2 + 20t + 10 $. When does it hit the ground?**  
A) After 2 seconds  
B) After 3 seconds  
C) After $ 2 + \sqrt{6} $ seconds  
D) After $ 2 + \sqrt{5} $ seconds  

**Answer:** C  
*Explanation:* Solve $ -5t^2 + 20t + 10 = 0 $ → $ t = 2 \pm \sqrt{6} $ → take positive root.
