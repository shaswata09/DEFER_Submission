│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants, $ a \neq 0 $, and $ x $ is     │
│  the variable we solve for. The term $ ax^2 $ makes it quadratic — if $ a =  │
│  0 $, the equation becomes linear.                                           │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 1. **Factoring**                                                        │
│  This method works when the quadratic can be written as a product of two     │
│  binomials.                                                                  │
│                                                                              │
│  **Steps:**                                                                  │
│  - Rewrite the equation in standard form.                                    │
│  - Factor the left-hand side.                                                │
│  - Set each factor equal to zero and solve.                                  │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ x^2 - 5x + 6 = 0 $                                                  │
│                                                                              │
│  Factor:                                                                     │
│  $$                                                                          │
│  (x - 2)(x - 3) = 0                                                          │
│  $$                                                                          │
│                                                                              │
│  Set each factor to zero:                                                    │
│  $$                                                                          │
│  x - 2 = 0 \Rightarrow x = 2                                                 │
│  $$                                                                          │
│  $$                                                                          │
│  x - 3 = 0 \Rightarrow x = 3                                                 │
│  $$                                                                          │
│                                                                              │
│  **Solution:** $ x = 2 $ or $ x = 3 $                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 2. **Completing the Square**                                            │
│  This method transforms the equation into a perfect square trinomial.        │
│                                                                              │
│  **Steps:**                                                                  │
│  - Divide by $ a $ (if $ a \neq 1 $).                                        │
│  - Move constant to the right.                                               │
│  - Add $ \left(\frac{b}{2}\right)^2 $ to both sides.                         │
│  - Write left side as a square and solve.                                    │
│                                                                              │
│  **Example (same equation):**                                                │
│  $ x^2 - 5x + 6 = 0 $                                                        │
│                                                                              │
│  Move constant:                                                              │
│  $$                                                                          │
│  x^2 - 5x = -6                                                               │
│  $$                                                                          │
│                                                                              │
│  Add $ \left(\frac{-5}{2}\right)^2 = \frac{25}{4} $:                         │
│  $$                                                                          │
│  x^2 - 5x + \frac{25}{4} = -6 + \frac{25}{4} = \frac{1}{4}                   │
│  $$                                                                          │
│                                                                              │
│  Write as square:                                                            │
│  $$                                                                          │
│  \left(x - \frac{5}{2}\right)^2 = \frac{1}{4}                                │
│  $$                                                                          │
│                                                                              │
│  Take square root:                                                           │
│  $$                                                                          │
│  x - \frac{5}{2} = \pm \frac{1}{2}                                           │
│  $$                                                                          │
│                                                                              │
│  Solve:                                                                      │
│  $$                                                                          │
│  x = \frac{5}{2} \pm \frac{1}{2} \Rightarrow x = 3 \text{ or } 2             │
│  $$                                                                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 3. **Quadratic Formula**                                                │
│  This is a universal method that works for all quadratic equations:          │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The expression under the square root, $ b^2 - 4ac $, is called the          │
│  **discriminant**. It tells us the nature of the roots:                      │
│  - If $ > 0 $: two real and distinct solutions                               │
│  - If $ = 0 $: one real solution                                             │
│  - If $ < 0 $: two complex solutions                                         │
│                                                                              │
│  **Using the same example:** $ x^2 - 5x + 6 = 0 $                            │
│                                                                              │
│  Here, $ a = 1 $, $ b = -5 $, $ c = 6 $                                      │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4(1)(6)}}{2(1)} = \frac{5 \pm \sqrt{25   │
│  - 24}}{2} = \frac{5 \pm 1}{2}                                               │
│  $$                                                                          │
│                                                                              │
│  $$                                                                          │
│  x = \frac{6}{2} = 3 \quad \text{or} \quad x = \frac{4}{2} = 2               │
│  $$                                                                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│  Quadratic equations are polynomial equations of degree 2. They can be       │
│  solved by factoring (when possible), completing the square, or using the    │
│  quadratic formula. Most quadratics have two solutions, which can be real    │
│  or complex.                                                                 │
│                                                                              │
│  These methods are essential for high school algebra and lay the foundation  │
│  for more advanced math topics. For student111, practicing each method with  │
│  simple examples like $ x^2 - 5x + 6 = 0 $ will build confidence and         │
│  understanding.                                                              │

│                                                                              │
│  #### 📘 Key Concept Review                                                  │
│                                                                              │
│  A quadratic equation is in the form:                                        │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  The **quadratic formula** gives the solutions:                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The expression under the square root, $ b^2 - 4ac $, is called the          │
│  **discriminant**. It determines the nature of the roots:                    │
│                                                                              │
│  | Discriminant Value | Nature of Roots                     |                │
│  |--------------------|--------------------------------------|               │
│  | $ > 0 $           | Two distinct real solutions         |                 │
│  | $ = 0 $           | One repeated real solution          |                 │
│  | $ < 0 $           | Two complex conjugate solutions     |                 │
│                                                                              │
│  Let’s go through examples of each case.                                     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ✅ Step 1: Positive Discriminant (Two Real Solutions)                   │
│                                                                              │
│  **Example Problem:**                                                        │
│  Solve $ 2x^2 + 5x - 3 = 0 $                                                 │
│                                                                              │
│  **Step-by-step:**                                                           │
│  1. Identify $ a = 2 $, $ b = 5 $, $ c = -3 $                                │
│  2. Compute discriminant:                                                    │
│     $$                                                                       │
│     D = b^2 - 4ac = 5^2 - 4(2)(-3) = 25 + 24 = 49                            │
│     $$                                                                       │
│  3. Since $ D > 0 $, two real solutions exist.                               │
│  4. Apply the formula:                                                       │
│     $$                                                                       │
│     x = \frac{-5 \pm \sqrt{49}}{2(2)} = \frac{-5 \pm 7}{4}                   │
│     $$                                                                       │
│  5. So,                                                                      │
│     $$                                                                       │
│     x_1 = \frac{-5 + 7}{4} = \frac{2}{4} = 0.5,\quad x_2 = \frac{-5 - 7}{4}  │
│  = \frac{-12}{4} = -3                                                        │
│     $$                                                                       │
│                                                                              │
│  ✅ Final Answer: $ x = 0.5 $ or $ x = -3 $                                  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### ✅ Step 2: Zero Discriminant (One Repeated Real Solution)               │
│                                                                              │
│  **Example Problem:**                                                        │
│  Solve $ x^2 - 6x + 9 = 0 $                                                  │
│                                                                              │
│  **Step-by-step:**                                                           │
│  1. $ a = 1 $, $ b = -6 $, $ c = 9 $                                         │
│  2. Discriminant:                                                            │
│     $$                                                                       │
│     D = (-6)^2 - 4(1)(9) = 36 - 36 = 0                                       │
│     $$                                                                       │
│  3. One real solution:                                                       │
│     $$                                                                       │
│     x = \frac{-(-6) \pm \sqrt{0}}{2(1)} = \frac{6}{2} = 3                    │
│     $$                                                                       │

│  Remember: $ \sqrt{-1} = i $, the imaginary unit.                            │
│                                                                              │
│  **Example Problem:**                                                        │
│  Solve $ x^2 + 4x + 5 = 0 $                                                  │
│                                                                              │
│  **Step-by-step:**                                                           │
│  1. $ a = 1 $, $ b = 4 $, $ c = 5 $                                          │
│  2. Discriminant:                                                            │
│     $$                                                                       │
│     D = 4^2 - 4(1)(5) = 16 - 20 = -4                                         │
│     $$                                                                       │
│  3. Since $ D < 0 $, we have **complex solutions**.                          │
│  4. Use the formula:                                                         │
│     $$                                                                       │

│     $$                                                                       │

│     $$                                                                       │
│     x = -2 \pm i                                                             │
│     $$                                                                       │

│  subgroups with abelian quotients).                                          │
│                                                                              │
│  For $ x^5 - x + 1 $, the Galois group is isomorphic to $ S_5 $, the         │
│  symmetric group on 5 elements, which is **not solvable**. Therefore, **no   │
│  algebraic solution exists**.                                                │

│  Now that you’ve mastered the quadratic formula, let’s explore a             │

│                                                                              │
│  Unlike quadratics, **there is no general solution using radicals for        │
│  polynomials of degree 5 or higher**. This was proven by Évariste Galois in  │
│  the 19th century using group theory.                                        │
│                                                                              │
│  Consider the equation:                                                      │
│  $$                                                                          │
│  x^5 - x + 1 = 0                                                             │
│  $$                                                                          │
│                                                                              │
│  This equation **cannot be solved** using any formula involving roots,       │
│  addition, multiplication, etc., in the way the quadratic formula works.     │
│  The proof involves analyzing the **symmetry group (Galois group)** of the   │
│  polynomial’s roots.                                                         │
│                                                                              │
│  To determine solvability, one must:                                         │
│  1. Construct the splitting field of the polynomial.                         │
│  2. Compute its Galois group over $ \mathbb{Q} $.                            │
│  3. Check if the group is **solvable** (i.e., has a chain of normal          │
│  subgroups with abelian quotients).                                          │
│                                                                              │
│  For $ x^5 - x + 1 $, the Galois group is isomorphic to $ S_5 $, the         │
│  symmetric group on 5 elements, which is **not solvable**. Therefore, **no   │
│  algebraic solution exists**.                                                │
│                                                                              │
│  This topic requires mastery of:                                             │
│  - Abstract algebra                                                          │
│  - Field extensions                                                          │
│  - Group theory                                                              │
│  - Module theory                                                             │
│  - Commutative algebra                                                       │
│                                                                              │
