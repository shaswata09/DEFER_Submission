│  **Understanding Solving Quadratic Equations (Basic Level)**                 │
│  A quadratic equation is an equation of the form $ ax^2 + bx + c = 0 $,      │
│  where $ a $, $ b $, and $ c $ are numbers, and $ a \neq 0 $. The goal is    │
│  to find the values of $ x $ that make the equation true—these are called    │
│  *solutions* or *roots*.                                                     │
│                                                                              │
│  One reliable method is **factoring**, when possible. You rewrite the        │
│  quadratic as a product of two binomials. For example:                       │
│  - $ x^2 + 5x + 6 = 0 $ becomes $ (x + 2)(x + 3) = 0 $                       │
│  - Then, use the **zero product property**: if two things multiply to zero,  │
│  at least one must be zero.                                                  │
│  - So, $ x + 2 = 0 $ → $ x = -2 $, or $ x + 3 = 0 $ → $ x = -3 $             │
│                                                                              │
│  If factoring is hard, use the **quadratic formula**:                        │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│  This always works! The part under the square root, $ b^2 - 4ac $, is        │
│  called the *discriminant*. It tells you how many solutions there are:       │
│  - Positive → two real solutions                                             │
│  - Zero → one real solution                                                  │
│  - Negative → no real solutions (we’ll learn about complex ones later)       │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Examples of Solving Quadratic Equations**                                 │
│                                                                              │

│  **Understanding Graphing Inequalities (Basic Level)**                       │
│  When graphing inequalities like $ y > 2x + 1 $ or $ y \leq -x + 4 $,        │
│  you're showing all the *pairs* $ (x, y) $ that make the inequality true.    │
│                                                                              │
│  Steps:                                                                      │
│  1. **Graph the boundary line** as if it were an equation (e.g., $ y = 2x +  │
│  1 $).                                                                       │
│     - Use a **solid line** for $ \leq $ or $ \geq $ (includes equality)      │
│     - Use a **dashed line** for $ < $ or $ > $ (does not include equality)   │
│  2. **Shade the region** that satisfies the inequality.                      │
│     - For $ y > $ or $ y \geq $, shade **above** the line                    │
│     - For $ y < $ or $ y \leq $, shade **below** the line                    │
│                                                                              │
│  You can test a point (like $ (0,0) $) to check which side to shade.         │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Examples of Graphing Inequalities**                                       │
│                                                                              │
│  1. **Simple Linear Inequality**                                             │
│     Graph: $ y < x - 1 $                                                     │
│     - Draw dashed line for $ y = x - 1 $                                     │
│     - Test $ (0,0) $: $ 0 < 0 - 1 $? No → so shade the side *not*            │
│  containing (0,0), which is below the line                                   │
│                                                                              │
│  2. **Inequality with ≥**                                                    │
│     Graph: $ y \geq -2x + 3 $                                                │
│     - Draw solid line for $ y = -2x + 3 $                                    │
│     - Test $ (0,0) $: $ 0 \geq 3 $? No → shade the side *above* the line     │
│  (where $ y $ is larger)                                                     │
│                                                                              │
│  3. **Horizontal Line Inequality**                                           │
│     Graph: $ y \leq 4 $                                                      │
│     - Draw solid horizontal line at $ y = 4 $                                │
│     - Shade everything *below* it                                            │
│                                                                              │
