│  Linear equations are mathematical expressions that describe a straight      │
│  line when graphed. They are called "linear" because the highest power of    │
│  the variable is 1 (first degree). These equations show a relationship       │
│  between variables that, when plotted on a coordinate plane, form a          │
│  straight line.                                                              │
│                                                                              │
│  For one variable, the standard form of a linear equation is:                │
│  **ax + b = 0**                                                              │
│  where *a* and *b* are constants, and *x* is the variable.                   │
│                                                                              │
│  For two variables, the most common form is the slope-intercept form:        │
│  **y = mx + b**                                                              │
│  where *m* represents the slope of the line, and *b* is the y-intercept      │
│  (where the line crosses the y-axis).                                        │
│                                                                              │
│  Here’s a simple example of solving a linear equation:                       │
│  Solve for *x*:                                                              │
│  2x + 3 = 7                                                                  │
│  Subtract 3 from both sides:                                                 │
│  2x = 4                                                                      │
│  Divide both sides by 2:                                                     │
│  x = 2                                                                       │
│                                                                              │
│  So, the solution is **x = 2**.                                              │
│                                                                              │
│  Another example in two variables:                                           │
│  y = 2x + 1                                                                  │
│  If x = 3, then y = 2(3) + 1 = 7. So the point (3, 7) lies on this line.     │
│                                                                              │
│  **Brief Summary**:                                                          │
│  Linear equations are first-degree equations that graph as straight lines.   │
│  They can be written in forms like ax + b = 0 (one variable) or y = mx + b   │
│  (two variables), and are solved using basic algebraic operations.           │
│                                                                              │
│  This explanation is beginner-friendly and aligns with what a student would  │
│  learn in an introductory algebra lesson.                                    │

**Explanation of Linear Equations:**  
Linear equations are first-degree mathematical equations that produce straight lines when graphed. The term "linear" refers to the fact that the variable (or variables) are raised only to the first power.  

For one variable, the standard form is:  
**ax + b = 0**,  
where *a* and *b* are constants, and *x* is the variable to be solved for.  

For two variables, the most common representation is the slope-intercept form:  
**y = mx + b**,  
where *m* is the slope of the line and *b* is the y-intercept (the point where the line crosses the y-axis).  

**Example of solving a linear equation:**  
Solve for *x*:  
2x + 3 = 7  
Subtract 3 from both sides:  
2x = 4  
Divide both sides by 2:  
x = 2  
Thus, the solution is **x = 2**.  

Another example in two variables:  
Given y = 2x + 1, if x = 3, then y = 2(3) + 1 = 7. Therefore, the point (3, 7) lies on the line.  

In summary, linear equations describe linear relationships and can be solved using basic algebraic operations or visualized on a coordinate plane.
