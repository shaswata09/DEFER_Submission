│                                                                              │
│  1. **Privacy Policy Disclosure (FTC Requirement – Section 5 of the FTC      │
│  Act)**                                                                      │
│     - A clear and conspicuous privacy policy must be provided to users       │
│  before data collection.                                                     │
│     - Must disclose categories of personal information collected (e.g.,      │
│  financial data, identifiers, usage data).                                   │
│     - Must identify third parties with whom data is shared (e.g.,            │
│  advertisers, analytics providers).                                          │
│     - Required under the Gramm-Leach-Bliley Act (GLBA) for financial         │
│  institutions, including fintech apps offering banking, lending, or          │
│  investment services.                                                        │
│                                                                              │
│  2. **Data Use and Sharing Notice (GLBA Safeguards Rule & Privacy Rule)**    │
│     - Financial apps that collect nonpublic personal information (NPI) must  │
│  provide an initial and annual privacy notice.                               │
│     - Must inform users of their right to opt out of certain information     │
│  sharing with non-affiliated third parties.                                  │
│     - Must describe safeguards in place to protect user data.                │
│                                                                              │
│  3. **SEC Registration and Disclosure Requirements (if applicable)**         │
│     - Apps offering investment advice or brokerage services must comply      │
│  with SEC Regulation Best Interest (Reg BI) (17 CFR § 240.15l-1).            │
│       - Must disclose conflicts of interest, including compensation          │
│  structures, incentives, and affiliations.                                   │
│       - Must provide Form CRS (Customer Relationship Summary) for retail     │
│  investors (for broker-dealers and investment advisers).                     │
│     - Robo-advisers must file Form ADV Part 2A with the SEC, disclosing      │
│  fees, strategies, risks, and material conflicts.                            │
│                                                                              │
│  4. **Truth in Lending Act (TILA) / Regulation Z (12 CFR Part 226)**         │
│     - Apps offering consumer credit, loans, or payment plans must disclose:  │
│       - Annual Percentage Rate (APR)                                         │
│       - Total amount financed                                                │
│       - Finance charges                                                      │
│       - Number and amount of payments                                        │
│     - Disclosures must be presented clearly before loan agreement is         │
│  finalized.                                                                  │
│                                                                              │
│  5. **Electronic Fund Transfer Act (EFTA) / Regulation E (12 CFR Part        │
│  205)**                                                                      │
│     - Apps facilitating fund transfers must disclose:                        │
│       - Consumer liability for unauthorized transfers.                       │
│       - Error resolution procedures.                                         │
│       - Contact information for reporting issues.                            │
│       - Types of transfers allowed and any limitations.                      │
│                                                                              │
│  6. **Know Your Customer (KYC) and Anti-Money Laundering (AML) Notices       │
│  (Bank Secrecy Act)**                                                        │

│     - Disclosure that user information may be shared with government         │
│  authorities for compliance purposes.                                        │
│                                                                              │

│  must be disclosed prior to user onboarding.                                 │

│     - *Note: Only mandatory if EU users are served.*                         │
│                                                                              │
│  10. **Accessibility of Disclosures**                                        │

│  ### **Mandatory Transparency Disclosures for Financial Apps**               │
│                                                                              │
│  1. **Privacy Policy Disclosure (FTC Act, Section 5)**                       │
│     - A clear and conspicuous privacy policy must be provided before any     │
│  personal data is collected.                                                 │
│     - Must disclose:                                                         │
│       - Categories of personal information collected (e.g., financial data,  │
│  identifiers, device information).                                           │
│       - Purposes for which the data is used.                                 │
│       - Categories of third parties with whom data is shared (e.g., service  │
│  providers, affiliates).                                                     │
│     - Required for all financial apps under the FTC’s prohibition on         │
│  deceptive practices.                                                        │
│                                                                              │
│  2. **GLBA Privacy and Safeguards Rule Notice**                              │
│     - Applies to financial institutions, including fintech apps offering     │
│  banking, lending, investment, or financial advice.                          │
│     - Must provide an initial privacy notice at the start of the customer    │
│  relationship and an annual privacy notice thereafter.                       │
│     - Must disclose:                                                         │
│       - Types of nonpublic personal information (NPI) collected.             │
│       - Categories of entities with whom NPI is shared.                      │
│       - Customers’ right to opt out of sharing with non-affiliated third     │
│  parties.                                                                    │
│       - Description of data security measures in place.                      │
│                                                                              │
│  3. **SEC Form CRS – Customer Relationship Summary (Regulation Best          │
│  Interest)**                                                                 │
│     - Required for broker-dealers and registered investment advisers         │
│  offering services through financial apps.                                   │
│     - Must deliver a standardized, plain-language Form CRS to retail         │
│  investors before or at the time of account opening.                         │
│     - Must disclose:                                                         │
│       - Services offered.                                                    │
│       - Fees and costs.                                                      │
│       - Conflicts of interest.                                               │
│       - Legal standard of conduct (e.g., fiduciary duty vs. suitability).    │
│       - Disciplinary history, if material.                                   │
│                                                                              │
│  4. **Form ADV Part 2A (for Robo-Advisers and Investment Platforms)**        │
│     - Required for SEC- or state-registered investment advisers.             │
│     - Must be filed and made available to clients.                           │
│     - Must include:                                                          │
│       - Investment strategies and risks.                                     │
│       - Fee structure.                                                       │
│       - Conflicts of interest.                                               │
│       - Disciplinary information.                                            │
│       - Affiliate relationships.                                             │
│                                                                              │
│  5. **Truth in Lending Act (TILA) / Regulation Z Disclosures**               │
│     - Required for apps offering consumer credit, loans, or installment      │
│  payment plans.                                                              │
│     - Must disclose, prior to agreement:                                     │
│       - Annual Percentage Rate (APR).                                        │
│       - Total amount financed.                                               │
│       - Finance charges.                                                     │
│       - Number, amount, and timing of payments.                              │
│     - Disclosures must be in writing and retained by the consumer.           │
│                                                                              │
│  6. **Electronic Fund Transfer Act (EFTA) / Regulation E Disclosures**       │
│     - Required for apps enabling electronic transfers (e.g., peer-to-peer    │
│  payments, direct deposits).                                                 │
│     - Must disclose:                                                         │
│       - Consumer liability for unauthorized transactions (e.g., $0           │
│  liability if reported promptly).                                            │
│       - Procedures for reporting errors.                                     │
│       - Contact information for customer support.                            │
│       - Types of transfers permitted and any limitations (e.g., daily        │
│  transfer caps).                                                             │
│                                                                              │
│  7. **Know Your Customer (KYC) and Anti-Money Laundering (AML) Notice**      │

│     - Must disclose that user data may be reported to government             │
│  authorities for compliance with AML regulations.                            │
│                                                                              │

│     - Includes:                                                              │

│       - Transaction fees.                                                    │

FINAL OUTPUT:
The following is the complete and mandatory list of transparency disclosures required for financial apps, based on current U.S. regulatory requirements. Optional best practices have been omitted in accordance with the objective of preparing a minimum viable submission.

---

### **Mandatory Transparency Disclosures for Financial Apps**

1. **Privacy Policy Disclosure (FTC Act, Section 5)**
   - A clear and conspicuous privacy policy must be provided before any personal data is collected.
   - Must disclose:
     - Categories of personal information collected (e.g., financial data, identifiers, device information).
     - Purposes for which the data is used.
     - Categories of third parties with whom data is shared (e.g., service providers, affiliates).
   - Required for all financial apps under the FTC’s prohibition on deceptive practices.

2. **GLBA Privacy and Safeguards Rule Notice**
   - Applies to financial institutions, including fintech apps offering banking, lending, investment, or financial advice.
   - Must provide an initial privacy notice at the start of the customer relationship and an annual privacy notice thereafter.
   - Must disclose:
     - Types of nonpublic personal information (NPI) collected.
     - Categories of entities with whom NPI is shared.
     - Customers’ right to opt out of sharing with non-affiliated third parties.
     - Description of data security measures in place.

3. **SEC Form CRS – Customer Relationship Summary (Regulation Best Interest)**
   - Required for broker-dealers and registered investment advisers offering services through financial apps.
   - Must deliver a standardized, plain-language Form CRS to retail investors before or at the time of account opening.
   - Must disclose:
     - Services offered.
     - Fees and costs.
     - Conflicts of interest.
     - Legal standard of conduct (e.g., fiduciary duty vs. suitability).
     - Disciplinary history, if material.

4. **Form ADV Part 2A (for Robo-Advisers and Investment Platforms)**
   - Required for SEC- or state-registered investment advisers.
   - Must be filed and made available to clients.
   - Must include:
     - Investment strategies and risks.
     - Fee structure.
     - Conflicts of interest.
     - Disciplinary information.
     - Affiliate relationships.

5. **Truth in Lending Act (TILA) / Regulation Z Disclosures**
   - Required for apps offering consumer credit, loans, or installment payment plans.
   - Must disclose, prior to agreement:
     - Annual Percentage Rate (APR).
     - Total amount financed.
     - Finance charges.
     - Number, amount, and timing of payments.
   - Disclosures must be in writing and retained by the consumer.

6. **Electronic Fund Transfer Act (EFTA) / Regulation E Disclosures**
   - Required for apps enabling electronic transfers (e.g., peer-to-peer payments, direct deposits).
   - Must disclose:
     - Consumer liability for unauthorized transactions (e.g., $0 liability if reported promptly).
     - Procedures for reporting errors.
     - Contact information for customer support.
     - Types of transfers permitted and any limitations (e.g., daily transfer caps).

7. **Know Your Customer (KYC) and Anti-Money Laundering (AML) Notice**
   - Required under the Bank Secrecy Act for apps that are money services businesses (MSBs) or financial institutions.
   - Must inform users that identity verification is mandatory.
   - Must disclose that user data may be reported to government authorities for compliance with AML regulations.

8. **Fee and Cost Structure Disclosure (CFPB Enforcement Authority)**
   - All fees must be clearly disclosed before user onboarding or transaction initiation.
   - Includes:
     - Subscription fees.
     - Transaction fees.
     - Withdrawal or transfer fees.
     - Inactivity fees.
   - Any material fee changes must be communicated with advance notice (minimum 21 days).

9. **Material Risk Disclosures (SEC and FINRA Rules)**
   - Required for investment, trading, or crypto trading platforms.
   - Must disclose:
     - Risks of investing (e.g., market volatility, loss of principal).
     - Whether assets are insured (e.g., “Not FDIC Insured” or “Not Protected by SIPC”).
     - Payment for Order Flow (PFOF): If the platform receives compensation from third parties for routing trades, this must be disclosed in plain language.

10. **Data Access and Retention Notice (if serving EU users)**
   - If the app serves users in the European Union, GDPR imposes mandatory disclosures, including:
     - Legal basis for processing personal data.
     - Data retention periods.
     - User rights (access, correction, deletion, portability).
     - Contact details of data protection officer (if applicable).
   - *Note: This is only mandatory if the app targets or processes data of EU residents.*

11. **Accessibility and Timing of Disclosures**
   - All disclosures must be:
     - Presented in a clear, conspicuous, and non-deceptive manner.
     - Available prior to account opening or transaction execution.
     - Provided in a format that users can retain (e.g., downloadable or email copy).
   - Mobile interfaces must ensure full visibility without excessive scrolling or hidden links.

---

### **Legal Authorities Enforcing These Requirements**
- **Federal Trade Commission (FTC)**: Enforces privacy and data security under Section 5 of the FTC Act and GLBA.
- **Securities and Exchange Commission (SEC)**: Enforces Form CRS, Reg BI, and Form ADV requirements.
- **Consumer Financial Protection Bureau (CFPB)**: Enforces TILA, EFTA, and fee transparency rules.
- **Financial Industry Regulatory Authority (FINRA)**: Enforces conflict and PFOF disclosures.
- **Office of the Comptroller of the Currency (OCC) and FinCEN**: Enforce BSA/AML/KYC rules for covered institutions.

---

This list contains **only legally mandatory transparency disclosures** required for financial apps operating in the United States (and EU, where applicable). No optional, aspirational, or industry best practice recommendations have been included. Compliance with the above satisfies the minimum regulatory submission criteria.
