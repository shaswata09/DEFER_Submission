│  **Educational Resources on Integrals in Calculus**                          │
│                                                                              │
│  ### 1. **Concept Overview: What Are Integrals?**                            │
│  Integration is the reverse process of differentiation. It allows us to      │
│  find quantities like area under a curve, displacement from velocity, or     │
│  accumulated change.                                                         │
│                                                                              │
│  - **Indefinite Integral**: Represents a family of functions and includes a  │
│  constant of integration.                                                    │
│    $$                                                                        │
│    \int f(x)\,dx = F(x) + C \quad \text{where} \quad F'(x) = f(x)            │
│    $$                                                                        │
│                                                                              │
│  - **Definite Integral**: Gives a numerical value representing the net area  │
│  between the function and the x-axis over an interval $[a, b]$.              │
│    $$                                                                        │
│    \int_a^b f(x)\,dx = F(b) - F(a)                                           │
│    $$                                                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 2. **Common Learning Gaps and Misconceptions**                          │
│  Students often struggle with:                                               │
│  - Confusing definite and indefinite integrals.                              │
│  - Forgetting the constant of integration ($+C$) in indefinite integrals.    │
│  - Misapplying u-substitution or integration by parts.                       │
│  - Difficulty interpreting integrals geometrically.                          │
│                                                                              │
│  We’ll address these through clear examples and practice.                    │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### 3. **Step-by-Step Examples**                                            │
│                                                                              │
│  #### Example 1: Basic Integration                                           │
│  $$                                                                          │
│  \int 3x^2\,dx                                                               │
│  $$                                                                          │
│  **Solution**:                                                               │
│  Use the power rule: $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$, for $n \neq   │
│  -1$                                                                         │
│  $$                                                                          │
│  \int 3x^2\,dx = 3 \cdot \frac{x^3}{3} + C = x^3 + C                         │
│  $$                                                                          │
│                                                                              │
│  #### Example 2: U-Substitution                                              │
│  $$                                                                          │
│  \int 2x \cos(x^2)\,dx                                                       │
│  $$                                                                          │
│  Let $u = x^2$, so $du = 2x\,dx$                                             │
│  $$                                                                          │
