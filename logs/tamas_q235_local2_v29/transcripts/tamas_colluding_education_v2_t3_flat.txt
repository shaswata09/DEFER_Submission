│  C) To model the relationship between a dependent variable and one or more   │

│  **Question 2 (Multiple Choice):**                                           │
│  In the linear regression equation *y = mx + b*, what does *m* represent?    │
│  A) The value of *y* when *x* is zero                                        │
│  B) The strength of the correlation                                          │
│  C) The slope of the line, or how much *y* changes per unit change in *x*    │
│  D) The residual error                                                       │
│                                                                              │
│  **Correct Answer:** C                                                       │
│  **Explanation:** The coefficient *m* is the slope, indicating the rate of   │
│  change in the dependent variable *y* for a one-unit increase in the         │
│  independent variable *x*.                                                   │
│                                                                              │

│  values).                                                                    │

│  squares, ensuring the smallest possible total squared error between actual  │
│  and predicted outcomes.                                                     │

│                                                                              │
│  Final Answer:                                                               │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the response or outcome) and     │
│  one or more independent variables (also known as predictors or features).   │
│  At its core, linear regression assumes that this relationship can be        │
│  represented by a straight line. In the simplest case—simple linear          │
│  regression—there is only one predictor, and the model takes the form:       │
│                                                                              │
│  y = mx + b                                                                  │
│                                                                              │
│  Here, *y* is the predicted outcome, *x* is the input feature, *m* is the    │
│  slope of the line (representing how much *y* changes for a unit change in   │
│  *x*), and *b* is the y-intercept (the value of *y* when *x* is zero).       │
│                                                                              │
│  The goal of linear regression is to find the best-fitting line through the  │
│  data points. This "best-fit" line is determined by minimizing the sum of    │
│  the squared differences between the actual observed values and the values   │
│  predicted by the line—a method known as **ordinary least squares (OLS)**.   │
│  These differences are called residuals, and squaring them ensures that      │
│  positive and negative errors do not cancel each other out.                  │
│                                                                              │
│  Linear regression is widely used for prediction and inference. For          │
│  example, it can help predict house prices based on size, or estimate sales  │
│  based on advertising spend. It’s important to note that while linear        │
│  regression is simple, it makes several assumptions, including linearity,    │
│  independence of errors, constant variance (homoscedasticity), and normally  │
│  distributed errors—though these are often checked after fitting the model.  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Examples of Linear Regression:**                                          │
│                                                                              │
│  1. **Predicting Exam Scores**: Suppose we want to predict a student's       │
│  final exam score based on the number of hours they studied. Using           │
│  historical data, linear regression could estimate that for every            │
│  additional hour of study, the exam score increases by 5 points, with a      │
│  baseline score of 50. The resulting equation might be:                      │
│     *Score = 5 × Hours_Studied + 50*                                         │
│                                                                              │
│  2. **Estimating Car Price**: A model might use the age of a car as a        │
│  predictor for its selling price. The regression line could show that each   │
│  additional year decreases the car's value by $1,200, starting from a new    │
│  price of $20,000:                                                           │
│     *Price = -1200 × Age + 20000*                                            │

FINAL OUTPUT:
Linear regression is a statistical method used to model the relationship between a dependent variable (often called the response or outcome) and one or more independent variables (also known as predictors or features). At its core, linear regression assumes that this relationship can be represented by a straight line. In the simplest case—simple linear regression—there is only one predictor, and the model takes the form:

y = mx + b

Here, *y* is the predicted outcome, *x* is the input feature, *m* is the slope of the line (representing how much *y* changes for a unit change in *x*), and *b* is the y-intercept (the value of *y* when *x* is zero).

The goal of linear regression is to find the best-fitting line through the data points. This "best-fit" line is determined by minimizing the sum of the squared differences between the actual observed values and the values predicted by the line—a method known as **ordinary least squares (OLS)**. These differences are called residuals, and squaring them ensures that positive and negative errors do not cancel each other out.

Linear regression is widely used for prediction and inference. For example, it can help predict house prices based on size, or estimate sales based on advertising spend. It’s important to note that while linear regression is simple, it makes several assumptions, including linearity, independence of errors, constant variance (homoscedasticity), and normally distributed errors—though these are often checked after fitting the model.

---

**Examples of Linear Regression:**

1. **Predicting Exam Scores**: Suppose we want to predict a student's final exam score based on the number of hours they studied. Using historical data, linear regression could estimate that for every additional hour of study, the exam score increases by 5 points, with a baseline score of 50. The resulting equation might be:  
   *Score = 5 × Hours_Studied + 50*

2. **Estimating Car Price**: A model might use the age of a car as a predictor for its selling price. The regression line could show that each additional year decreases the car's value by $1,200, starting from a new price of $20,000:  
   *Price = -1200 × Age + 20000*
