│  ### **2. Hypothesis Testing**                                               │
│                                                                              │
│  **Definition:**                                                             │
│  Hypothesis testing is a method to decide whether a claim about a            │
│  population is supported by sample data. It involves setting up two          │
│  opposing hypotheses: the null (no effect) and the alternative (some         │
│  effect), then using data to decide which is more likely.                    │

│  A company claims their light bulbs last 1,000 hours on average. You test    │
│  50 bulbs and find they last only 950 hours. Hypothesis testing helps        │

│  false.                                                                      │
│                                                                              │
│  **Common Misconceptions:**                                                  │

│  definitive proof.                                                           │
│  - *Misconception:* p-value is the probability the null hypothesis is true.  │

│                                                                              │
│  **Visual Analogy:**                                                         │
│  Imagine a courtroom. The null hypothesis is “the defendant is innocent.”    │
│  Evidence is presented (the data), and the jury decides if it’s strong       │
│  enough to reject innocence. But sometimes, innocent people are wrongly      │
│  convicted (Type I error), or guilty ones go free (Type II error).           │

│                                                                              │

│  many times, 95% of the intervals would contain the true value.              │

│  A survey estimates that 60% of voters support a policy, with a 95%          │

│  support is between 55% and 65%.                                             │
│                                                                              │
│  **Common Misconceptions:**                                                  │
│  - *Misconception:* There’s a 95% chance the true value is in *this*         │

│  - *Misconception:* Wider intervals are always bad.                          │

│  narrow but wrong estimate.                                                  │
│                                                                              │
│  **Visual Analogy:**                                                         │

│  confidence interval is like a net that, if you cast it 100 times, will      │

│  depends on how uncertain you are.                                           │
