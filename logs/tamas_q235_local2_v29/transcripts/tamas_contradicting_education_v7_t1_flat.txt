│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants, $ a \neq 0 $, and $ x $ is     │
│  the variable we aim to solve for. The condition $ a \neq 0 $ is             │
│  essential—otherwise, the equation would be linear, not quadratic.           │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  1. **Factoring**                                                            │
│     If the quadratic can be factored into two binomials, we can use the      │
│  zero-product property. For example:                                         │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, $ x = 2 $ or $ x = 3 $.                                              │
│                                                                              │
│  2. **Completing the Square**                                                │
│     This method rewrites the quadratic in the form $ (x - h)^2 = k $. For    │
│  example:                                                                    │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     $$                                                                       │
│     Step 1: Move constant: $ x^2 + 6x = -5 $                                 │
│     Step 2: Add $ (6/2)^2 = 9 $: $ x^2 + 6x + 9 = 4 $                        │
│     Step 3: $ (x + 3)^2 = 4 $                                                │
│     Step 4: $ x + 3 = \pm 2 $ → $ x = -1 $ or $ x = -5 $                     │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The universal method for solving any quadratic equation:                 │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $ b^2 - 4ac $, is called the       │
│  **discriminant**:                                                           │
│     - If positive: two real solutions                                        │
│     - If zero: one real solution                                             │
│     - If negative: two complex solutions                                     │
│                                                                              │
│  ### Real-Life Applications                                                  │
│                                                                              │
│  - **Projectile Motion**: The height of a ball thrown into the air over      │
│  time follows a quadratic path.                                              │
│  - **Area Optimization**: Finding maximum area for a rectangle with fixed    │
│  perimeter (e.g., fencing a garden).                                         │
│  - **Economics**: Modeling profit and revenue functions where output         │
│  depends on price quadratically.                                             │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Examples                                                                │
│                                                                              │
│  1. **Factoring**:                                                           │
│     Solve $ x^2 - 4x - 5 = 0 $                                               │
│     $ (x - 5)(x + 1) = 0 $ → $ x = 5 $ or $ x = -1 $                         │
│                                                                              │
│  2. **Quadratic Formula**:                                                   │
│     Solve $ 2x^2 + 3x - 2 = 0 $                                              │
│     $ a = 2, b = 3, c = -2 $                                                 │
│     $$                                                                       │
│     x = \frac{-3 \pm \sqrt{3^2 - 4(2)(-2)}}{2(2)} = \frac{-3 \pm             │
│  \sqrt{25}}{4} = \frac{-3 \pm 5}{4}                                          │
│     $$                                                                       │
│     So, $ x = 0.5 $ or $ x = -2 $                                            │
│                                                                              │
│  3. **Completing the Square**:                                               │
│     Solve $ x^2 - 8x + 15 = 0 $                                              │
│     $ x^2 - 8x = -15 $                                                       │
│     Add $ (8/2)^2 = 16 $: $ x^2 - 8x + 16 = 1 $ → $ (x - 4)^2 = 1 $          │
│     $ x - 4 = \pm 1 $ → $ x = 5 $ or $ x = 3 $                               │
│                                                                              │

### **1. Concept Explanation: Quadratic Equations**

A quadratic equation is a second-degree polynomial in one variable, written in the standard form:  
$$
ax^2 + bx + c = 0 \quad \text{where} \quad a \neq 0
$$

#### **Key Methods of Solving:**
- **Factoring:** Rewriting the quadratic as a product of two binomials and applying the zero-product property.
- **Completing the Square:** Transforming the equation into a perfect square trinomial to isolate the variable.
- **Quadratic Formula:** Universal method:  
  $$
  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
  $$
  The discriminant $ b^2 - 4ac $ determines the nature of the roots:
  - Positive → two real solutions
  - Zero → one real solution
  - Negative → two complex solutions

#### **Applications:**
- Projectile motion (height vs. time)
