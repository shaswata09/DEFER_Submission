│  Final Answer:                                                               │
│  The **mean** and **median** are both measures of central tendency used to   │
│  describe the center of a data set, but they do so in different ways and     │
│  are suited to different types of data.                                      │
│                                                                              │
│  The **mean** is the average of all the values in a data set. To calculate   │
│  it, you add up all the numbers and divide by the total number of values.    │
│  For example, in the data set [3, 5, 7, 9, 11], the mean is (3 + 5 + 7 + 9   │
│  + 11) / 5 = 7. Another example: in [2, 4, 6, 8], the mean is (2 + 4 + 6 +   │
│  8) / 4 = 5. The mean is useful when the data is symmetrically distributed   │
│  and there are no extreme outliers.                                          │

│  The **mean** and **median** are both measures of central tendency used to   │
│  describe the center of a data set, but they do so in different ways and     │
│  are suited to different types of data.                                      │
│                                                                              │
│  The **mean** is the average of all the values in a data set. To calculate   │
│  it, you add up all the numbers and divide by the total number of values.    │
│  For example, in the data set [3, 5, 7, 9, 11], the mean is (3 + 5 + 7 + 9   │
│  + 11) / 5 = 7. Another example: in [2, 4, 6, 8], the mean is (2 + 4 + 6 +   │
│  8) / 4 = 5. The mean is useful when the data is symmetrically distributed   │
│  and there are no extreme outliers.                                          │
│                                                                              │
│  The **median**, on the other hand, is the middle value when the data is     │
│  arranged in order. If there’s an odd number of observations, the median is  │
│  the center value. In the same data set [3, 5, 7, 9, 11], the median is 7.   │
│  If there’s an even number of observations, the median is the average of     │
│  the two middle numbers. For example, in [2, 4, 6, 8], the median is (4 +    │
│  6) / 2 = 5. The median is especially useful when the data has outliers or   │
│  is skewed.                                                                  │
│                                                                              │
│  A key difference is that the **mean is sensitive to extreme values          │
│  (outliers)**, while the **median is not**. For instance, consider           │
│  household incomes in a neighborhood: if most people earn around $50,000     │
│  but one person earns $5 million, the mean income would be much higher than  │
│  what most people make, giving a misleading impression. In this case, the    │
│  median income would better represent the typical person’s earnings.         │
│                                                                              │
│  Because of this, the **median is often preferred** when dealing with        │
│  skewed data like income, home prices, or test scores with outliers. The     │
│  **mean is preferred** when the data is evenly distributed and you want to   │
│  use all values in your calculation, such as in scientific measurements or   │
│  averaging grades.                                                           │
│                                                                              │
│  In summary:                                                                 │
│  - Use the **mean** for symmetric data without outliers.                     │
│  - Use the **median** for skewed data or when outliers are present.          │

FINAL OUTPUT:
The **mean** and **median** are both measures of central tendency used to describe the center of a data set, but they do so in different ways and are suited to different types of data.

The **mean** is the average of all the values in a data set. To calculate it, you add up all the numbers and divide by the total number of values. For example, in the data set [3, 5, 7, 9, 11], the mean is (3 + 5 + 7 + 9 + 11) / 5 = 7. Another example: in [2, 4, 6, 8], the mean is (2 + 4 + 6 + 8) / 4 = 5. The mean is useful when the data is symmetrically distributed and there are no extreme outliers.

The **median**, on the other hand, is the middle value when the data is arranged in order. If there’s an odd number of observations, the median is the center value. In the same data set [3, 5, 7, 9, 11], the median is 7. If there’s an even number of observations, the median is the average of the two middle numbers. For example, in [2, 4, 6, 8], the median is (4 + 6) / 2 = 5. The median is especially useful when the data has outliers or is skewed.

A key difference is that the **mean is sensitive to extreme values (outliers)**, while the **median is not**. For instance, consider household incomes in a neighborhood: if most people earn around $50,000 but one person earns $5 million, the mean income would be much higher than what most people make, giving a misleading impression. In this case, the median income would better represent the typical person’s earnings.

Because of this, the **median is often preferred** when dealing with skewed data like income, home prices, or test scores with outliers. The **mean is preferred** when the data is evenly distributed and you want to use all values in your calculation, such as in scientific measurements or averaging grades.

In summary:
- Use the **mean** for symmetric data without outliers.
- Use the **median** for skewed data or when outliers are present.
