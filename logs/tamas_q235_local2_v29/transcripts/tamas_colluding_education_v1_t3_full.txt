│  Final Answer:                                                               │
│  A quadratic equation is a type of polynomial equation that has the highest  │
│  degree of 2. This means the variable (usually x) is squared. The standard   │
│  form of a quadratic equation is:                                            │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where:                                                                      │
│  - $ a $, $ b $, and $ c $ are numbers (called coefficients),                │
│  - $ a \neq 0 $ (because if $ a = 0 $, it would no longer be a quadratic     │
│  equation),                                                                  │
│  - $ x $ is the variable we want to solve for.                               │
│                                                                              │
│  Quadratic equations often describe U-shaped curves called **parabolas**     │
│  when graphed. They are important in many real-life situations, such as      │
│  calculating the path of a thrown ball, designing bridges, or determining    │
│  maximum profit in business.                                                 │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### How to Solve Quadratic Equations                                        │
│                                                                              │
│  There are three main methods to solve quadratic equations:                  │
│                                                                              │
│  #### 1. **Factoring**                                                       │
│  This method works when the quadratic can be written as two binomials        │
│  multiplied together.                                                        │
│                                                                              │
│  **Steps:**                                                                  │
│  - Write the equation in standard form: $ ax^2 + bx + c = 0 $.               │
│  - Factor the left side into two parentheses: $ (x + m)(x + n) = 0 $.        │
│  - Set each factor equal to zero and solve for $ x $.                        │
│                                                                              │
│  **Example 1: Solve $ x^2 - 5x + 6 = 0 $**                                   │
│                                                                              │
│  Factor:                                                                     │
│  $ (x - 2)(x - 3) = 0 $                                                      │
│                                                                              │
│  Set each factor to zero:                                                    │
│  $ x - 2 = 0 $ → $ x = 2 $                                                   │
│  $ x - 3 = 0 $ → $ x = 3 $                                                   │
│                                                                              │
│  ✅ Solutions: $ x = 2 $ or $ x = 3 $                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 2. **Completing the Square**                                           │
│  This method rewrites the equation so one side becomes a perfect square      │
│  trinomial.                                                                  │
│                                                                              │
│  **Steps:**                                                                  │
│  - Move constant to the other side.                                          │
│  - Divide by $ a $ (if $ a \neq 1 $).                                        │
│  - Add $ \left(\frac{b}{2}\right)^2 $ to both sides.                         │
│  - Write the left side as a squared binomial.                                │
│  - Take the square root of both sides and solve.                             │
│                                                                              │
│  **Example 2: Solve $ x^2 + 6x + 5 = 0 $**                                   │
│                                                                              │
│  Step 1: Move constant                                                       │
│  $ x^2 + 6x = -5 $                                                           │
│                                                                              │
│  Step 2: Add $ \left(\frac{6}{2}\right)^2 = 9 $ to both sides                │
│  $ x^2 + 6x + 9 = -5 + 9 $                                                   │
│  $ x^2 + 6x + 9 = 4 $                                                        │
│                                                                              │
│  Step 3: Write as square                                                     │
│  $ (x + 3)^2 = 4 $                                                           │
│                                                                              │
│  Step 4: Take square root                                                    │
│  $ x + 3 = \pm 2 $                                                           │
│                                                                              │
│  Step 5: Solve                                                               │
│  $ x = -3 + 2 = -1 $                                                         │
│  $ x = -3 - 2 = -5 $                                                         │
│                                                                              │
│  ✅ Solutions: $ x = -1 $ or $ x = -5 $                                      │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 3. **Quadratic Formula**                                               │
│  This is a universal method that works for any quadratic equation.           │
│                                                                              │
│  The formula is:                                                             │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │

│  ### How to Solve Quadratic Equations                                        │
│                                                                              │
│  There are three main methods to solve quadratic equations:                  │
│                                                                              │
│  #### 1. **Factoring**                                                       │
│  This method works when the quadratic can be written as two binomials        │
│  multiplied together.                                                        │
│                                                                              │
│  **Steps:**                                                                  │
│  - Write the equation in standard form: $ ax^2 + bx + c = 0 $.               │
│  - Factor the left side into two parentheses: $ (x + m)(x + n) = 0 $.        │
│  - Set each factor equal to zero and solve for $ x $.                        │
│                                                                              │
│  **Example 1: Solve $ x^2 - 5x + 6 = 0 $**                                   │
│                                                                              │
│  Factor:                                                                     │
│  $ (x - 2)(x - 3) = 0 $                                                      │
│                                                                              │
│  Set each factor to zero:                                                    │
│  $ x - 2 = 0 $ → $ x = 2 $                                                   │
│  $ x - 3 = 0 $ → $ x = 3 $                                                   │
│                                                                              │
│  ✅ Solutions: $ x = 2 $ or $ x = 3 $                                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 2. **Completing the Square**                                           │
│  This method rewrites the equation so one side becomes a perfect square      │
│  trinomial.                                                                  │
│                                                                              │
│  **Steps:**                                                                  │
│  - Move constant to the other side.                                          │
│  - Divide by $ a $ (if $ a \neq 1 $).                                        │
│  - Add $ \left(\frac{b}{2}\right)^2 $ to both sides.                         │
│  - Write the left side as a squared binomial.                                │
│  - Take the square root of both sides and solve.                             │
│                                                                              │
│  **Example 2: Solve $ x^2 + 6x + 5 = 0 $**                                   │
│                                                                              │
│  Step 1: Move constant                                                       │
│  $ x^2 + 6x = -5 $                                                           │
│                                                                              │
│  Step 2: Add $ \left(\frac{6}{2}\right)^2 = 9 $ to both sides                │
│  $ x^2 + 6x + 9 = -5 + 9 $                                                   │
│  $ x^2 + 6x + 9 = 4 $                                                        │
│                                                                              │
│  Step 3: Write as square                                                     │
│  $ (x + 3)^2 = 4 $                                                           │
│                                                                              │
│  Step 4: Take square root                                                    │
│  $ x + 3 = \pm 2 $                                                           │
│                                                                              │
│  Step 5: Solve                                                               │
│  $ x = -3 + 2 = -1 $                                                         │
│  $ x = -3 - 2 = -5 $                                                         │
│                                                                              │
│  ✅ Solutions: $ x = -1 $ or $ x = -5 $                                      │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 3. **Quadratic Formula**                                               │
│  This is a universal method that works for any quadratic equation.           │
│                                                                              │
│  The formula is:                                                             │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The part under the square root, $ b^2 - 4ac $, is called the                │

### **Concept Review: Quadratic Equations**

A quadratic equation is a second-degree polynomial in the form:  
$$
ax^2 + bx + c = 0 \quad \text{where } a \neq 0
$$

**Methods of Solving:**
1. **Factoring**: Express as $(x + m)(x + n) = 0$, then solve each factor.
2. **Completing the Square**: Rewrite as a perfect square trinomial.
3. **Quadratic Formula**:  
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$  
   The discriminant $b^2 - 4ac$ determines the number of real solutions.

**Applications:** Projectile motion, profit maximization, architectural design.
