│                                                                              │
│  ### Understanding the Unit Circle                                           │
│                                                                              │
│  Imagine a circle drawn on a graph where the center is at point (0, 0), and  │
│  the distance from the center to any point on the edge of the circle is      │
│  exactly 1. This is the unit circle. Any angle can be represented as a       │
│  rotation from the positive x-axis. The angle can be measured in degrees or  │
│  radians.                                                                    │
│                                                                              │
│  When we draw a radius from the center to a point on the circle, forming an  │
│  angle θ (theta) with the positive x-axis, the coordinates of that point     │
│  are (cos θ, sin θ). This means:                                             │
│  - The **x-coordinate** is the **cosine** of the angle.                      │
│  - The **y-coordinate** is the **sine** of the angle.                        │
│                                                                              │
│  For example:                                                                │
│  - At 0° (or 0 radians), the point is (1, 0), so cos(0°) = 1 and sin(0°) =   │
│  0.                                                                          │
│  - At 90° (or π/2 radians), the point is (0, 1), so cos(90°) = 0 and         │
│  sin(90°) = 1.                                                               │
│  - At 180° (or π radians), the point is (-1, 0), so cos(180°) = -1 and       │
│  sin(180°) = 0.                                                              │
│                                                                              │
│  This pattern continues all the way around the circle, allowing us to find   │
│  sine and cosine values for any angle.                                       │
│                                                                              │
│  ### Key Angles to Remember                                                  │
│                                                                              │
│  Some common angles and their coordinates on the unit circle include:        │
│  - **30° (π/6)**: (√3/2, 1/2)                                                │
│  - **45° (π/4)**: (√2/2, √2/2)                                               │
│  - **60° (π/3)**: (1/2, √3/2)                                                │
│                                                                              │
│  These values repeat in each quadrant, with sign changes depending on the    │
│  quadrant (positive or negative x and y values).                             │
│                                                                              │
│  ### Examples                                                                │
│                                                                              │
│  1. **Find cos(60°) and sin(60°)**                                           │
│     On the unit circle, 60° corresponds to the point (1/2, √3/2).            │

│                                                                              │
│  2. **What are the coordinates for 135°?**                                   │
│     135° is in the second quadrant. It corresponds to an angle of π - π/4 =  │
│  3π/4.                                                                       │

│  √2/2.                                                                       │
│                                                                              │
│  3. **Find sin(270°)**                                                       │
│     At 270°, the point is (0, -1). So, sin(270°) = -1.                       │
│                                                                              │

### The Unit Circle – Full Educational Content

The unit circle is a fundamental concept in trigonometry that helps us understand the relationships between angles and the trigonometric functions sine, cosine, and tangent. It is a circle with a radius of 1 unit, centered at the origin (0, 0) of the coordinate plane.

#### Understanding the Unit Circle

Imagine a circle drawn on a graph where the center is at point (0, 0), and the distance from the center to any point on the edge of the circle is exactly 1. This is the unit circle. Any angle can be represented as a rotation from the positive x-axis. The angle can be measured in degrees or radians.

When we draw a radius from the center to a point on the circle, forming an angle θ (theta) with the positive x-axis, the coordinates of that point are (cos θ, sin θ). This means:
- The **x-coordinate** is the **cosine** of the angle.
- The **y-coordinate** is the **sine** of the angle.

For example:
- At 0° (or 0 radians), the point is (1, 0), so cos(0°) = 1 and sin(0°) = 0.
- At 90° (or π/2 radians), the point is (0, 1), so cos(90°) = 0 and sin(90°) = 1.
- At 180° (or π radians), the point is (-1, 0), so cos(180°) = -1 and sin(180°) = 0.

This pattern continues all the way around the circle, allowing us to find sine and cosine values for any angle.

#### Key Angles to Remember

Some common angles and their coordinates on the unit circle include:
- **30° (π/6)**: (√3/2, 1/2)
- **45° (π/4)**: (√2/2, √2/2)
- **60° (π/3)**: (1/2, √3/2)

These values repeat in each quadrant, with sign changes depending on the quadrant (positive or negative x and y values).

#### Examples

1. **Find cos(60°) and sin(60°)**  
   On the unit circle, 60° corresponds to the point (1/2, √3/2).  
   So, cos(60°) = 1/2 and sin(60°) = √3/2.

2. **What are the coordinates for 135°?**  
   135° is in the second quadrant. It corresponds to an angle of π - π/4 = 3π/4.  
   The coordinates are (-√2/2, √2/2), so cos(135°) = -√2/2 and sin(135°) = √2/2.

3. **Find sin(270°)**  
   At 270°, the point is (0, -1). So, sin(270°) = -1.

#### Why Is It Useful?

The unit circle allows us to:
- Find exact values of trigonometric functions.
- Understand how sine and cosine values repeat every 360° (or 2π radians).
- Visualize periodic behavior of waves and oscillations.
