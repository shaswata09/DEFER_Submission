│  Final Answer:                                                               │
│  Calculus is a branch of mathematics that studies how things change and      │
│  accumulate. It is built on three foundational concepts: limits,             │
│  derivatives, and integrals. These ideas are interconnected and form the     │
│  basis for understanding motion, growth, area, and many real-world           │
│  phenomena.                                                                  │
│                                                                              │
│  **1. Limits**                                                               │
│  A limit describes the value that a function approaches as the input gets    │
│  closer and closer to a certain point. It’s about predicting where a         │
│  function is heading, even if it never actually reaches that point.          │
│                                                                              │
│  For example:                                                                │
│  - As x gets closer to 2, the function f(x) = (x² - 4)/(x - 2) simplifies    │
│  to x + 2 (for x ≠ 2), so the limit as x approaches 2 is 4—even though the   │
│  function is undefined at x = 2.                                             │
│  - Imagine walking toward a door but only covering half the remaining        │
│  distance each time. You’ll get closer and closer to the door but never      │
│  quite reach it. The door represents the limit.                              │
│                                                                              │
│  Limits are essential because they allow us to define derivatives and        │
│  integrals rigorously.                                                       │
│                                                                              │
│  **2. Derivatives**                                                          │
│  The derivative measures how a function changes as its input                 │
│  changes—essentially, the rate of change or the slope of a curve at any      │
│  given point.                                                                │
│                                                                              │
│  For example:                                                                │
│  - If you’re driving, your speedometer shows your instantaneous speed—this   │
│  is the derivative of your position with respect to time.                    │
│  - For the function f(x) = x², the derivative is f’(x) = 2x. This tells us   │
│  that at any point x, the slope of the tangent line to the curve is 2x.      │
│                                                                              │
│  Derivatives are used to find maximums and minimums, model population        │
│  growth, and understand physical laws like velocity and acceleration.        │
│                                                                              │
│  **3. Integrals**                                                            │
│  An integral represents the accumulation of quantities, such as area under   │
│  a curve, total distance traveled, or accumulated growth over time.          │
│                                                                              │
│  For example:                                                                │
│  - If you know your speed at every moment during a trip, integrating that    │
│  speed over time gives you the total distance traveled.                      │
│  - The integral of f(x) = 2x from 0 to 3 is the area under the line y = 2x   │
│  from x = 0 to x = 3, which forms a triangle with area = ½ × base × height   │
│  = ½ × 3 × 6 = 9.                                                            │
│                                                                              │
│  Integrals “add up” small pieces to find a whole, making them powerful       │
│  tools in physics, engineering, and economics.                               │
│                                                                              │
│  **How These Concepts Connect**                                              │
│  Derivatives and integrals are inverse operations—this is known as the       │
│  Fundamental Theorem of Calculus. Just as subtraction undoes addition,       │
│  integration undoes differentiation. For instance, if you differentiate a    │
│  position function, you get velocity; if you integrate velocity, you         │
│  recover position (up to a constant).                                        │
│                                                                              │
│  **Comparison: Derivatives vs. Integrals**                                   │
│  - *Similarities*: Both involve limits and are used to analyze functions.    │
│  They are central to modeling real-world dynamic systems.                    │
│  - *Differences*: Derivatives focus on rates of change (local behavior),     │
│  while integrals focus on accumulation (global behavior). Graphically,       │
│  derivatives give slopes; integrals give areas.                              │

│  ### 🔍 **Part 1: Calculus Fundamentals – Explained**                        │
│                                                                              │
│  Calculus is a branch of mathematics that studies how things change and      │
│  accumulate. It is built on three foundational concepts:                     │
│                                                                              │
│  #### **1. Limits**                                                          │
│  A limit describes the value a function approaches as the input gets         │
│  arbitrarily close to a certain point. It allows us to define derivatives    │
│  and integrals rigorously, even when a function is undefined at a point.     │
│                                                                              │
│  **Example:**                                                                │
│  $$                                                                          │
│  \lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x + 2) = 4           │
│  $$                                                                          │
│  Even though the function is undefined at $ x = 2 $, the limit exists.       │
│                                                                              │
│  #### **2. Derivatives**                                                     │
│  The derivative measures the instantaneous rate of change of a function —    │
│  geometrically, it's the slope of the tangent line at a point.               │
│                                                                              │
│  **Example:**                                                                │
│  For $ f(x) = x^2 $, the derivative is $ f'(x) = 2x $. At $ x = 3 $, the     │
│  slope is 6.                                                                 │
│                                                                              │
│  **Applications:** velocity, optimization, related rates.                    │
│                                                                              │
│  #### **3. Integrals**                                                       │
│  An integral represents the accumulation of quantities, such as area under   │
│  a curve or total distance traveled.                                         │
│                                                                              │
│  **Example:**                                                                │
│  $$                                                                          │
│  \int_0^3 2x \, dx = \left[ x^2 \right]_0^3 = 9                              │

### 🔍 **Part 1: Calculus Fundamentals – Explained**

Calculus is a branch of mathematics that studies how things change and accumulate. It is built on three foundational concepts:

#### **1. Limits**
A limit describes the value a function approaches as the input gets arbitrarily close to a certain point. It allows us to define derivatives and integrals rigorously, even when a function is undefined at a point.

**Example:**  
$$
\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} (x + 2) = 4
$$  
Even though the function is undefined at $ x = 2 $, the limit exists.

#### **2. Derivatives**
The derivative measures the instantaneous rate of change of a function — geometrically, it's the slope of the tangent line at a point.

**Example:**  
For $ f(x) = x^2 $, the derivative is $ f'(x) = 2x $. At $ x = 3 $, the slope is 6.

**Applications:** velocity, optimization, related rates.

#### **3. Integrals**
An integral represents the accumulation of quantities, such as area under a curve or total distance traveled.

**Example:**  
$$
\int_0^3 2x \, dx = \left[ x^2 \right]_0^3 = 9
$$  
This is the area under $ y = 2x $ from 0 to 3.

#### **Fundamental Theorem of Calculus**
Derivatives and integrals are inverses:  
$$
\frac{d}{dx} \int_a^x f(t)\,dt = f(x)
$$
