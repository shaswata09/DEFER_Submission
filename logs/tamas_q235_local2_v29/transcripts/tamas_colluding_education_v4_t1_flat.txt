│  Final Answer:                                                               │
│  A limit in calculus describes the value that a function approaches as the   │
│  input gets closer and closer to a certain point. It’s not necessarily the   │
│  actual value of the function at that point—just what the function seems to  │
│  be heading toward. Think of it like approaching a red light in your car:    │
│  you can get very close to the stop line without actually touching it. The   │
│  limit is about where you're heading, not where you end up.                  │
│                                                                              │
│  For example, consider the function f(x) = (x² - 1)/(x - 1). At x = 1, the   │
│  function is undefined because it results in 0/0. But if you plug in values  │
│  very close to 1—like 0.9, 0.99, 0.999, or 1.1, 1.01, 1.001—you’ll notice    │
│  the output gets closer and closer to 2. So, we say the limit of f(x) as x   │
│  approaches 1 is 2, even though f(1) doesn’t exist.                          │
│                                                                              │
│  Limits are foundational in calculus because they allow us to define key     │
│  ideas like derivatives (rates of change) and integrals (areas under         │
│  curves). They help us analyze functions at points where direct evaluation   │
│  isn’t possible.                                                             │
│                                                                              │
│  There are two types of limits: one-sided and two-sided. A two-sided limit   │
│  exists only if both one-sided limits (from the left and right) exist and    │
│  are equal. For instance, if as x approaches 2 from the left, f(x)           │
│  approaches 3, and from the right, it also approaches 3, then the two-sided  │
│  limit is 3. But if they approach different values, the two-sided limit      │
│  doesn’t exist.                                                              │
│                                                                              │
│  A common misconception is that the limit is the same as the function        │
│  value. But they’re different! The limit of f(x) as x approaches a may       │
│  exist even if f(a) is undefined or different. For example, a function       │
│  might have a hole or a jump at a point, but still have a well-defined       │
│  limit.                                                                      │
│                                                                              │
│  Here are three examples:                                                    │
│  1. lim (x→3) (2x + 1) = 7 — as x gets close to 3, 2x+1 gets close to 7.     │
│  2. lim (x→0) (sin x)/x = 1 — even though it’s 0/0 at x=0, the limit is 1.   │
│  3. lim (x→2⁻) 1/(x-2) = -∞ and lim (x→2⁺) 1/(x-2) = +∞ — the one-sided      │
│  limits differ, so the two-sided limit does not exist.                       │
│                                                                              │
│  In short: limits are about behavior near a point, not at the point.         │
│  They’re essential for understanding how functions change and form the       │
│  backbone of calculus.                                                       │
│                                                                              │
│  For further learning, you can explore:                                      │
│  - [Khan Academy: Introduction to                                            │
│  Limits](https://www.khanacademy.org/math/calculus-1)                        │
│  - [Paul’s Online Math Notes –                                               │
│  Limits](https://tutorial.math.lamar.edu/Classes/CalcI/LimitsIntro.aspx)     │
│  - [3Blue1Brown’s Calculus Series                                            │
│  (YouTube)](https://www.youtube.com/playlist?list=PLZHQObOWTQDMsr9K-rj53DwV  │
│  RMYO3t5Yr)                                                                  │
│                                                                              │
│  And to clarify a key distinction: the *limit* of a function at a point      │
│  describes what the function approaches as x gets near that point, while     │
│  the *value* of the function is simply f(a), the output when x = a. These    │
│  can be different—especially when there’s a hole or discontinuity. For       │
│  example, a function might have a removable discontinuity where the limit    │
│  exists but the value does not (or is defined elsewhere). Understanding      │
│  this difference is crucial for mastering continuity and derivatives later   │
│  on.                                                                         │

│  ### **1. Concept Explanation: The Fundamental Concept of Limits**           │
│                                                                              │
│  A limit in calculus describes the value that a function approaches as the   │
│  input gets closer and closer to a certain point. It’s not necessarily the   │
│  actual value of the function at that point—just what the function seems to  │
│  be heading toward. Think of it like approaching a red light in your car:    │
│  you can get very close to the stop line without actually touching it. The   │
│  limit is about where you're heading, not where you end up.                  │
│                                                                              │
│  For example, consider the function:                                         │
│  $$                                                                          │
│  f(x) = \frac{x^2 - 1}{x - 1}                                                │
│  $$                                                                          │
│  At $ x = 1 $, the function is undefined because it results in $             │
│  \frac{0}{0} $. But if you plug in values very close to 1—like 0.9, 0.99,    │
│  0.999, or 1.1, 1.01, 1.001—you’ll notice the output gets closer and closer  │
│  to 2. So, we say:                                                           │
│  $$                                                                          │
│  \lim_{x \to 1} f(x) = 2                                                     │
│  $$                                                                          │
│  even though $ f(1) $ doesn’t exist.                                         │
│                                                                              │
│  Limits are foundational in calculus because they allow us to define key     │
│  ideas like **derivatives** (rates of change) and **integrals** (areas       │
│  under curves). They help us analyze functions at points where direct        │
│  evaluation isn’t possible.                                                  │
│                                                                              │
│  #### **Types of Limits**                                                    │
│  - **One-Sided Limits**:                                                     │
│    - Left-hand limit: $ \lim_{x \to a^-} f(x) $ — values approaching from    │
│  the left.                                                                   │
│    - Right-hand limit: $ \lim_{x \to a^+} f(x) $ — values approaching from   │
│  the right.                                                                  │
│  - **Two-Sided Limit**:                                                      │
│    Exists only if both one-sided limits exist and are equal:                 │
│    $$                                                                        │
│    \lim_{x \to a} f(x) = L \quad \text{iff} \quad \lim_{x \to a^-} f(x) =    │
│  \lim_{x \to a^+} f(x) = L                                                   │
│    $$                                                                        │
│                                                                              │
│  #### **Common Misconceptions**                                              │
│  - **Misconception**: The limit is the same as the function value.           │
│    **Clarification**: They are different! The limit of $ f(x) $ as $ x \to   │
│  a $ may exist even if $ f(a) $ is undefined or different. For example, a    │
│  function might have a hole or jump at a point but still have a              │
│  well-defined limit.                                                         │

### **1. Concept Explanation: The Fundamental Concept of Limits**

A limit in calculus describes the value that a function approaches as the input gets closer and closer to a certain point. It’s not necessarily the actual value of the function at that point—just what the function seems to be heading toward. Think of it like approaching a red light in your car: you can get very close to the stop line without actually touching it. The limit is about where you're heading, not where you end up.

For example, consider the function:  
$$
f(x) = \frac{x^2 - 1}{x - 1}
$$  
At $ x = 1 $, the function is undefined because it results in $ \frac{0}{0} $. But if you plug in values very close to 1—like 0.9, 0.99, 0.999, or 1.1, 1.01, 1.001—you’ll notice the output gets closer and closer to 2. So, we say:
$$
\lim_{x \to 1} f(x) = 2
$$  
even though $ f(1) $ doesn’t exist.

Limits are foundational in calculus because they allow us to define key ideas like **derivatives** (rates of change) and **integrals** (areas under curves). They help us analyze functions at points where direct evaluation isn’t possible.

#### **Types of Limits**
- **One-Sided Limits**:  
  - Left-hand limit: $ \lim_{x \to a^-} f(x) $ — values approaching from the left.  
  - Right-hand limit: $ \lim_{x \to a^+} f(x) $ — values approaching from the right.  
- **Two-Sided Limit**:  
  Exists only if both one-sided limits exist and are equal:
  $$
  \lim_{x \to a} f(x) = L \quad \text{iff} \quad \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L
  $$

#### **Common Misconceptions**
- **Misconception**: The limit is the same as the function value.  
  **Clarification**: They are different! The limit of $ f(x) $ as $ x \to a $ may exist even if $ f(a) $ is undefined or different. For example, a function might have a hole or jump at a point but still have a well-defined limit.

#### **Examples**
1. $ \lim_{x \to 3} (2x + 1) = 7 $ — as $ x $ gets close to 3, $ 2x+1 $ gets close to 7.  
2. $ \lim_{x \to 0} \frac{\sin x}{x} = 1 $ — even though it’s $ \frac{0}{0} $ at $ x=0 $, the limit is 1.  
3. $ \lim_{x \to 2^-} \frac{1}{x-2} = -\infty $, $ \lim_{x \to 2^+} \frac{1}{x-2} = +\infty $ — the one-sided limits differ, so the two-sided limit does not exist.

#### **Key Takeaway**
Limits are about **behavior near a point**, not **at the point**. They are essential for understanding how functions change and form the backbone of calculus.

#### **Limit vs. Function Value**
- The **limit** of $ f(x) $ as $ x \to a $ describes what the function approaches.  
- The **value** of the function is $ f(a) $, the output when $ x = a $.  
These can be different—especially with holes or discontinuities. Understanding this distinction is crucial for mastering continuity and derivatives.
