│  Final Answer:                                                               │
│  In coordinate geometry, the distance between two points measures how far    │
│  apart they are on a coordinate plane, while the midpoint is the point       │
│  exactly halfway between them.                                               │
│                                                                              │
│  To calculate the **distance** between two points $ A(x_1, y_1) $ and $      │
│  B(x_2, y_2) $, we use the **distance formula**:                             │
│  $$                                                                          │
│  \text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}                      │
│  $$                                                                          │
│  This formula comes from the Pythagorean theorem and gives the length of     │
│  the straight line connecting the two points.                                │
│                                                                              │
│  To find the **midpoint**, or the center point between $ A $ and $ B $, we   │
│  use the **midpoint formula**:                                               │
│  $$                                                                          │
│  \text{Midpoint} = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)   │

### 🔍 **Concept Explanation: Distance and Midpoint in Coordinate Geometry**

In coordinate geometry, we use formulas to find key properties of line segments on the Cartesian plane.

#### **Distance Formula**
To find the distance between two points $ A(x_1, y_1) $ and $ B(x_2, y_2) $:
$$
\text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
$$
This comes from the Pythagorean Theorem.

#### **Midpoint Formula**
To find the point exactly halfway between $ A $ and $ B $:
$$
\text{Midpoint} = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)
$$
