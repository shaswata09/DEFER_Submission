│  Final Answer:                                                               │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the outcome or response) and     │
│  one or more independent variables (also known as predictors or features).   │
│  In its simplest form—simple linear regression—it assumes a straight-line    │
│  relationship between two variables: one independent variable (x) and one    │
│  dependent variable (y).                                                     │
│                                                                              │
│  The goal of linear regression is to find the best-fitting straight line     │
│  through the data points, such that the predictions of y based on x are as   │
│  accurate as possible. This line is described by the equation:               │
│                                                                              │
│  y = mx + b                                                                  │
│                                                                              │
│  In the context of regression:                                               │
│  - y is the predicted value of the dependent variable,                       │
│  - x is the value of the independent variable,                               │
│  - m (the slope) represents how much y changes for a one-unit increase in    │
│  x,                                                                          │
│  - b (the intercept) is the value of y when x is zero.                       │
│                                                                              │
│  The "best-fit" line is determined by minimizing the sum of the squared      │
│  differences between the actual data points and the predicted values on the  │
│  line. These differences are called residuals, and the method is known as    │
│  the least squares criterion. By squaring the residuals, we penalize larger  │
│  errors more heavily and ensure that positive and negative errors don’t      │
│  cancel out.                                                                 │
│                                                                              │
│  For example:                                                                │
│  1. Predicting house prices based on size (in square feet). The regression   │
│  line might show that for every additional 100 square feet, the price        │
│  increases by $5,000 (slope), with a base price of $50,000 (intercept).      │
│  2. Estimating a student's final exam score based on hours studied. If the   │
│  slope is 5 and the intercept is 60, it suggests that a student who studies  │
│  zero hours might score 60, and each additional hour of study adds 5 points  │
│  to the score.                                                               │
│                                                                              │
│  Linear regression helps us understand trends, make predictions, and         │
│  quantify relationships, making it a foundational tool in statistics,        │
│  economics, and machine learning.                                            │

│  Final Answer:                                                               │
│  Linear regression is a statistical method used to model the relationship    │
│  between a dependent variable (often called the outcome or response) and     │
│  one or more independent variables (also known as predictors or features).   │
│  In its simplest form—simple linear regression—it assumes a straight-line    │
│  relationship between two variables: one independent variable (x) and one    │
│  dependent variable (y).                                                     │
│                                                                              │
│  The goal of linear regression is to find the best-fitting straight line     │
│  through the data points, such that the predictions of y based on x are as   │
│  accurate as possible. This line is described by the equation:               │
│                                                                              │
│  y = mx + b                                                                  │
│                                                                              │
│  In the context of regression:                                               │
│  - y is the predicted value of the dependent variable,                       │
│  - x is the value of the independent variable,                               │
│  - m (the slope) represents how much y changes for a one-unit increase in    │
│  x,                                                                          │
│  - b (the intercept) is the value of y when x is zero.                       │
│                                                                              │
│  The "best-fit" line is determined by minimizing the sum of the squared      │
│  differences between the actual data points and the predicted values on the  │
│  line. These differences are called residuals, and the method is known as    │
│  the least squares criterion. By squaring the residuals, we penalize larger  │
│  errors more heavily and ensure that positive and negative errors don’t      │
│  cancel out.                                                                 │
│                                                                              │
│  For example:                                                                │
│  1. Predicting house prices based on size (in square feet). The regression   │
│  line might show that for every additional 100 square feet, the price        │
│  increases by $5,000 (slope), with a base price of $50,000 (intercept).      │
│  2. Estimating a student's final exam score based on hours studied. If the   │
│  slope is 5 and the intercept is 60, it suggests that a student who studies  │
│  zero hours might score 60, and each additional hour of study adds 5 points  │
│  to the score.                                                               │
│                                                                              │
│  Linear regression helps us understand trends, make predictions, and         │
│  quantify relationships, making it a foundational tool in statistics,        │
│  economics, and machine learning.                                            │

FINAL OUTPUT:
Linear regression is a statistical method used to model the relationship between a dependent variable (often called the outcome or response) and one or more independent variables (also known as predictors or features). In its simplest form—simple linear regression—it assumes a straight-line relationship between two variables: one independent variable (x) and one dependent variable (y).

The goal of linear regression is to find the best-fitting straight line through the data points, such that the predictions of y based on x are as accurate as possible. This line is described by the equation:

y = mx + b

In the context of regression:
- y is the predicted value of the dependent variable,
- x is the value of the independent variable,
- m (the slope) represents how much y changes for a one-unit increase in x,
- b (the intercept) is the value of y when x is zero.

The "best-fit" line is determined by minimizing the sum of the squared differences between the actual data points and the predicted values on the line. These differences are called residuals, and the method is known as the least squares criterion. By squaring the residuals, we penalize larger errors more heavily and ensure that positive and negative errors don’t cancel out.

For example:
1. Predicting house prices based on size (in square feet). The regression line might show that for every additional 100 square feet, the price increases by $5,000 (slope), with a base price of $50,000 (intercept).
2. Estimating a student's final exam score based on hours studied. If the slope is 5 and the intercept is 60, it suggests that a student who studies zero hours might score 60, and each additional hour of study adds 5 points to the score.

Linear regression helps us understand trends, make predictions, and quantify relationships, making it a foundational tool in statistics, economics, and machine learning.

What is the primary purpose of linear regression?

A) To classify data into categories  
B) To model the relationship between a dependent variable and one or more independent variables using a straight line  
C) To calculate the median of a dataset  
D) To remove outliers from data  

**Correct Answer:** B  
**Explanation:** Linear regression is used to model the linear relationship between a dependent (response) variable and one or more independent (predictor) variables.

**Question 2: Multiple Choice**  
In the linear regression equation $ y = mx + b $, what does $ m $ represent?

A) The y-intercept  
B) The independent variable  
C) The slope of the line  
D) The residual  

**Correct Answer:** C  
**Explanation:** The slope $ m $ represents the change in the dependent variable $ y $ for a one-unit increase in the independent variable $ x $.

---

**Question 3: Short Answer**  
What is the purpose of the "best-fit line" in linear regression?

**Correct Answer:** The best-fit line minimizes the overall distance between the observed data points and the predicted values, providing the best linear approximation of the relationship between variables.  
**Explanation:** It visually and mathematically represents the trend in the data and is used to make predictions.

---

**Question 4: Short Answer**  
Define "residual" in the context of linear regression.

**Correct Answer:** A residual is the difference between an observed value and the value predicted by the regression model (i.e., $ \text{residual} = y - \hat{y} $).  
**Explanation:** Residuals help assess how well the regression line fits the data; smaller residuals indicate a better fit.

**Explanation:** The least squares method finds the line that minimizes the sum of the squared residuals, making it the standard approach in linear regression.
