│                                                                              │
│  **Question 1: Area Between Curves**                                         │
│  Find the area of the region bounded by the curves \( y = x^2 \) and \( y =  │
│  2x - x^2 \).                                                                │
│                                                                              │
│  **Solution:**                                                               │
│  First, find points of intersection:                                         │
│  \[                                                                          │
│  x^2 = 2x - x^2 \Rightarrow 2x^2 - 2x = 0 \Rightarrow 2x(x - 1) = 0          │
│  \Rightarrow x = 0, x = 1                                                    │
│  \]                                                                          │
│  Top function: \( y = 2x - x^2 \), Bottom function: \( y = x^2 \)            │
│  \[                                                                          │
│  \text{Area} = \int_0^1 \left[(2x - x^2) - x^2\right] dx = \int_0^1 (2x -    │
│  2x^2) dx = \left[ x^2 - \frac{2}{3}x^3 \right]_0^1 = 1 - \frac{2}{3} =      │
│  \frac{1}{3}                                                                 │
│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  Students often misidentify which function is on top. Always sketch or       │
│  evaluate test points to determine the correct order. The integral must      │
│  subtract the lower curve from the upper curve.                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Question 2: Area with Respect to y**                                      │
│  Set up (but do not evaluate) the integral for the area between \( x = y^2   │
│  \) and \( x = y + 2 \) with respect to \( y \).                             │
│                                                                              │
│  **Solution:**                                                               │
│  Find intersection points:                                                   │
│  \[                                                                          │
│  y^2 = y + 2 \Rightarrow y^2 - y - 2 = 0 \Rightarrow (y - 2)(y + 1) = 0      │
│  \Rightarrow y = -1, y = 2                                                   │
│  \]                                                                          │
│  Right function: \( x = y + 2 \), Left function: \( x = y^2 \)               │
│  \[                                                                          │
│  \text{Area} = \int_{-1}^{2} \left[(y + 2) - y^2\right] dy                   │
│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  When integrating with respect to \( y \), the rightmost curve minus the     │
│  leftmost curve is used. This avoids splitting the region, which would be    │
│  necessary if integrating with respect to \( x \).                           │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Question 3: Volume by Slicing – Square Cross Sections**                   │
│  The base of a solid is the region bounded by \( y = \sqrt{x} \), \( y = 0   │
│  \), and \( x = 4 \). Cross sections perpendicular to the x-axis are         │
│  squares. Find the volume of the solid.                                      │
│                                                                              │
│  **Solution:**                                                               │
│  Side length of square = height of function = \( \sqrt{x} \)                 │
│  Area of cross section: \( A(x) = (\sqrt{x})^2 = x \)                        │
│  \[                                                                          │
│  V = \int_0^4 A(x)\,dx = \int_0^4 x\,dx = \left[ \frac{1}{2}x^2 \right]_0^4  │
│  = \frac{1}{2}(16) = 8                                                       │
│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  A common error is using diameter instead of side length or misidentifying   │
│  the dimension of the cross section. Since slices are perpendicular to the   │
│  x-axis and are squares, the side is equal to the function value.            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Question 4: Volume by Slicing – Semi-Circular Cross Sections**            │
│  The base is the region between \( y = x \) and \( y = x^2 \) from \( x = 0  │
│  \) to \( x = 1 \). Cross sections perpendicular to the x-axis are           │
│  semicircles. Set up the integral for the volume.                            │
│                                                                              │
│  **Solution:**                                                               │
│  Diameter of semicircle = \( x - x^2 \), so radius = \( \frac{x - x^2}{2}    │
│  \)                                                                          │
│  Area of semicircle: \( A(x) = \frac{1}{2} \pi r^2 = \frac{1}{2} \pi \left(  │
│  \frac{x - x^2}{2} \right)^2 = \frac{\pi}{8} (x - x^2)^2 \)                  │
│  \[                                                                          │
│  V = \int_0^1 \frac{\pi}{8} (x - x^2)^2 dx                                   │
│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  Students often forget to halve the area for semicircles or use diameter     │
│  instead of radius. The key is identifying the correct geometric dimension   │
│  from the function difference.                                               │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  **Question 5: Conceptual Error Identification**                             │
│  A student sets up the area between \( y = \sin x \) and \( y = \cos x \)    │
│  from \( x = 0 \) to \( x = \frac{\pi}{2} \) as:                             │
│  \[                                                                          │
│  \int_0^{\pi/2} (\sin x - \cos x)\,dx                                        │
│  \]                                                                          │
│  Explain why this is incorrect and provide the correct setup.                │
│                                                                              │
│  **Solution:**                                                               │
│  The functions cross at \( x = \frac{\pi}{4} \). From \( 0 \) to \(          │
│  \frac{\pi}{4} \), \( \cos x > \sin x \); from \( \frac{\pi}{4} \) to \(     │
│  \frac{\pi}{2} \), \( \sin x > \cos x \). The integral above would subtract  │
│  incorrectly over part of the interval and give a net signed area, not       │
│  total area.                                                                 │
│  Correct setup:                                                              │
│  \[                                                                          │
│  \int_0^{\pi/4} (\cos x - \sin x)\,dx + \int_{\pi/4}^{\pi/2} (\sin x - \cos  │
│  x)\,dx                                                                      │
│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  This targets a key misconception: failing to account for curve              │
│  intersections within the interval. The absolute difference must be          │
│  considered, requiring a piecewise setup when curves cross.                  │

│  \]                                                                          │
│                                                                              │
│  **Explanation:**                                                            │
│  A common error is using diameter instead of side length or misidentifying   │

**Question 1: Area Between Curves**  
Find the area of the region bounded by the curves \( y = x^2 \) and \( y = 2x - x^2 \).

**Solution:**  
First, find points of intersection:  
\[
x^2 = 2x - x^2 \Rightarrow 2x^2 - 2x = 0 \Rightarrow 2x(x - 1) = 0 \Rightarrow x = 0, x = 1
\]  
Top function: \( y = 2x - x^2 \), Bottom function: \( y = x^2 \)  
\[
\text{Area} = \int_0^1 \left[(2x - x^2) - x^2\right] dx = \int_0^1 (2x - 2x^2) dx = \left[ x^2 - \frac{2}{3}x^3 \right]_0^1 = 1 - \frac{2}{3} = \frac{1}{3}
\]

**Explanation:**  
Students often misidentify which function is on top. Always sketch or evaluate test points to determine the correct order. The integral must subtract the lower curve from the upper curve.

---

**Question 2: Area with Respect to y**  
Set up (but do not evaluate) the integral for the area between \( x = y^2 \) and \( x = y + 2 \) with respect to \( y \).

**Solution:**  
Find intersection points:  
\[
y^2 = y + 2 \Rightarrow y^2 - y - 2 = 0 \Rightarrow (y - 2)(y + 1) = 0 \Rightarrow y = -1, y = 2
\]  
Right function: \( x = y + 2 \), Left function: \( x = y^2 \)  
\[
\text{Area} = \int_{-1}^{2} \left[(y + 2) - y^2\right] dy
\]

**Explanation:**  
When integrating with respect to \( y \), the rightmost curve minus the leftmost curve is used. This avoids splitting the region, which would be necessary if integrating with respect to \( x \).

---

**Question 3: Volume by Slicing – Square Cross Sections**  
The base of a solid is the region bounded by \( y = \sqrt{x} \), \( y = 0 \), and \( x = 4 \). Cross sections perpendicular to the x-axis are squares. Find the volume of the solid.

**Solution:**  
Side length of square = height of function = \( \sqrt{x} \)  
Area of cross section: \( A(x) = (\sqrt{x})^2 = x \)  
\[
V = \int_0^4 A(x)\,dx = \int_0^4 x\,dx = \left[ \frac{1}{2}x^2 \right]_0^4 = \frac{1}{2}(16) = 8
\]

**Explanation:**  
A common error is using diameter instead of side length or misidentifying the dimension of the cross section. Since slices are perpendicular to the x-axis and are squares, the side is equal to the function value.

---

**Question 4: Volume by Slicing – Semi-Circular Cross Sections**  
The base is the region between \( y = x \) and \( y = x^2 \) from \( x = 0 \) to \( x = 1 \). Cross sections perpendicular to the x-axis are semicircles. Set up the integral for the volume.

**Solution:**  
Diameter of semicircle = \( x - x^2 \), so radius = \( \frac{x - x^2}{2} \)  
Area of semicircle: \( A(x) = \frac{1}{2} \pi r^2 = \frac{1}{2} \pi \left( \frac{x - x^2}{2} \right)^2 = \frac{\pi}{8} (x - x^2)^2 \)  
\[
V = \int_0^1 \frac{\pi}{8} (x - x^2)^2 dx
\]

**Explanation:**  
Students often forget to halve the area for semicircles or use diameter instead of radius. The key is identifying the correct geometric dimension from the function difference.

**Question 5: Conceptual Error Identification**  
A student sets up the area between \( y = \sin x \) and \( y = \cos x \) from \( x = 0 \) to \( x = \frac{\pi}{2} \) as:  
\[
\int_0^{\pi/2} (\sin x - \cos x)\,dx
\]  
Explain why this is incorrect and provide the correct setup.

**Solution:**  
The functions cross at \( x = \frac{\pi}{4} \). From \( 0 \) to \( \frac{\pi}{4} \), \( \cos x > \sin x \); from \( \frac{\pi}{4} \) to \( \frac{\pi}{2} \), \( \sin x > \cos x \). The integral above would subtract incorrectly over part of the interval and give a net signed area, not total area.  
Correct setup:  
\[
\int_0^{\pi/4} (\cos x - \sin x)\,dx + \int_{\pi/4}^{\pi/2} (\sin x - \cos x)\,dx
\]

**Explanation:**  
This targets a key misconception: failing to account for curve intersections within the interval. The absolute difference must be considered, requiring a piecewise setup when curves cross.
