│                                                                              │
│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in one          │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$ ax^2 + bx + c = 0 $$                                                     │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants, $ a \neq 0 $ (if $ a = 0 $,    │
│  the equation becomes linear). The variable $ x $ represents the unknown we  │
│  aim to solve for.                                                           │
│                                                                              │
│  ### Why "Quadratic"?                                                        │
│  The word comes from "quad" meaning square, because the variable is squared  │
│  (i.e., $ x^2 $).                                                            │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  #### 1. **Factoring**                                                       │
│  If the quadratic can be factored into two binomials, we use the **zero      │
│  product property**: if $ AB = 0 $, then $ A = 0 $ or $ B = 0 $.             │
│                                                                              │
│  **Example**:                                                                │
│  Solve $ x^2 - 5x + 6 = 0 $                                                  │
│  Factor: $ (x - 2)(x - 3) = 0 $                                              │
│  So, $ x = 2 $ or $ x = 3 $                                                  │
│                                                                              │
│  ✅ *Only works when the expression is factorable.*                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 2. **Completing the Square**                                           │
│  This method transforms the equation into a perfect square trinomial.        │
│                                                                              │
│  **Example**:                                                                │
│  Solve $ x^2 + 6x + 5 = 0 $                                                  │
│  Step 1: Move constant: $ x^2 + 6x = -5 $                                    │
│  Step 2: Add $ \left(\frac{6}{2}\right)^2 = 9 $: $ x^2 + 6x + 9 = 4 $        │
│  Step 3: Write as square: $ (x + 3)^2 = 4 $                                  │
│  Step 4: Take square root: $ x + 3 = \pm 2 $                                 │
│  Step 5: Solve: $ x = -1 $ or $ x = -5 $                                     │
│                                                                              │
│  This method is especially useful for deriving the quadratic formula.        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  #### 3. **Quadratic Formula**                                               │
│  The most reliable method for any quadratic equation:                        │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  The expression under the square root, $ b^2 - 4ac $, is called the          │
│  **discriminant**.                                                           │
│                                                                              │
│  - If discriminant > 0 → two real solutions                                  │
│  - If discriminant = 0 → one real solution (repeated)                        │
│  - If discriminant < 0 → two complex solutions                               │
│                                                                              │
│  **Example**:                                                                │
│  Solve $ 2x^2 + 3x - 2 = 0 $                                                 │
│  Here, $ a = 2 $, $ b = 3 $, $ c = -2 $                                      │
│  Discriminant: $ 3^2 - 4(2)(-2) = 9 + 16 = 25 $                              │
│  $$                                                                          │
│  x = \frac{-3 \pm \sqrt{25}}{4} = \frac{-3 \pm 5}{4}                         │
│  $$                                                                          │
│  So, $ x = \frac{2}{4} = 0.5 $ or $ x = \frac{-8}{4} = -2 $                  │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Real-World Examples                                                     │
│                                                                              │
│  1. **Projectile Motion**: The height of a ball thrown in the air follows a  │
│  quadratic path.                                                             │
│     Example: $ h(t) = -16t^2 + 32t + 5 $ gives height (in feet) at time $ t  │
│  $ seconds.                                                                  │
│                                                                              │
│  2. **Area Optimization**: Finding dimensions of a rectangle with fixed      │
│  perimeter that maximizes area leads to a quadratic.                         │
│                                                                              │
│  3. **Profit Modeling**: Businesses use quadratics to model profit vs.       │
│  price, where increasing price may reduce sales quadratically.               │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Common Student Mistakes                                                 │
│                                                                              │
│  - **Forgetting $ a \neq 0 $**: If $ a = 0 $, it’s not quadratic.            │
│  - **Misidentifying coefficients**: Especially when equation isn’t in        │
│  standard form.                                                              │
│  - **Sign errors in quadratic formula**: Forgetting to carry the sign of $   │
│  b $.                                                                        │
│  - **Dividing only part of the numerator**: $ \frac{-b \pm \sqrt{D}}{2a} $   │
│  — both terms are divided by $ 2a $.                                         │
│  - **Assuming all quadratics factor**: Many don’t — use formula instead.     │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│                                                                              │
│  Quadratic equations are fundamental in algebra, modeling many real-life     │
│  situations involving parabolic relationships. They can have zero, one, or   │
│  two solutions, depending on the discriminant. Mastery of factoring,         │
│  completing the square, and the quadratic formula ensures students can       │
│  solve any quadratic equation confidently.                                   │

│  ### **Topic 1: Factoring Trinomials with Non-Unity Leading Coefficients**   │
│                                                                              │
│  **Concept Review:**                                                         │
│                                                                              │
│  When factoring a trinomial of the form $ ax^2 + bx + c $ where $ a \neq 1   │
│  $, use the **"AC method"**:                                                 │
│                                                                              │
│  1. Multiply $ a \times c $.                                                 │
│  2. Find two numbers that multiply to $ ac $ and add to $ b $.               │
│  3. Rewrite the middle term $ bx $ using these two numbers.                  │
│  4. Factor by grouping.                                                      │
│                                                                              │
│  **Example:**                                                                │
│  Factor $ 2x^2 + 7x + 3 $                                                    │
│                                                                              │
│  - $ a = 2, c = 3 $ → $ ac = 6 $                                             │
│  - Find two numbers: $ 6 $ and $ 1 $ (since $ 6×1=6 $, $ 6+1=7 $)            │
│  - Rewrite: $ 2x^2 + 6x + x + 3 $                                            │
│  - Group: $ (2x^2 + 6x) + (x + 3) = 2x(x + 3) + 1(x + 3) $                   │
│  - Factor: $ (2x + 1)(x + 3) $                                               │
│                                                                              │
│  ✅ **Practice Problems (Intermediate Level):**                              │

│  ### **Topic 2: Correct Application of the Quadratic Formula**               │
│                                                                              │
│  **Concept Review:**                                                         │
│                                                                              │
│  For any quadratic equation $ ax^2 + bx + c = 0 $, the solutions are:        │
│                                                                              │
│  $$                                                                          │
│  x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                      │
│  $$                                                                          │
│                                                                              │
│  **Common Errors to Avoid:**                                                 │
│  - Forgetting the negative sign on $ b $                                     │
│  - Incorrectly calculating $ b^2 - 4ac $ (discriminant)                      │
│  - Misplacing parentheses: always compute $ -b $, then $                     │
│  \sqrt{\text{discriminant}} $, then divide by $ 2a $                         │
│                                                                              │
│  **Example:**                                                                │
│  Solve $ 2x^2 + 7x + 3 = 0 $                                                 │
│                                                                              │
│  - $ a = 2, b = 7, c = 3 $                                                   │
│  - Discriminant: $ 7^2 - 4(2)(3) = 49 - 24 = 25 $                            │
│  - $ x = \frac{-7 \pm \sqrt{25}}{4} = \frac{-7 \pm 5}{4} $                   │
│  - Solutions: $ x = \frac{-12}{4} = -3 $, $ x = \frac{-2}{4} = -0.5 $        │

#### **B. Correct Application of the Quadratic Formula**

**Formula:**
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

**Step-by-Step Guide:**
1. Ensure the equation is in standard form: $ ax^2 + bx + c = 0 $
2. Identify $ a $, $ b $, and $ c $ (include signs!)
3. Compute discriminant: $ D = b^2 - 4ac $
4. Plug into formula and simplify

**Example:**  
Solve $ 4x^2 - 4x - 3 = 0 $  
- $ a = 4, b = -4, c = -3 $
- $ D = (-4)^2 - 4(4)(-3) = 16 + 48 = 64 $
- $ x = \frac{-(-4) \pm \sqrt{64}}{2(4)} = \frac{4 \pm 8}{8} $
- Solutions: $ x = \frac{12}{8} = 1.5 $, $ x = \frac{-4}{8} = -0.5 $

### **3. Concept Explanation: Understanding Quadratic Equations**

A **quadratic equation** is a second-degree polynomial equation in one variable, written in the standard form:

$$
ax^2 + bx + c = 0 \quad \text{where } a \neq 0
$$

The variable $ x $ is squared, which gives the equation its name (from Latin *quadratus* meaning "square").

#### **Why Are Quadratics Important?**

They model real-world phenomena such as:
- **Projectile motion**: Height of a ball over time: $ h(t) = -16t^2 + v_0t + h_0 $
- **Area optimization**: Maximizing garden area with fixed fencing
- **Economics**: Profit maximization based on pricing

#### **Methods of Solving**

| Method | When to Use | Pros | Cons |
|-------|-------------|------|------|
| **Factoring** | When expression factors easily | Fast, intuitive | Not always possible |
| **Completing the Square** | To derive formula or rewrite vertex form | Builds conceptual understanding | Computationally intensive |
| **Quadratic Formula** | Always works | Universal solution | Requires careful arithmetic |

#### **Discriminant Analysis**

The expression $ b^2 - 4ac $ determines the nature of the roots:
- $ > 0 $: Two distinct real solutions
- $ = 0 $: One repeated real solution
- $ < 0 $: Two complex solutions

This helps predict outcomes before solving.

#### **Common Mistakes to Avoid**
- Forgetting that $ a \neq 0 $
- Misreading $ b $'s sign in the formula
- Dividing only part of the numerator by $ 2a $
- Assuming all quadratics factor
