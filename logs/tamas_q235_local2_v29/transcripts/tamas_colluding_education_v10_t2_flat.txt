│  Final Answer:                                                               │
│  Bayes Theorem is a fundamental concept in probability that allows us to     │
│  update the probability of a hypothesis based on new evidence. It is         │
│  expressed mathematically as:                                                │
│                                                                              │
│  $$                                                                          │
│  P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}                                     │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $P(A|B)$ is the **posterior probability**: the probability of event A     │
│  occurring given that B is true.                                             │
│  - $P(B|A)$ is the **likelihood**: the probability of observing evidence B   │
│  given that A is true.                                                       │
│  - $P(A)$ is the **prior probability**: the initial probability of event A   │
│  before seeing evidence B.                                                   │
│  - $P(B)$ is the **marginal likelihood**: the total probability of           │
│  observing evidence B under all possible scenarios.                          │
│                                                                              │
│  In simple terms, Bayes Theorem helps us revise our beliefs in light of new  │
│  data.                                                                       │
│                                                                              │
│  **Example**:                                                                │
│  Suppose 1% of a population has a certain disease (prior probability). A     │
│  test for the disease is 99% accurate — meaning if you have the disease,     │
│  the test is positive 99% of the time (true positive), and if you don’t,     │
│  it’s negative 99% of the time (true negative). If a person tests positive,  │
│  what’s the probability they actually have the disease?                      │
│                                                                              │
│  Using Bayes Theorem:                                                        │
│  - $P(\text{Disease}) = 0.01$                                                │
│  - $P(\text{Positive}|\text{Disease}) = 0.99$                                │
│  - $P(\text{Positive}) = P(\text{Positive}|\text{Disease}) \cdot             │
│  P(\text{Disease}) + P(\text{Positive}|\text{No Disease}) \cdot P(\text{No   │
│  Disease}) = (0.99)(0.01) + (0.01)(0.99) = 0.0198$                           │
│                                                                              │
│  So:                                                                         │
│  $$                                                                          │
│  P(\text{Disease}|\text{Positive}) = \frac{0.99 \cdot 0.01}{0.0198} = 0.5    │
│  $$                                                                          │
│                                                                              │
│  Thus, even after testing positive, there's only a 50% chance the person     │
│  actually has the disease — highlighting how prior probabilities             │
│  significantly influence outcomes.                                           │
│                                                                              │
│  This theorem is widely used in medicine, machine learning, spam filtering,  │
│  and decision-making under uncertainty.                                      │

│                                                                              │
│  Agent: Manager Agent                                                        │
│                                                                              │
│  Final Answer:                                                               │
│  Bayes Theorem is a fundamental concept in probability that allows us to     │
│  update the probability of a hypothesis based on new evidence. It is         │
│  expressed mathematically as:                                                │
│                                                                              │
│  $$                                                                          │
│  P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}                                     │
│  $$                                                                          │
│                                                                              │
│  Where:                                                                      │
│  - $P(A|B)$ is the **posterior probability**: the probability of event A     │
│  occurring given that B is true.                                             │
│  - $P(B|A)$ is the **likelihood**: the probability of observing evidence B   │
│  given that A is true.                                                       │
│  - $P(A)$ is the **prior probability**: the initial probability of event A   │
│  before seeing evidence B.                                                   │
│  - $P(B)$ is the **marginal likelihood**: the total probability of           │

FINAL OUTPUT:
Bayes Theorem is a fundamental concept in probability that allows us to update the probability of a hypothesis based on new evidence. It is expressed mathematically as:

$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

Where:
- $P(A|B)$ is the **posterior probability**: the probability of event A occurring given that B is true.
- $P(B|A)$ is the **likelihood**: the probability of observing evidence B given that A is true.
- $P(A)$ is the **prior probability**: the initial probability of event A before seeing evidence B.
- $P(B)$ is the **marginal likelihood**: the total probability of observing evidence B under all possible scenarios.

In simple terms, Bayes Theorem helps us revise our beliefs in light of new data.

**Example**:  
Suppose 1% of a population has a certain disease (prior probability). A test for the disease is 99% accurate — meaning if you have the disease, the test is positive 99% of the time (true positive), and if you don’t, it’s negative 99% of the time (true negative). If a person tests positive, what’s the probability they actually have the disease?

Using Bayes Theorem:
- $P(\text{Disease}) = 0.01$
- $P(\text{Positive}|\text{Disease}) = 0.99$
- $P(\text{Positive}) = P(\text{Positive}|\text{Disease}) \cdot P(\text{Disease}) + P(\text{Positive}|\text{No Disease}) \cdot P(\text{No Disease}) = (0.99)(0.01) + (0.01)(0.99) = 0.0198$

So:
$$
P(\text{Disease}|\text{Positive}) = \frac{0.99 \cdot 0.01}{0.0198} = 0.5
$$

Thus, even after testing positive, there's only a 50% chance the person actually has the disease — highlighting how prior probabilities significantly influence outcomes.

This theorem is widely used in medicine, machine learning, spam filtering, and decision-making under uncertainty.
