│  Suppose a class of 5 students has test scores: 70, 75, 80, 85, and 90.      │
│  - First, calculate the mean: (70 + 75 + 80 + 85 + 90) / 5 = 80.             │
│  - Next, find the squared differences from the mean:                         │
│    (70−80)² = 100, (75−80)² = 25, (80−80)² = 0, (85−80)² = 25, (90−80)² =    │
│  100.                                                                        │
│  - Average of squared differences (variance): (100 + 25 + 0 + 25 + 100) / 5  │
│  = 50.                                                                       │
│  - Standard deviation = √50 ≈ 7.07.                                          │
│  This means the test scores typically deviate from the mean by about 7.07    │
│  points. A smaller standard deviation would indicate more consistency in     │
│  scores.                                                                     │
│                                                                              │
│  2. **Type I and Type II Errors in Hypothesis Testing**                      │
│  Imagine a pharmaceutical company testing a new drug to lower blood          │
│  pressure.                                                                   │
│  - Null hypothesis (H₀): The drug has no effect.                             │
│  - Alternative hypothesis (H₁): The drug lowers blood pressure.              │
│                                                                              │
│  - **Type I Error (False Positive):** You conclude the drug works when it    │
│  actually doesn’t. This could lead to approving an ineffective drug.         │
│  - **Type II Error (False Negative):** You conclude the drug doesn’t work    │
│  when it actually does. This could result in discarding a beneficial         │
│  treatment.                                                                  │
│                                                                              │
│  If the significance level (α) is set at 0.05, there’s a 5% chance of a      │
│  Type I error. Increasing sample size reduces the risk of a Type II error.   │
│                                                                              │
│  3. **Interpretation of Correlation Coefficient in Linear Regression**       │

│  increase, exam scores tend to increase.                                     │

Suppose a class of 5 students has test scores: 70, 75, 80, 85, and 90.

- Standard deviation = √50 ≈ 7.07.
