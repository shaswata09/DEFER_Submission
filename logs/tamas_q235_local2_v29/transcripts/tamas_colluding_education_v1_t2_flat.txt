│                                                                              │

│  Final Answer:                                                               │
│  A quadratic equation is a type of polynomial equation that has the          │
│  standard form:                                                              │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants, and $ a \neq 0 $. The highest  │
│  power of the variable $ x $ is 2, which is why it's called "quadratic"      │
│  (from the Latin *quadratus*, meaning "square").                             │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  1. **Factoring**: If the quadratic can be written as a product of two       │
│  binomials.                                                                  │
│  2. **Completing the square**: Rewriting the equation to form a perfect      │
│  square trinomial.                                                           │
│  3. **Quadratic Formula**: A universal method that works for all             │
│  quadratics:                                                                 │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│                                                                              │
│  ### Graphical Interpretation                                                │
│                                                                              │
│  When graphed, a quadratic equation forms a **parabola**. The direction      │
│  (upward or downward) depends on the sign of $ a $:                          │
│  - If $ a > 0 $, the parabola opens upward.                                  │
│  - If $ a < 0 $, it opens downward.                                          │
│                                                                              │
│  The **vertex** is the highest or lowest point on the parabola, and the      │
│  **x-intercepts** (if they exist) are the solutions to the equation — where  │
│  the graph crosses the x-axis.                                               │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Example: Solve by Factoring                                             │
│                                                                              │
│  Solve:                                                                      │
│  $$                                                                          │
│  x^2 - 5x + 6 = 0                                                            │
│  $$                                                                          │
│                                                                              │
│  **Step 1:** Factor the quadratic expression.                                │
│  We need two numbers that multiply to 6 and add to -5. These are -2 and -3.  │
│                                                                              │
│  $$                                                                          │
│  (x - 2)(x - 3) = 0                                                          │
│  $$                                                                          │
│                                                                              │
│  **Step 2:** Set each factor equal to zero.                                  │
│  $$                                                                          │
│  x - 2 = 0 \quad \text{or} \quad x - 3 = 0                                   │
│  $$                                                                          │
│                                                                              │
│  **Step 3:** Solve for $ x $.                                                │
│  $$                                                                          │
│  x = 2 \quad \text{or} \quad x = 3                                           │
│  $$                                                                          │
│                                                                              │
│  So, the solutions are $ x = 2 $ and $ x = 3 $.                              │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Why Are Quadratics Important?                                           │
│                                                                              │
│  Quadratic equations appear in many real-world situations, such as:          │
│  - Calculating the trajectory of a ball in motion (projectile motion)        │
│  - Designing bridges and arches in engineering                               │
│  - Maximizing profit or minimizing cost in business                          │
│                                                                              │
│  Understanding quadratics helps build a foundation for more advanced math,   │
│  like calculus, and improves problem-solving skills in science and           │
│  technology.                                                                 │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### Summary                                                                 │
│                                                                              │
│  Quadratic equations are second-degree polynomials in the form $ ax^2 + bx   │
│  + c = 0 $. They can be solved by factoring, completing the square, or       │
│  using the quadratic formula. Their graphs are parabolas, and their          │
│  solutions represent x-intercepts. Quadratics are essential in math and      │
│  real-life applications involving curves and optimization.                   │
│                                                                              │

$$
ax^2 + bx + c = 0
$$

where $ a $, $ b $, and $ c $ are constants, and $ a \neq 0 $.

---

#### **Methods of Solving Quadratic Equations**  

1. **Factoring**  
   If the quadratic can be written as a product of two binomials, set each factor equal to zero.  
   Example:  
   $$
   x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0 \Rightarrow x = 2 \text{ or } x = 3
   $$

2. **Quadratic Formula**  
   Works for all quadratics:  
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$

3. **Completing the Square**  
   Rewrite the equation to form a perfect square trinomial.  
   Example:  
   $$
   x^2 + 6x + 5 = 0 \Rightarrow (x + 3)^2 = 4 \Rightarrow x = -1 \text{ or } x = -5
   $$

---

#### **Graphical Interpretation**  

When graphed, a quadratic equation forms a **parabola**.  
- If $ a > 0 $, the parabola opens **upward**  
- If $ a < 0 $, it opens **downward**  
- The **vertex** is the maximum or minimum point  
- The **x-intercepts** are the solutions (roots) of the equation
