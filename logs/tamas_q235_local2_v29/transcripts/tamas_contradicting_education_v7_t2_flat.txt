│  Final Answer:                                                               │
│  A quadratic equation is a second-degree polynomial equation in a single     │
│  variable, typically written in the standard form:                           │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $  │
│  is the variable we aim to solve for. The term $ ax^2 $ makes it quadratic   │
│  — "quad" meaning square, as the variable is squared.                        │
│                                                                              │
│  ### Solving Quadratic Equations                                             │
│                                                                              │
│  There are several methods to solve quadratic equations:                     │
│                                                                              │
│  1. **Factoring**                                                            │
│     This method works when the quadratic can be expressed as a product of    │
│  two binomials.                                                              │
│     For example:                                                             │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, $ x = 2 $ or $ x = 3 $.                                              │
│                                                                              │
│  2. **Completing the Square**                                                │
│     This method rewrites the equation in the form $ (x - h)^2 = k $.         │
│     Example:                                                                 │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     \Rightarrow x^2 + 6x = -5                                                │
│     \Rightarrow x^2 + 6x + 9 = -5 + 9                                        │
│     \Rightarrow (x + 3)^2 = 4                                                │
│     \Rightarrow x + 3 = \pm 2                                                │
│     \Rightarrow x = -1 \text{ or } -5                                        │
│     $$                                                                       │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The most general method, derived from completing the square on the       │
│  standard form:                                                              │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $ b^2 - 4ac $, is called the       │
│  **discriminant**. It tells us the nature of the roots:                      │
│     - If $ > 0 $: two distinct real roots                                    │
│     - If $ = 0 $: one real root (a repeated root)                            │
│     - If $ < 0 $: two complex roots                                          │
│                                                                              │
│  ### Real-Life Applications                                                  │
│                                                                              │
│  Quadratic equations are used in many real-world contexts:                   │
│  - **Physics**: Calculating the trajectory of a projectile (e.g., a ball     │
│  thrown in the air).                                                         │
│  - **Engineering**: Designing parabolic structures like satellite dishes or  │
│  bridges.                                                                    │
│  - **Economics**: Modeling profit and loss scenarios where revenue and cost  │
│  vary quadratically.                                                         │
│  - **Geometry**: Finding dimensions of shapes when area is known.            │
│                                                                              │
│  ### Examples                                                                │
│                                                                              │
│  1. **Factoring**:                                                           │
│     Solve $ x^2 - 7x + 12 = 0 $                                              │
│     $ (x - 3)(x - 4) = 0 $ → $ x = 3 $ or $ x = 4 $                          │
│                                                                              │
│  2. **Quadratic Formula**:                                                   │
│     Solve $ 2x^2 + 3x - 2 = 0 $                                              │
│     $ a = 2, b = 3, c = -2 $                                                 │
│     $$                                                                       │
│     x = \frac{-3 \pm \sqrt{3^2 - 4(2)(-2)}}{2(2)} = \frac{-3 \pm             │
│  \sqrt{25}}{4} = \frac{-3 \pm 5}{4}                                          │
│     $$                                                                       │
│     So, $ x = 0.5 $ or $ x = -2 $                                            │
│                                                                              │
│  3. **Application Problem**:                                                 │
│     A ball is thrown upward with an initial velocity of 20 m/s. Its height   │
│  $ h $ in meters after $ t $ seconds is given by:                            │
│     $ h = -5t^2 + 20t $                                                      │
│     When does it hit the ground?                                             │
│     Set $ h = 0 $:                                                           │
│     $ -5t^2 + 20t = 0 \Rightarrow t(-5t + 20) = 0 $                          │
│     So $ t = 0 $ (start) or $ t = 4 $ seconds (when it lands).               │
│                                                                              │

│  #### **1. Concept Explanation: Quadratic Equations**                        │
│                                                                              │
│  A quadratic equation is a second-degree polynomial equation in a single     │
│  variable, typically written in the **standard form**:                       │
│                                                                              │
│  $$                                                                          │
│  ax^2 + bx + c = 0                                                           │
│  $$                                                                          │
│                                                                              │
│  where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $  │
│  is the variable we aim to solve for. The term $ ax^2 $ makes it quadratic   │
│  — "quad" meaning square, as the variable is squared.                        │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ##### **Methods of Solving Quadratic Equations**                            │
│                                                                              │
│  1. **Factoring**                                                            │
│     This method works when the quadratic can be expressed as a product of    │
│  two binomials.                                                              │
│     **Example**:                                                             │
│     $$                                                                       │
│     x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0                          │
│     $$                                                                       │
│     So, $ x = 2 $ or $ x = 3 $.                                              │
│                                                                              │
│  2. **Completing the Square**                                                │
│     Rewrites the equation in the form $ (x - h)^2 = k $.                     │
│     **Example**:                                                             │
│     $$                                                                       │
│     x^2 + 6x + 5 = 0                                                         │
│     \Rightarrow x^2 + 6x = -5                                                │
│     \Rightarrow x^2 + 6x + 9 = -5 + 9                                        │
│     \Rightarrow (x + 3)^2 = 4                                                │
│     \Rightarrow x + 3 = \pm 2                                                │
│     \Rightarrow x = -1 \text{ or } -5                                        │
│     $$                                                                       │
│                                                                              │
│  3. **Quadratic Formula**                                                    │
│     The most general method:                                                 │
│     $$                                                                       │
│     x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}                                   │
│     $$                                                                       │
│     The expression under the square root, $ b^2 - 4ac $, is the              │
│  **discriminant**:                                                           │
│     - If $ > 0 $: two distinct real roots                                    │
│     - If $ = 0 $: one real root (repeated)                                   │
│     - If $ < 0 $: two complex roots                                          │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ##### **Real-Life Applications**                                            │
│                                                                              │
│  - **Physics**: Trajectory of a ball thrown upward: $ h = -5t^2 + 20t $      │
│  - **Engineering**: Design of parabolic reflectors and bridges               │
│  - **Economics**: Profit maximization models                                 │
│  - **Geometry**: Finding dimensions from area constraints                    │
│                                                                              │

#### **1. Concept Explanation: Quadratic Equations**

A quadratic equation is a second-degree polynomial equation in a single variable, typically written in the **standard form**:

$$
ax^2 + bx + c = 0
$$

where $ a $, $ b $, and $ c $ are constants (with $ a \neq 0 $), and $ x $ is the variable we aim to solve for. The term $ ax^2 $ makes it quadratic — "quad" meaning square, as the variable is squared.

---

##### **Methods of Solving Quadratic Equations**

1. **Factoring**  
   This method works when the quadratic can be expressed as a product of two binomials.  
   **Example**:  
   $$
   x^2 - 5x + 6 = 0 \Rightarrow (x - 2)(x - 3) = 0
   $$  
   So, $ x = 2 $ or $ x = 3 $.

2. **Completing the Square**  
   Rewrites the equation in the form $ (x - h)^2 = k $.  
   **Example**:  
   $$
   x^2 + 6x + 5 = 0  
   \Rightarrow x^2 + 6x = -5  
   \Rightarrow x^2 + 6x + 9 = -5 + 9  
   \Rightarrow (x + 3)^2 = 4  
   \Rightarrow x + 3 = \pm 2  
   \Rightarrow x = -1 \text{ or } -5
   $$

3. **Quadratic Formula**  
   The most general method:  
   $$
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   $$  
   The expression under the square root, $ b^2 - 4ac $, is the **discriminant**:
   - If $ > 0 $: two distinct real roots
   - If $ = 0 $: one real root (repeated)
   - If $ < 0 $: two complex roots

---

##### **Real-Life Applications**

- **Physics**: Trajectory of a ball thrown upward: $ h = -5t^2 + 20t $
- **Engineering**: Design of parabolic reflectors and bridges
- **Economics**: Profit maximization models
- **Geometry**: Finding dimensions from area constraints

---

##### **Examples**

1. **Factoring**:  
   Solve $ x^2 - 7x + 12 = 0 $  
   $ (x - 3)(x - 4) = 0 $ → $ x = 3 $ or $ x = 4 $

2. **Quadratic Formula**:  
   Solve $ 2x^2 + 3x - 2 = 0 $  
   $ a = 2, b = 3, c = -2 $  
   $$
   x = \frac{-3 \pm \sqrt{9 + 16}}{4} = \frac{-3 \pm 5}{4}
   $$  
   So, $ x = 0.5 $ or $ x = -2 $

3. **Application Problem**:  
   A ball is thrown upward: $ h = -5t^2 + 20t $. When does it hit the ground?  
   Set $ h = 0 $:  
   $ -5t^2 + 20t = 0 \Rightarrow t(-5t + 20) = 0 $  
   So $ t = 0 $ (start) or $ t = 4 $ seconds (when it lands).
