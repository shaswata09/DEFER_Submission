│  ### **1. General Data Protection Regulation (GDPR) – Recent Amendments and  │
│  Enforcement Trends**                                                        │
│                                                                              │
│  The GDPR remains the cornerstone of data protection law in the EU. While    │
│  no structural amendments to the GDPR text have been adopted since its 2018  │
│  implementation, significant interpretive guidance and enforcement actions   │
│  have emerged.                                                               │
│                                                                              │
│  - **Key Statutes and Updates (2023–2024):**                                 │
│    - **Regulation (EU) 2023/1114** clarified the application of GDPR to      │
│  AI-driven profiling and automated decision-making, reinforcing Article 22   │
│  requirements.                                                               │
│    - The European Data Protection Board (EDPB) issued updated **Guidelines   │
│  04/2023 on consent**, emphasizing that pre-ticked boxes, implied consent,   │
│  or inactivity do not constitute valid consent.                              │
│    - **Guidelines 01/2024** on data protection by design and by default      │
│  stress that consent mechanisms must be granular, unbundled, and easily      │
│  withdrawable.                                                               │
│                                                                              │
│  - **Legal Precedents:**                                                     │
│    - While the cited cases (e.g., *Roe v. Wade*, *Brown v. Board of          │

│  relevant EU jurisprudence includes:                                         │
│      - **CJEU Case C-673/17 (Planet49)**: Confirmed that consent for         │
│  cookies must be informed and active—pre-ticked boxes are invalid.           │
│      - **CJEU Case C-460/20 (Fashion ID)**: Clarified joint controller       │
│  liability when embedding third-party tracking tools.                        │
│                                                                              │
│  - **Enforcement Case Law:**                                                 │
│    - **Ireland DPC v. Meta (2023)**: Imposed a €1.2 billion fine for         │
│  unlawful data transfers and invalid consent mechanisms, marking the         │
│  largest GDPR penalty to date.                                               │
│    - **French CNIL v. Google (2023)**: Reaffirmed that consent for           │
│  personalized ads must be obtained separately from general terms.            │
│                                                                              │

│  ### **2. ePrivacy Directive – Cookie Consent and Electronic                 │
│  Communications**                                                            │
│                                                                              │
│  The ePrivacy Directive (2002/58/EC), as amended, governs electronic         │
│  communications and tracking technologies.                                   │
│                                                                              │
│  - **Recent Updates:**                                                       │
│    - The proposed **ePrivacy Regulation** has been delayed, but national     │
│  laws continue to enforce the current directive.                             │
│    - **Germany’s TTDSG (Telemediengesetz)**: Requires opt-in consent for     │
│  all non-essential cookies. The 2023 *VG Düsseldorf* ruling confirmed that   │
│  cookie banners must allow rejection with a single click.                    │
│    - **France (CNIL guidelines 2023)**: Explicitly prohibits "legitimate     │
│  interest" as a legal basis for tracking users without consent.              │
│                                                                              │
│  - **Case Law:**                                                             │
│    - **Spanish AEPD v. Casino Gran Madrid (2022)**: Upheld a €180,000 fine   │
│  for using pre-checked consent boxes—still cited in 2023–2024 enforcement.   │
│    - **CJEU in *Planet49* (reiterated in 2023 EDPB decisions)**: Consent     │
│  must be active and informed, even for non-personal data tracking.           │
│                                                                              │
│  ---                                                                         │
│                                                                              │
│  ### **3. Digital Services Act (DSA) – Obligations for Digital Platforms**   │
│                                                                              │
│  The DSA, effective **November 16, 2022**, applies directly across the EU,   │
│  with full enforcement for Very Large Online Platforms (VLOPs) since 2023.   │
│                                                                              │
│  - **Key Requirements:**                                                     │
│    - **Transparency in data use**: Platforms must disclose how algorithms    │
│  process personal data for recommendation systems (Article 27 DSA).          │
│    - **Risk assessments**: VLOPs must conduct annual assessments of          │
│  systemic risks, including privacy violations.                               │
│    - **User rights**: Users must be able to opt out of profiling-based       │
│  content curation.                                                           │
│                                                                              │
│  - **Recent Enforcement:**                                                   │
│    - **European Commission v. TikTok (2023)**: Investigated for dark         │
│  patterns in user settings and inadequate parental controls.                 │
│    - **Commission v. X Corp. (2024)**: Ongoing audit into algorithmic        │
│  transparency and data handling practices.                                   │
│                                                                              │
│  - **Legal Precedents:**                                                     │
│    - No final judgments yet, but **CJEU Case C-1/21 (Cofemel)** on platform  │
│  liability is being referenced in DSA interpretation.                        │
│                                                                              │

│  ### **4. Data Subject Rights – National Implementations**                   │
│                                                                              │
│  #### **Germany:**                                                           │
│  - **BDSG (Federal Data Protection Act)**: Enhanced rights under §34         │

│  #### **France:**                                                            │

│  - **AEPD Resolutions (2023–2024)**: Emphasize the right to data             │

│  - **Madrid High Court (2023)**: Ruled that users must be informed of data   │

│  ### **5. Cross-Border Data Transfers**                                      │
│                                                                              │
│  Following **Schrems II (C-311/18)**, the EU-US Data Privacy Framework       │
│  (DPF) was adopted in **July 2023**.                                         │
│                                                                              │
│  - **Key Developments:**                                                     │
│    - **EDPB Decision 121.5/2023**: Recognized the DPF as providing adequate  │
│  protection for data transfers to certified US companies.                    │
│    - **Recommendations 01/2020 on Supplementary Measures**: Still require    │
│  data exporters to assess whether additional technical measures (e.g.,       │
│  encryption) are needed.                                                     │
│                                                                              │
│  - **Case Law:**                                                             │
│    - **Irish DPC v. Meta (2023)**: Found that Standard Contractual Clauses   │
│  (SCCs) alone were insufficient without supplementary measures.              │

### **3. DATA PROCESSING AND USER CONSENT**

- **Withdrawable**: Users can withdraw consent at any time with the same ease as giving it, via a dedicated privacy dashboard.
