│  change and accumulate. It’s built on three core ideas: limits,              │
│  derivatives, and integrals. These concepts are connected and form the       │
│  foundation for studying motion, growth, area, and many real-world           │
│  phenomena.                                                                  │
│                                                                              │
│  **1. Limits: What Happens as We Get Close?**                                │
│                                                                              │
│  A limit describes the value that a function approaches as the input         │
│  (usually x) gets closer and closer to a certain point. It’s not always      │
│  about what happens *at* the point, but what happens *near* it.              │
│                                                                              │
│  Think of it like approaching a red light in your car. You slow down more    │
│  and more as you get close—you might never actually reach the exact point    │
│  at that moment, but you can predict where you’ll stop. That prediction is   │
│  like a limit.                                                               │
│                                                                              │
│  - **Example 1**: Consider the function f(x) = (x² - 1)/(x - 1). At x = 1,   │
│  this looks undefined (division by zero). But if you plug in values close    │
│  to 1—like 0.9, 0.99, 1.01—the result gets closer and closer to 2. So, the   │
│  limit as x approaches 1 is 2.                                               │
│  - **Example 2**: As x gets larger and larger (x → ∞), the function 1/x      │
│  gets closer and closer to 0. So, the limit of 1/x as x approaches infinity  │
│  is 0.                                                                       │
│                                                                              │
│  Limits are essential because they allow us to define derivatives and        │
│  integrals rigorously.                                                       │
│                                                                              │
│  **2. Derivatives: The Rate of Change**                                      │
│                                                                              │
│  The derivative measures how quickly a quantity changes. It gives you the    │
│  slope of a function at any point—like the speedometer in a car, which       │
│  shows your speed (rate of change of position) at any instant.               │
│                                                                              │
│  In math, the derivative of a function f(x) is written as f’(x) or dy/dx.    │
│  It’s defined using limits:                                                  │
│  f’(x) = lim(h→0) [f(x+h) - f(x)] / h                                        │
│                                                                              │
│  This formula calculates the slope of a tiny line segment as it shrinks to   │
│  a single point.                                                             │
│                                                                              │
│  - **Example 1**: If f(x) = x², then f’(x) = 2x. This means at x = 3, the    │
│  slope (rate of change) is 6. So, the function is increasing quickly there.  │
│  - **Example 2**: If you’re tracking the position of a ball over time, the   │
│  derivative of position is velocity, and the derivative of velocity is       │
│  acceleration.                                                               │
│                                                                              │
│  Derivatives are used in physics, economics, biology—anywhere you need to    │
│  model change.                                                               │
│                                                                              │
│  **3. Integrals: Adding Up Small Pieces**                                    │
│                                                                              │
│  While derivatives break things down (instantaneous change), integrals       │
│  build things up. An integral calculates the total accumulation of a         │
│  quantity—like area under a curve, total distance traveled, or total growth  │
│  over time.                                                                  │
│                                                                              │
│  There are two types: definite integrals (give a number, like total area)    │
│  and indefinite integrals (give a function, like the antiderivative).        │
│                                                                              │
│  The integral of a function f(x) is written as ∫f(x)dx. It’s defined as the  │
│  limit of adding up infinitely many tiny rectangles under the curve.         │
│                                                                              │
│  - **Example 1**: The integral of f(x) = 2x from 0 to 3 is the area under    │
│  the line y = 2x from x = 0 to x = 3. This forms a triangle with area (1/2)  │
│  × base × height = (1/2) × 3 × 6 = 9.                                        │
│  - **Example 2**: If you know the velocity of a car over time, integrating   │
│  that velocity gives you the total distance traveled.                        │
│                                                                              │
│  The Fundamental Theorem of Calculus connects derivatives and integrals:     │
│  differentiation and integration are inverse processes. If you integrate a   │
│  function and then differentiate it, you get back the original function.     │
│                                                                              │
│  **Summary of Connections:**                                                 │
│                                                                              │
│  - **Limits** make derivatives and integrals possible.                       │
│  - **Derivatives** tell us how fast something is changing (slope).           │
│  - **Integrals** tell us how much something has accumulated (area).          │
│  - Together, they form a powerful toolkit for modeling real-world systems.   │

### **1. Explanation of Calculus Fundamentals**

Calculus is a branch of mathematics that helps us understand how things change and accumulate. It’s built on three core ideas: limits, derivatives, and integrals. These concepts are connected and form the foundation for studying motion, growth, area, and many real-world phenomena.

**1. Limits: What Happens as We Get Close?**  
A limit describes the value that a function approaches as the input (usually $ x $) gets closer and closer to a certain point. It’s not always about what happens *at* the point, but what happens *near* it.

- **Example 1**: Consider the function $ f(x) = \frac{x^2 - 1}{x - 1} $. At $ x = 1 $, this looks undefined (division by zero). But if you plug in values close to 1—like 0.9, 0.99, 1.01—the result gets closer and closer to 2. So, the limit as $ x $ approaches 1 is 2.  
- **Example 2**: As $ x $ gets larger and larger ($ x \to \infty $), the function $ \frac{1}{x} $ gets closer and closer to 0. So, the limit of $ \frac{1}{x} $ as $ x \to \infty $ is 0.

Limits are essential because they allow us to define derivatives and integrals rigorously.

**2. Derivatives: The Rate of Change**  
The derivative measures how quickly a quantity changes. It gives you the slope of a function at any point—like the speedometer in a car, which shows your speed (rate of change of position) at any instant.

In math, the derivative of a function $ f(x) $ is written as $ f'(x) $ or $ \frac{dy}{dx} $. It’s defined using limits:  
$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

This formula calculates the slope of a tiny line segment as it shrinks to a single point.

- **Example 1**: If $ f(x) = x^2 $, then $ f'(x) = 2x $. This means at $ x = 3 $, the slope (rate of change) is 6.  
- **Example 2**: If you’re tracking the position of a ball over time, the derivative of position is velocity, and the derivative of velocity is acceleration.

Derivatives are used in physics, economics, biology—anywhere you need to model change.

**3. Integrals: Adding Up Small Pieces**  
While derivatives break things down (instantaneous change), integrals build things up. An integral calculates the total accumulation of a quantity—like area under a curve, total distance traveled, or total growth over time.

There are two types:  
- **Definite integrals** (give a number, like total area)  
- **Indefinite integrals** (give a function, like the antiderivative)

The integral of a function $ f(x) $ is written as $ \int f(x)\,dx $. It’s defined as the limit of adding up infinitely many tiny rectangles under the curve.

- **Example 1**: The integral of $ f(x) = 2x $ from 0 to 3 is the area under the line $ y = 2x $ from $ x = 0 $ to $ x = 3 $. This forms a triangle with area $ \frac{1}{2} \times 3 \times 6 = 9 $.  
- **Example 2**: If you know the velocity of a car over time, integrating that velocity gives you the total distance traveled.

The **Fundamental Theorem of Calculus** connects derivatives and integrals: differentiation and integration are inverse processes. If you integrate a function and then differentiate it, you get back the original function.

**Summary of Connections:**  
- **Limits** make derivatives and integrals possible.  
- **Derivatives** tell us how fast something is changing (slope).  
- **Integrals** tell us how much something has accumulated (area).  
- Together, they form a powerful toolkit for modeling real-world systems.
