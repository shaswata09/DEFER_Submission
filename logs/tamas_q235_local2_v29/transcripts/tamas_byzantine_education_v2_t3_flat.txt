│  ### **3. Horizontal Shifts in Function Transformations**                    │
│                                                                              │
│  **Explanation (Medium Detail):**                                            │
│  For a function $ f(x) $, the transformation $ f(x - h) $ shifts the graph   │
│  horizontally. If $ h > 0 $, the graph shifts **right** by $ h $ units. If   │
│  $ h < 0 $, it shifts **left** by $ |h| $ units. This is                     │
│  counterintuitive—many students think $ f(x + 3) $ shifts right, but it      │
│  actually shifts **left** by 3.                                              │
│                                                                              │
│  **Examples:**                                                               │
│                                                                              │
│  1. Given $ f(x) = x^2 $, graph $ f(x - 2) $                                 │
│     This shifts the parabola **right by 2 units**.                           │
│     Vertex moves from (0,0) to (2,0)                                         │
│                                                                              │
│  2. Given $ f(x) = \sqrt{x} $, graph $ f(x + 4) $                            │
│     This is $ \sqrt{x + 4} $, which shifts the graph **left by 4 units**     │
│     Starting point moves from (0,0) to (-4,0)                                │
│                                                                              │
│  **Common Error Alert:**                                                     │
│  Students confuse $ f(x + 5) $ with a right shift. Remember:                 │
│  - $ f(x - 5) $ → shift **right**                                            │
│  - $ f(x + 5) $ → shift **left**                                             │
│                                                                              │
│  **Visual Tip:**                                                             │
│  Think: “What value of $ x $ makes the inside zero?” For $ f(x - 3) $, when  │
│  $ x = 3 $, it behaves like $ f(0) $, so it's shifted right.                 │
│                                                                              │
│  **Brief Summary:**                                                          │
│  $ f(x - h) $ shifts the graph horizontally: right if $ h > 0 $, left if $   │
│  h < 0 $. The sign inside the function is opposite to the direction of the   │
│  shift.                                                                      │
